# 动作构建进度与处理时限

动作编辑页在“动作构建与导出”中显示当前处理阶段、图层、采样帧、修正轮次、已用时和最后一次进度更新时间。帧计数只代表当前图层或检查阶段，不能作为整个构建的完成百分比；自适应修正可能增加采样或进入下一轮。

短暂网络断开后页面继续查询原任务，不重新提交构建。刷新或重新打开带任务编号的编辑页可继续查看。取消会终止该任务的工作进程，已生成候选和来源记录保留。

角色构建与文件解析使用不同的预算：角色构建最长 60 分钟，连续 15 分钟没有处理进度会停止；文件解析仍为 4 分钟，动作生成仍为 60 分钟。角色构建超时分别报告 `motion_target_timeout`（总时限）或 `motion_target_stalled`（无进度），不再混用文件解码超时。时限是资源保护，并非完成时间承诺。

性能优化仅跳过已严格满足全部求解目标的固定点所对应的空迭代，不减少采样、不降低几何或 Runtime 验收标准。无法修复的变形仍保留为异常。
