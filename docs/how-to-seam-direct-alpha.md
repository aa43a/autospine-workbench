# 直接 UV／alpha 子像素核查

本诊断直接执行世界坐标→当前变形三角形→UV→源纹理双线性 alpha 采样，
不再对已有世界像素中心值作二次插值。保留此前报告及动画，结果仍为 needs_review。

```powershell
python -m autospine_workbench.benchmark.seam_direct_alpha_cli `
  --before ../tmp/r2b-continuous-anchor/alice-v1.json `
  --after ../tmp/r2b-seam-increment/alice-v1.json `
  --before-dir ../tmp/r2b-continuous-anchor/alice `
  --after-dir ../tmp/r2b-seam-increment/alice `
  --output-dir ../tmp/r2b-direct-alpha/alice
```

每个已记录空白像素单元使用规则 8×8、16×16 中心子采样，记录两层各自 alpha<8 的数量，
以及合成 alpha `255 * (1 - (1-a/255)*(1-b/255))` <8 的数量、均值和极值。
二者不能混用：两层分别较淡，叠加后仍可超过阈值。
报告绑定 source_isoline_sha256，逐点核验旧整数格中心采样及“原动画有覆盖、增量后两层各自低于阈值”。
`read_direct` 重算报告并比对规范化内容地址。

页面展示每关系按原顺序前三个像素单元的 16×16 alpha 图，其余数据可展开。
黑色表示透明，白色表示不透明；这不是角色最终彩色截图。

## 2026-09-08 发现

| 关系 | 样本数 | 16×16 合成 alpha<8 的最小占比 | 8／16 采样最大占比变化 |
| --- | ---: | ---: | ---: |
| Alice 左 | 7 | 11.71875% | 1.953125 个百分点 |
| 琪露诺左 | 99 | 20.3125% | 3.90625 个百分点 |
| 琪露诺右 | 212 | 1.5625% | 6.25 个百分点 |

全部 318 个像素单元内均存在低合成 alpha 子采样点；这支持空白不是仅由前一版轮廓插值产生。
Alice 七个中心均被两张附件的 Mesh 覆盖，低 alpha 来自纹理采样，不是中心位置没有三角形覆盖。
其中三个中心（34 帧、37 帧、52 帧的第二点）虽然两层分别低于 8，合成后却达到 8，
说明原逐附件阈值计数不能直接当作最终合成透明度判据。

该结果不证明玩家可见裂缝：使用源图纹理、CPU 双线性过滤、三角形重叠取最大 alpha，
没有模拟全部 GPU 边缘规则、Atlas 采样、混合状态、角色其他附件及屏幕缩放。
16×16 是采样估计，不是连续面积积分；8／16 差异也不是严格误差界。
铃仙无接缝候选，不计为通过。

下一步应优先在同帧官方 Runtime 中分别捕获附件隔离与最终合成的局部区域，
对照 alpha 与实际颜色，并校准可见性门禁；暂不通过修改权重消除未校准的计数。
