# M4 同帧连贯深度推断

本切片从“只挑整段始终单向的小区域”转为同一帧内联合处理相邻
三角形。它是显式的代理模型实验，不是真实深度观测，也未作为默认
自动采用规则。源资产、原动作候选和已有人工决定保持不变。

## 固定算法

使用二值 Potts 代价：每个三角形选择相对某身体附件的前/后标签，
相邻且两者均有采样重叠时，标签不同增加 8 的代价；相对上一时刻
变化增加 1。通过有界整数容量最小割求解。无角色名、动作名或单帧
特例，不为得到通过结果逐角色调参。

明确的前/后代理证据作为不可违背约束。深度裕量不足区域可以得到
模型推断，但仍保存原 `A` 状态及推断索引。未知或三角形内部前后
混合保留 setup 标签，并继续作为未解决项传给顺序检查；未测帧不能
使用异常中断前产生的部分统计。

邻接项目前仅根据三角形拓扑和采样重叠存在性构建，不是精确的
alpha 边界长度代价。8:1 是版本化的实验参数，尚未证明跨网格密度
或角色结构最优，不能解读为置信概率。每个身体附件分别求解，再由
整体顺序检查核对所有关系，不能用一张衣层的结果覆盖另一张。

将完整时间序列标签用于连续三角形分区，保持纹理、权重、源三角形
顺序，并压缩分区顶点和 deform。输出逐源帧与中间帧的几何对应检查
后，才尝试可见交叉约束及循环检查。循环上限和内部混合不被绕过。

两种结构使用相同策略，转身均为 44 源帧加 43 中间帧；不是新的
3D 观测。来源观测文件先由原 MotionIR 链重新生成，并写入字节 SHA。

这些是模型检查计数，不是视觉错误率。与前一版兼容分区相比，Alice
区域数由 206 降到 186；红美铃由 132 增到 163，不能宣称普遍降低
复杂度。两组均保留完整动作，没有裁剪失败时刻。本轮未重新捕获
Runtime，也没有新增视觉验收记录。

观测、报告和推断文件哈希。局部输出目录分别为：

- `../tmp/m4-motion-center/coherent-region-order-alice-v1/`
- `../tmp/m4-motion-center/coherent-region-order-hong-v1/`

`partition.json` 只是未施加新顺序的网格表示；只有整体检查生成了
候选才写 `skeleton.json`，不能将前者当成已修复的动画。

## 验证与下一步

小图穷举验证最小割能量与最优值一致；硬约束、确定性、未知输入和
资源边界有回归测试。真实输出另外核对明确标签零覆盖。

目前瓶颈已明确为跨衣层关系与三角形内部混合，单纯增加空间平滑
不能解决。下一阶段应处理这些具体约束的来源和几何分辨率，并继续
使用上一轮的相邻显示连续性门禁。不能把未通过的模型标签直接写入
工作台默认资产，也不能为取得通过而删去失败时刻。

后续[共享边界复核](m4-shared-boundary-refinement.md)确认部分相邻网格
边界被含边栅格采样记成重叠。已在隔离实验中纠正并保留原测量，但
两角色仍有跨图层顺序冲突，没有生成替代动画或改变默认策略。
