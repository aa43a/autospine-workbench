# 使用 M4 动作中心

从主工作台顶部点击 **动作中心**，或访问 `/motions.html`。文件和角色均在界面选择，不需要输入 SHA、服务器路径或命令。

角色动作任务出现几何异常时，点击“检查可用范围与待处理项 → 查看变形区域与处理方案”。在当前页面选择异常三角形，对照原纹理、骨骼影响和面积变化；“定位到此动作时刻”在支持同步播放的入口定位现有播放器，否则打开该候选播放器。原图定位与动作轮廓是两种观察，面积失败点不一定就是可见裂缝位置。历史候选缺少 setup 证据时会提示重建，不推定通过。此入口尚不提供自动分区或姿态附件编辑。

1. 选择 FBX/BVH 或 Kimodo SOMA77 NPZ 文件和投影视角，点击“导入并解析”。NPZ 需选择 SOMA77 约定并填写实际导出帧率（默认 30）。任务卡显示上传、转换、核对骨架和编译阶段；可取消、刷新或重新解析。
2. 点击“查看源动作”，拖动时间轴检查骨架。标准 Mixamo 名称及 `mixamorig:` 前缀可自动生成 MotionIR；其他骨架保留源预览并提示映射待处理。
3. 在“应用到角色”选择已经构建整角色候选的项目，点击“构建角色动作候选”。若当前角色来源已变化，先回工作台重新构建整角色。
4. 完成后点击“打开角色时间轴”，使用官方 Runtime 播放、暂停、拖动和全屏查看。下载的 ZIP 是独立诊断候选，包含 Spine JSON、atlas、纹理与检查记录。当前入口不替换已验收角色、不增加人工验收记录。
5. “查看接触检查”展示每段支撑期的原始和当前踝部位移，并可定位到角色时间轴。默认依据源标签或稳定区间尝试支撑修正；可能修正根骨和腿骨旋转，密集支点与网格检查通过才采用。部分区间修正不会隐藏未锁定异常。取消勾选“依据源标签或稳定区间尝试支撑修正”再构建，可得到未修正版。重试保留这个选择，旧候选仍可查看。
6. “比较该角色的已有视角候选”在当前卡片内检查同源动作、同一角色与策略的已有版本。推荐项需通过当前技术检查，且没有人工拒绝或过期验收证据；直接打开推荐的时间轴做阶段验收。没有合格项时会显示各项异常，不以失败较少替代通过。它尚不会替你批量构建全部视角。

## 选择视角与片段

选中源动作后，在源时间轴下方选择正面或侧面，点击“生成此视角版本”。新任务复用原始字节重新编译，保留旧视角、父任务身份和本机生成来源；不是修改当前角色的相机，也不自动解决转身遮挡。

“应用到角色”还提供恒定偏转角和“自动选择投影角度”。自动比较整段源动作的十三个角度，原视角合格则保留，否则选取最小的合格偏转；比较期间不能提交旧角度。所有角度不合格时保留异常。该建议只依据源骨段投影，构建后仍重新检查角色几何、接触和遮挡，不生成侧面或背面贴图。任务卡片可查看实际偏转及其来源依据。

“新动作默认自动选择合格投影”默认开启：选中新的已编译源动作即开始比较。手动修改偏转角会关闭自动选择，之后换源也保持手动模式，直到重新勾选。失败或无合格角度不会反复自动重试；可以使用比较按钮重新检查。自动选角不等于角色动作验收通过。

拖动源时间轴，点击“当前时间设为起点/终点”，或填写从 1 开始的起止帧。勾选片段后再构建角色候选；包含起止帧、至少两帧，源文件保持完整。新候选时间从 0 开始，但旋转和位移保持原动作相对绑定姿态的数值，不把片段起点重置为站立姿态。足部接触区间会与所选片段求交后同步移位。

投影缩短仅检查所选帧，但仍依赖原第 0 帧的有效绑定参考；原参考塌缩时不能用裁剪绕过。片段重新执行修正、几何和 Runtime 检查。几何检查对照原绑定网格，不能把片段首帧中已存在的翻转作为正常基准。官方 Runtime 额外捕获真实绑定姿态作源纹理对照，独立于动画第 0 帧。重试保留片段范围。

## 运行环境和限制

Windows 服务在动作工作进程开始执行前建立 Job Object 隔离。正常取消、服务关闭或服务被强制结束时，工作进程及其后代随之退出；无法建立隔离则任务失败，不启动生成。服务异常退出后，未写入最终结果的任务显示为“已中断”，可创建新任务重试；这会重新生成，不是从扩散过程检查点续算。旧请求和诊断保留。

BVH 可直接解析。FBX 通过已安装的 Blender 转换，启动服务前设置 `AUTOSPINE_BLENDER` 为本机 Blender 可执行文件，或把 Blender 放在 PATH。官方捕获复用当前工作区的 Runtime 环境；未配置时会显示不可用，不冒充已验证。

当前每文件上限 64 MiB，两项任务排队、一次执行一项。导入超时 240 秒，角色适配超时 900 秒；角色源轨道最多 768 个关键帧，合并密集采样上限 1,025。源骨架画布最多显示 240 个真实采样姿态，未展示的源帧仍进入编译。

正面为源局部 X/−Y，侧面为 −Z/−Y，需与素材骨架约定匹配。当前不会猜测任意骨架的坐标轴、自动推断循环或补造足部标签。接触检查使用源标签或符合条件的源稳定区间，推断结果单独标识。阈值为角色腿长的 1%；根骨修正幅度不超过腿长 15%，双脚残差不超过 1%，修正速度不超过每秒两倍腿长，并需修正后密集采样与网格检查通过。未获得支撑依据时保留未验证状态，部分区间通过不代表整段锁足。鞋底/地面碰撞和衣料次级运动尚未由此证明。

动态遮挡已有源深度、透明像素重叠与绘制顺序检查。混合服装、手臂跨越躯干前后或顺序冲突仍保留异常；“查看遮挡区域归属”可定位首个异常及实际驱动骨骼。局部网格深度仍是独立实验，不会自动修改当前候选。

投影或网格异常会显示具体原因，诊断时间轴可用于定位。Runtime 数值与非空画面通过不等于动作适用或视觉合格。历史卡片保留上次运行结果，打开/下载前重新核对角色来源。

NPZ 支持 `core-v1` / `complete-v1` 的 float32 / bool 数组及四或六通道足部标签。导入器检查固定 SOMA77 层级下的矩阵与位置一致性，保留原始 NPZ，并生成内容绑定的解释文件。帧率与骨架约定来自显式输入，不能仅从数组大小推断。SMPL-X、G1、旧 SOMA30 和含对象/pickle 的数组均不支持。源足部标签写入 MotionIR，但不代表目标脚已锁定。

外部 NPZ 没有随附的生成证据时，模型、seed 和生成环境记为未知，不冒充本机生成；历史已记录的来源包不受影响。数据格式依据 [Kimodo 官方输出说明](https://research.nvidia.com/labs/sil/projects/kimodo/docs/user_guide/output_formats.html)。

## 文字生成

在“用文字生成动作”输入英文单句、1–10 秒时长、种子和 10–100 步，点击“生成动作”。句点仅用于句尾，避免上游 CLI 将多个句子变成多个连续片段。完成后仍通过“查看源动作 → 应用到角色”生成独立候选。

服务端默认使用工作区 `kimodo-runtime`，可用 `AUTOSPINE_KIMODO_RUNTIME` 指定同结构安装目录；浏览器不能传入路径或命令。当前适配固定 `Kimodo-SOMA-RP-v1.1` 与已验证的本地 loader 修订 `c503c77`。CUDA 必须可用，文本编码器使用 CPU，禁用下载与生成器后处理。准备阶段完整验证已下载 ModelScope 基座，并在每个任务目录建立派生适配器，不依赖或修改共享派生目录。

生成任务上限 3,600 秒，显示模型校验、文本编码器校验、生成（含加载）、输出复查及 MotionIR 编译阶段。取消终止进程树；服务重启后的未完成任务显示中断，重试从头生成并创建新记录，不代表恢复扩散中间状态。原始 NPZ、请求、模型/适配器指纹与诊断均保留。即使参数相同，也不承诺跨设备逐字节一致。

生成成功只表示动作资产形成；应用到角色后仍执行几何和 Runtime 检查。动态遮挡、视角增强和三角色八动作验收见 [M4 后续交付](milestone-m4-external-motion.md)。
