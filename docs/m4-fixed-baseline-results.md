# M4 固定动作基线结果

固定三角色：Alice（普通衣装）、辉夜（宽袖长裙）、红美铃（无袖）；八类动作，24 个完整源动作与角色组合。原始文件与角色工件均在计划 v2 中冻结，未裁掉失败片段或替换样本。

全部 24 项已结束。23 项完成官方 Runtime 捕获，共 8,447 帧；1 项失败。11 项几何通过，6 项没有已记录的投影/变形/接触异常，17 项为诊断候选。未进行该矩阵的人工视觉验收，不能把这些数量称为可交付动作数量。

基线完成后，新请求的 Float32 存储参考已启用。辉夜原失败工件已通过工作台重新捕获 313 帧，几何与投影异常继续保留。这是独立补验证，原基线不覆盖；见 [实时策略验证](benchmark/m4-live-runtime-profile-v1.json)。
