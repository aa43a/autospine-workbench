# M4 重新分解：从可转换到可用动作

日期：2026-09-22。本文作为后续执行入口；历史实验和验收记录不改写。详细证据见 [当前实验进度](m4-next-objectives.md)、[动作保真计划](m4-motion-fidelity-plan.md) 和 [三角色回归](benchmark/m4-proximal-ring-cohort-v1.json)。

## 总目标

用户导入或生成动作后，系统自动完成适配、验证、播放和导出；可表达的动作默认生成候选，异常能定位到角色、部件和时间。先在 Alice、辉夜、红美铃完成 squat/reach 六组合，再回归固定八动作。阶段验收只要求检查异常，不恢复逐层确认。

“可播放”“数值一致”“形状合理”“视觉接受”分别记录。不可表达的姿态明确返回限制，不用静默减幅、删帧或换动作制造通过。

## M4.1：六组合动作可用性闭环（下一里程碑）

交付一个集中验收页面：动作选择、拖动时间轴、源动作与目标同步、异常定位、原方案/新方案对照、明确的支持结论。

### 切片 1：保护正常关节形状

- 在现有有界修正中增加可选的逐三角形面积保留下限，以修正前姿态及投影参考为依据；保持固定顶点、位移和边长约束。
- 首先复现并修复 Alice/红美铃已定位的膝部压缩，再检查脚踝和接触是否回归。
- 求解器与独立检查器使用一致的约束，检查关键帧及中间采样；保留旧门禁和失败说明。
- 若同一边界内无法满足约束，输出冲突区域，转入局部拓扑/关节形状方案，不无限加大位移预算。

完成条件：已定位的健康膝区不再因修正被推至统一最低面积；三角色脚踝稳定性、翻转、预算及纹理/骨架一致性无回归。数值改善之后仍需实际轮廓检查。

### 切片 2：屈膝方向与前后关系

- 使用源三维髋—膝—踝的弯曲平面与相机深度，区分投影缩短、朝前屈膝和错误反折。
- 将深度检查从现有手臂/躯干扩展到腿、裙装和鞋；使用具有稳定切换条件的区域遮挡策略。
- 简化三维骨架/体块只提供方向、体积与遮挡参考；当前不要求制作完整三维角色。

完成条件：三角色 squat 初始举臂、下蹲过程、脚面方向、膝部轮廓及裙腿遮挡可同步核对；不得以裙子遮住膝盖推定方向正确。

### 切片 3：伸手连续性与手部表达

- 明确固定视角、源初始姿态和角度连续性，保留源抬手时序；区分真实转圈与投影退化造成的跳变。
- 注册目标手部贴图与源手轴/掌面的关系；单轴缩放不承担完整掌面姿态表达。
- 优先复用可用附件。只有需要缺失的侧面/背面素材时才提出素材需求；缺图时保留原候选并标明区间与限制。
- 固定斜视作为显式版本化策略，不能只旋转肢体后声称全角色已完成侧身投影。

完成条件：三角色 reach 无无源依据的半圈突跳；问题手部有可检查的表达方案或准确的不可支持区间。标记不支持不能计为动作可用。

### 六组合验收口径

每项均需精确候选、同帧源/目标对照、连续播放、几何/接触/遮挡结果、实际 Runtime 捕获和导出。结果分为可用、带明确异常阶段可用、当前不支持。里程碑报告必须逐项列出，不能将六份报告等同六项通过；若仍有不支持项，记录部分交付并保留原目标。

## M4.2：接入默认工作流

依赖 M4.1 已验证策略。导入/生成 → 适配 → 修正 → 验证 → 播放/下载在动作中心完成。自动选择有证据的策略，保留版本和撤销；人工只处理异常与阶段验收。

进度显示当前阶段、已完成数、当前部件、失败原因和下一操作。诊断、修改与重建留在同一上下文。旧人工决定不能自动转移到变化后的动作候选。

完成条件：三个角色能从工作台重现新策略输出，无需命令行、手填路径或摘要；失败可恢复，不丢失原绑定与用户修改。breathing 已接受结果不回归。
