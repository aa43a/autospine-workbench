# 在验收页播放整角色动画

在工作台的整角色候选区点击“播放整角色 · 动作与时间轴”。候选必须已完成
Runtime 捕获且来源仍有效。旧候选也可使用，无须重新构建或重做已保存验收。

1. 从“动作”选择当前候选实际包含的动作。
2. 点击“播放 / 暂停”，按需选择 0.25×、0.5×、1×、2× 和循环。
3. 拖动时间轴定位到任意时刻；拖动会暂停，方便检查接缝和遮挡。
4. “回到起点”恢复动作起始姿态，“全屏预览”放大画面。

窗口底部保留原始捕获帧、Runtime 报告、源图对照链接。
新入口为同一任务 `view/player.html`；历史 `view/index.html` 及捕获清单不修改。

播放器使用当前机器上与该捕获报告包名、版本及 SHA 一致的官方 Runtime。
候选资源经一次来源和内容校验后作为快照加载；不允许任意路径读取。
反向拖动每次从 setup 重建状态，避免累计旧动作或 deform。
实时播放仅用于观察，不能自动产生验收、发布授权或新的捕获验证结论。

## 点击查看缺口或外露部件

展开播放器下方“部件与遮挡对照”，开启“点击检查归属”，再点击角色画布。
动作会暂停，结果显示当前时刻、画面像素透明度和命中的图层。
点击结果里的“在部件对照中选择”，可继续单独显示或隐藏该部件作比较。
检查时需恢复完整角色并关闭骨骼、三角形高亮，以免把辅助显示当作角色材质。

低透明度结果表示当前点的理想合成上限低于 8/255；有覆盖不代表该部件应该露出。
检查同时使用当前 framebuffer 与 Runtime 顶点、当前序列图集 UV 的双线性透明度采样。
若包含裁剪、非普通混合、非双线性过滤等不支持条件，会保留“无法判断”，不强行归因。
共享三角形边缘可能重复计数，因此理想合成值只是上限。
时间轴、动作或显示方式改变后，旧结果清除。检查不会写入验收或改动候选。
