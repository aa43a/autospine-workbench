# 保存动作异常处理草稿

在动作中心的角色候选卡片打开“检查可用范围与待处理项”，再打开“查看变形区域与处理方案”。选择异常三角形和时刻后，可定位播放画面并加载该位置的处理草稿。

选择局部变形修正、重新划分区域或补充姿态附件，填写说明并保存。刷新后重新加载可以恢复记录；选择“撤销此处处理草稿”并保存会追加撤销记录，保留历史。切换异常会切换草稿范围，未保存输入不会自动提交。

保存草稿只记录处理意图；点击相应构建按钮才执行独立候选任务，不改变原候选的阶段验收。入口覆盖几何定位报告当前展示的极值事件，未展示的失败仍在原报告中保留。

保存“局部变形修正”后，可另外点击“构建局部修正候选”。系统冻结当前草稿，重算这个附件整个动作的变形轨道，原动作骨骼、纹理、绑定与其他附件不变。新任务使用现有进度、取消和重试机制，结果是独立候选，原候选与验收不受影响。撤销草稿不会取消已提交任务；要停止运行需在任务卡片取消。

当前方法只处理单 default skin、单动作的加权 Mesh；固定单骨顶点，混合顶点位移不超过相关骨链最短段的 10%。该预算不保证一定修好。原采样点、新变形关键点及其中点进入几何检查，并重新检查 CPU 踝部支撑、执行官方 Runtime 捕获。遮挡和视觉需要重新验证，不能据此自动采用。重试仍从原候选和有效草稿构建，草稿已更新或撤销会拒绝。

### 最终腿姿态的自动策略

新保存的“局部变形修正”会根据当前候选自动选择策略，无需另选算法。只有来源明确使用绝对肢体投影、当前几何检查失败、实际正权重骨骼只来自同侧 thigh/calf/foot 链的附件，才选择最终腿姿态双参考修正。页面显示“构建最终腿姿态修正候选”；原始面积和投影面积约束同时保留。旧草稿与旧任务继续使用已冻结的原策略；希望采用新策略时需保存新修订。

新策略对原候选和修正候选使用相同时间点比较，保留已有检查时刻，并检查实际动画关键点之间的中点和四分之一点。连续处理其他部件时不会重复细分前序 QA 网格。采样仍不能证明连续时间或视觉通过。

若固定三角形已经无法满足两个面积约束，任务在求解前终止，不生成新候选。动作卡片的“查看固定区域限制”展示超限三角形数、采样次数和最多 24 个代表位置，并可在原候选定位。此时需要调整投影、绑定区域或姿态表达；重复同一求解无效，但这也不证明必须补图。原有“检查局部修复限制”仍可用于已完成候选。

最终腿姿态修正和裙腰跟随允许按不同部位串联：在新候选中重新定位异常、保存草稿，再修正另一条腿或裙装。每步核对精确父候选并保留前序修正历史；同一部位不能在该链中反复叠加。其他不支持的嵌套路线仍明确拒绝，不会改用普通重定向。

可先处理腿部几何，再处理裙腰跟随。接续时保留未变化的躯干投影来源；新裙腰草稿冻结独立采样策略，避免把此前的密集检查时刻全部烘焙为动画关键帧。历史检查点仍会参与最终 QA，未被删除或稀释；旧裙腰草稿继续按原策略执行。

记录绑定精确任务、候选、定位证据、附件、动作、三角形与时刻。旧页面保存冲突时须重新加载；不同候选或更新的证据不会自动沿用旧草稿。接口为同源 GET/POST `/api/motions/<job>/repair-draft`；与人工阶段验收记录独立。

## 裙腰随躯干投影跟随

在动作候选卡的“编辑衣料跟随、覆盖与前后关系”中选择裙装附件、动作和检查时刻，打开处理画布、加载处理草稿，再选择“裙腰随躯干投影跟随”。也可以从已有几何异常进入同一草稿。此路线无需先有几何失败或再次逐骨确认。

系统自动读取当前角色中已声明的裙装辅助链，核对当前网格、来源和躯干投影。没有裙装声明、躯干投影没有实际应用、骨链跨越其他部件或来源已变化时，会显示不适用原因。这里不允许手填骨链来绕开声明。

条件满足后，保存草稿并点击“构建裙腰跟随候选”。动作中心显示生成裙腰变形、检查整角色几何与接触、遮挡检查、官方 Runtime 检查等实际阶段。可使用同一任务队列的取消与重试。结果页比较相同采样时刻的几何与腰部材料点分离；腰部采样不可观测会明确保留，不能当作通过。

所选检查时间用于记录问题位置；修正作用于所选裙装的**整段动作**。只补偿其已声明骨链根部随躯干投影的位移，保留骨骼动画、权重、纹理、绘制顺序及其他附件的所有轨道。前后视角、腿部变形或透明接缝问题不会因此自动消失。生成结果是独立候选，需按原流程播放、阶段验收和导出。

当前入口作用于动作任务的候选；已经关联的离线改进候选拥有独立身份，不会暗中改用其基线执行修正。允许接续不同部位的最终腿姿态修正或裙腰跟随，不允许重复补偿同一部位。原候选和人工记录始终保留。

保存“补充姿态附件”草稿后，点击同页“下载姿态素材任务包”。ZIP 包含未经修改的原纹理、原图异常位置 SVG、变形后三角形 SVG、带精确候选及草稿身份的 request.json 和文件摘要。解压后保持文件在同一目录，以便 SVG 读取原纹理。

变形后三角形只是失败诊断，不是期望外观；是否需要补图仍需结合源动作与整体画面判断。输出包不会生成缺失的侧背面。撤销或更新该位置草稿后，旧修订下载接口拒绝继续导出；已经下载的文件仍是历史证据，不代表当前有效计划。

回交与继续处理：

1. 在同页“回交姿态素材”中选择任务包的 request.json，以及与原画布尺寸一致的 RGBA PNG，保存独立素材版本。
2. 查看已回交版本，加载区域映射，在原纹理上选择三角形并填写换图起止时间，保存映射。
3. 点击“构建区域换图候选”。起点启用新图，终点恢复原图；这是离散切换，需要检查切换瞬间。新候选保留原网格、权重及 deform，不能用换图消除网格翻转或投影错误。
4. 可以从已完成的局部修正、分区或其他部位换图候选继续此流程。必须在该候选重新选择异常、下载任务包和保存映射，不能复用父候选身份。新导出保留前序修正记录。
5. 同一插槽已有透明度动画、非默认混合或动态绘制顺序等不支持情况会明确失败，不会覆盖原动画。当前不支持反复嵌套局部求解；不同路线的连续处理也不代表质量已通过。

撤销草稿或映射会阻止再次执行该计划，但不会删除已经冻结的候选。可随时返回原任务播放或下载；新候选需要独立检查几何、遮挡和阶段视觉结果。
