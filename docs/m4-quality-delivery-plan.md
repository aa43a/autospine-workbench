## M4.1：六个困难动作案例的质量闭环

固定 Alice、辉夜、红美铃 × reach、squat。

| 顺序 | 切片 | 验收条件 |
| --- | --- | --- |
| A | 收尾 Reach 肩部候选 | 同时间对比修正前后，验证纹理轮廓、透明接缝、未修改部件；约束点接上但画面扭曲仍算失败。 |
| B | 统一投影和前后关系 | 源关节、视角、深度与弯曲平面使用相同坐标约定；源正侧视与角色同步显示；前后排序稳定，交叉部件必要时做最小分区。 |
| C | Reach 连续性 | 可靠区间保持方向和时序；退化区间利用深度与邻帧确定分支。消除非源动作引入的半圈突转，不以冻结、删帧或隐蔽限幅通过。真实绕转与角度换支分开处理。 |
| D | Squat 投影与变形分离 | 先确保膝盖向前、手臂轨迹及脚部支撑正确，再处理额外挤压。比较源投影参考与最终网格，区分正常透视缩短与异常形变。 |
| E | 六项统一验收 | 求解、网格和 Runtime 共用覆盖完整的检查时间清单；动作意图、连接、轮廓与遮挡共同通过，三项 breathing 无回归。 |

保留原 setup 门禁。若需要投影感知的形变评价，另建版本和证据，不以放宽旧阈值清除失败。变形按证据升级：局部 corrective → 保体积截面或辅助骨 → 最小分区或姿态附件。缺少侧背面、手掌等内容时报告补素材需求，不无限拉伸现有纹理。

六项均保留在分母，逐项标记完整支持、受限支持、需补素材或失败。目标是六项在明确范围内技术通过且阶段视觉可接受；仅完成分类不能宣布本里程碑完成。

## M4.2：自动适配与原地异常处理

只接入 M4.1 已验证策略。选动作后自动分析可投影性与素材能力、生成候选；异常定位到部件、时间和原因。

同一工作台提供源动作、当前角色、修改候选的同步播放器，以及动作选择、时间轴和异常跳转。提供视角、前后归属、局部弯曲及连接修正，支持重建和撤销。幅度变化显式记为风格化改编，原来源与人工决定保留。

验收：三个角色分别走通导入或生成 → 适配 → 异常定位 → 修改 → 重建 → 导出 → 恢复；播放、报告、下载对应同一候选。普通归属无需逐项确认，一次修复无需跳转多个实验报告。

## M4.3：冻结策略与泛化验收

先重验三角色八动作 24 项，再扩展固定十角色，不增加角色专属算法分支。

分别统计支持率、技术通过率、阶段接受率、人工干预次数与实测时间、自动耗时和 Runtime 失败率。错误自动采用率只使用真实抽查分母；默认采用不等于抽查正确。失败、不支持、缺素材项不从总数移除。

验收：固定集合具有统一策略、精确来源与候选、实际播放和导出证据；旧验收不无条件转移给新候选。

## 范围与执行规则

本轮使用 3D 深度、朝向和弯曲平面辅助 2D 表达。完整三维重建、全面三渲二、脸部参数化、头发次级运动和更深袖装模拟不进入当前关键路径。

每种新算法先验证失败帧，再跑整段和跨角色回归。连续两轮无实际改善，转向表达能力、拓扑或素材诊断，不持续盲调权重。

来源、投影、支撑、变形、遮挡、验证与 UI 保持模块化；新增生产文件尽量不超过 300 行，遵守 400 行硬限制。每切片交付可播放改善或改变下一决策的证据。

## Reach 同视角深度检查进展

肩部候选已补充 45° 源视角下的原生像素中心 alpha 重叠检查，三角色未测量数均为零。Alice、辉夜各有 242 个可见部件对采样，其中 82 个源关节深度跨面；红美铃有 363 个可见部件对采样，其中 164 个跨面。三个角色各有 119 个非跨面可见采样的源前后建议与 setup 顺序不同。这些是待解释的遮挡证据，不是已确认的视觉错误数量；同一时间的不同部件对分别计数。

将同一源动作错误地按 0° 而非 45° 计算深度，会分别改变 221、221、442 个部件对采样的前后或跨面判断。现有通用深度模块支持 yaw；本次新实验入口明确从姿态来源读取视角，未宣称正式工作台存在相同错误。

诊断见 docs/benchmark/m4-reach-shoulder-depth-v1.json；完整记录与区间定位页位于 ../tmp/m4-motion-center/reach-shoulder-depth-v1/index.html。定位链接支持角色和时间参数，保持双播放器同步。检查范围仅手臂与躯干，不覆盖裙腿、头发或完整 GPU 遮挡验收；本次不改绘制顺序、不自动采用候选。

下一步对跨面重叠使用已有局部骨段深度模型，先区分可解释区域和证据缺失的服装区域，再决定最小分区；整段透明接缝与视觉验收仍未完成。

局部模型对照已完成：基础骨段对全部 328 个跨面部件对采样均不能给出统一方向；改用已有躯干平面、手部观测和权重深度区间后，Alice 74/82 个采样具有统一前侧代理证据，余下 8 个位于 1.300–1.533 秒，缺失深度像素为零。红美铃 10/164 个采样具有统一后侧代理证据，余下 154 个仍有近面歧义，缺失深度也为零。辉夜 82/82 个仍待解释，累计 491,523 个跨帧重叠像素计数缺少代理深度。全部采样均实际测量，没有因预算跳过。

该比较没有更改任何绘制顺序。平面、截面和深度区间是模型假设，不是表面真值，不能把上述比例称为视觉通过率。摘要见 docs/benchmark/m4-reach-local-depth-v1.json；时间定位页见 ../tmp/m4-motion-center/reach-local-plane-v1/index.html。
