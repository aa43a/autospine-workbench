# 局部支持弧段与有序配对

本实验承接完整 alpha 曲线锚点。它选择有证据支持的局部弧段并检查配对顺序，不改变动画，不产生形状修正或生产权。

## 弧段规则

在每条曲线上收集原接缝样本的所有投影选项，按边索引分组。相邻支持边相距最多 4 条纹理边时，保留其间的完整曲线；超过则分开。闭合轮廓允许跨首尾，但不会沿长路径绕过整只鞋。歧义路径的两个端点永不相接。

4 是当前实验 profile 的纹理边间隔上限，不是世界空间容差，也不表示通用阈值已经校准。只有一个支持边或覆盖完整闭环的情况不会进入配对。新增中间边只提供几何路径，不冒充新增姿态或人工证据。

## 配对规则

输入使用重配工件中封存的 `alpha_seam_qa.after.relations`，即用于回归验算的原始对应集合。它不包含重配求解器的新 follower 替换；本报告评估的是如何从冻结原始证据建立连续参数配对，不是评价已重配动画的实际目标顺序。

保留每一条原始对应：能唯一归入一对局部弧段的进入分组，否则带 `arc_missing_or_ambiguous` 保留。对组内尖角选项，以 setup 世界空间的平方距离为代价，通过动态规划寻找源侧严格递增、目标侧单调的路径；分别检查目标正向与反向，并保留两个不同最优路径的代价差。

源侧排序由候选局部参数下界固定，不搜索跨样本重排序。无法保持该顺序时返回 `nonmonotone_correspondence`，不宣称不存在任何可能配对。少于三条对应的组保持 blocked。

目标侧允许平台，以显式保留多对一事实；`many_to_one_steps` 非零时要求后续处理，不能直接当成可逆参数映射。零次优代价差表示多解。所有成功组仍为 `candidate_requires_review`，距离代价和顺序可行不能证明语义或动态接缝正确。

## 使用与复现

从仓库根设置 `PYTHONPATH=src` 后：

```powershell
python -m autospine_workbench.benchmark.seam_arc_cli `
  --manifest docs/benchmark/manifest-frozen-v1.json --workspace .. `
  --source ../tmp/r2b-alpha-curves/alice-v1.json `
  --output ../tmp/r2b-seam-arcs/alice-v1.json `
  --html ../tmp/r2b-seam-arcs/alice/index.html
```

合同 `autospine.seam-arc-pairs/v1` 引用曲线工件。编译重放原来源链并核对曲线摘要；reader 再生成完整报告。语义 validator 检查原对应恰好被覆盖一次、弧段引用、路径单调性、代价与有限数。

复核页红线显示局部弧段，表格显示配对方向、多对一步数、次优代价差与阻塞原因。铃仙无对应关系不算通过。CLI 不导出新的 Spine 动画，本切片无需新增 Runtime 播放声明；此前同帧栅格证据保持原样。

下一步根据实际阻塞分布选择局部连续参数配对策略，再联合距离、切线和面积约束；求解器输出必须重跑冻结的原对应与同帧栅格检查。

三角色结果：105 条原对应全部保留。11 个弧段组中，6 组得到带平台的单调路径、3 组固定源序下非单调、2 组不足三条对应；另 1 条不能唯一归入支持弧段。没有形成可直接用于可逆形状参数映射的通过组。
