# M4 执行目标：具有明确支持范围的自动动作工作流

更新：2026-09-22。本文为唯一当前执行计划。[历史快照](m4-execution-history-2026-09-22.md)保留此前实验与证据，不再将各段“下一步”并行执行。

## 当前判断

基础链路 FBX/BVH/Kimodo → MotionIR → 整角色候选 → Runtime → 导出已建立。主要差距是大幅度动作的二维表达、可靠前后关系以及已验证策略的默认工作台接入。

- 历史三角色八类动作已有 24 个候选；当前明确接受的外部动作仍为三角色 breathing。旧整角色接受不自动转移到新动作。
- Reach 新躯干策略各有 817 时刻 Runtime 数值证据，尚未全段视觉接受；局部遮挡仍未解决。218 分区实验停止扩张。
- Squat 新实验的源帧骨架已保留举臂，但 Alice 肩部连接、红美铃膝部轮廓仍失败。辉夜裙子遮住腿不能证明腿形正确。
- 最新膝部定向覆盖满足几何覆盖检查，实际贴片形成突出折片，未采用。停止统一/定向覆盖及已失败插值路线的调参。
- 膝部弯曲平面诊断已接入集中播放器组件并用真实证据回放测试，只是观察能力，不能作为动作修复或新验收。
- [肩部接触圆域整段候选](benchmark/m4-squat-shoulder-region-sequence-v1.json)已在 Alice 完成 114 次源姿态求解、4,090 时刻接触/双肩几何检查与官方 Runtime 数值验证，原采样保留。分离减轻，但袖片仍变窄、拉长，腿部原有失败仍保留；尚未视觉接受或默认采用，下一步评估袖片轮廓与三角色迁移。
- [三维圆柱表面直接映射实验](benchmark/m4-squat-surface-proxy-v1.json)的两种表面朝向均新增大量翻转，已拒绝；不继续调半径。它未实现独立可见面选择、源轴向扭转或深度排序，不能据此否定完整三渲二。下一表达实验须先处理可见面和姿态连接，避免继续将立体表面直接混入原关节权重。

本次为代码与已有记录核对，未重新捕获动画，不给出缺乏依据的完成百分比。

## 总目标与三阶段

用户从工作台选择角色和外部动作，自动获得支持范围内的 Spine 4.3.26 动画；仅处理异常，可在同页调整、比较、撤销，并导出正在播放的确切版本。不能表达的动作明确显示部位、时间和原因。

| 阶段 | 交付 | 完成条件 |
| --- | --- | --- |
| M4.1 动作表达闭环（当前） | Alice、辉夜、红美铃 × Reach/Squat，共六案例；方向、弯曲、接触与遮挡的可播放改善 | 六案例在事先声明的范围内技术通过并阶段视觉接受；三个既有 breathing 不回归。受限、失败、缺素材项保留在分母，不能计作通过 |
| M4.2 默认自动化 | 导入/生成、策略选择、构建、验证、异常调整、重建、撤销、导出贯通工作台 | 三角色无需脚本、手填路径或摘要即可复现已验证策略；任务可恢复，人工修改保留；不重复逐层确认 |
| M4.3 固定集推广 | 冻结三角色八动作，再扩展十角色 | 24 项先全部有可复现结论；支持项具有对应候选的技术与视觉证据。再按相同策略跑十角色，公开受限与失败项 |

“六项均有诊断”不等于 M4.1 完成；阶段接受也不抹掉技术失败。若目标范围必须改变，明确记录范围变更，不以自动缩小动作冒充原动作通过。

## 本轮重拆：以实际画面为推进单位

本节优先于后文技术路线的排列顺序。当前进入 P0，随后依次执行 P1、P2、P3；每项完成后立即接入动作中心，不等待全部实验结束。

| 顺序 | 具体目标 | 可检查的交付与退出条件 |
| --- | --- | --- |
| P0 冻结六案例 | 明确三角色 × Reach/Squat 的源动作、相机、当前候选和失败区间 | 同页源正/侧视、目标骨架、贴图共用时间轴；按角色列出错误，不用诊断数量计进度；记录源右手与角色左右映射 |
| P1 Reach 连续抬臂 | 先解决源动作之外的半圈突跳，再解决手臂穿过身体时的前后关系 | 先在一个真实异常区间展示前后对比，再完成全段和三角色；保留抬臂时序。投影接近零长度时不得用不稳定角度直接驱动；局部遮挡未解决不能报全段通过 |
| P2 Squat 动作表达 | 保留骨盆下降、支撑脚、举臂及膝部前向弯曲的可读性 | 先检查红美铃外露膝关键姿态。用源弯曲平面和深度引导缩短、轮廓与遮挡；正面投影不可辨识时，提供明确标注的全角色斜视/风格化候选，不能只把膝点反向。画面改善后才扩展整段 |
| P3 肩部与材料形状 | 处理仍阻断上述动作的肩缝和袖片变窄 | 复用接触区域约束；形状保留最多补一次可行解起点实验。无可见改善则停止求解调参，给出局部姿态附件或素材需求；不扩展成新袖装专项 |
| P4 六案例验收与交付 | 把通过的策略变成可直接使用的工作流 | 六案例逐项记录技术、视觉、支持限制；三个 breathing 回归。支持策略默认应用，异常同页定位/改动/重建/撤销，下载与播放版本一致 |

下一切片明确为 **P0 + P1 的真实区间修复**：定位 Reach 的分支突变或投影退化区间，先验证发生在哪一层，再交付一个实际纹理播放改善。若现有新候选已无突跳，则直接处理该区间的遮挡问题，避免重复修复。只有报告或叠加线条不算完成。

本轮 Reach 已核对当前三角色没有源外半圈突跳。右肩整层排序产生 307 像素切换，46 个局部分区将同处变化降到 6 像素，但放大渲染仍有网格形状硬切边；两版均未采用。固定三角形排序路线停止加细，下一表达需连续可见性边界或姿态附件，先确认标准 Spine 导出可实现性。证据见 [局部边界检查](benchmark/m4-reach-shoulder-cut-review-v1.md)。

本轮补充证据：辉夜、红美铃的肩部接触规则各在双肩三个关键姿态找到可行解，共十二次；尚无这轮整段及视觉验收。Alice 的原边长形状目标首次六次求解均未满足全部约束，不能视为改善候选。相关实验代码仍未提交，不属于已交付默认能力。

## M4.1 技术路线与验证要求

### A. 收敛基线与表达选择

复用集中播放器，在同一时间显示源正侧视、目标骨架和最终贴图。给每个失败区间标明：运动方向问题、投影缩短、材料形变、遮挡不确定，或待核实的素材不足。来源深度不直接称为解剖学前向。

先取红美铃 Squat 的 0.966667、1.12 秒和 Alice 肩部失败姿态；Reach 从已有轨迹自动定位退化和遮挡切换区间。保留来源、候选、相机及检查时刻身份。

交付：当前页面能定位失败时刻并比较表达方案；同时交付一个真实关键姿态的纹理改善候选。仅增加诊断字段不算本切片全部完成。

### B. 以三维代理引导二维表达

优先复用源骨架，建立最小肢段体块与关节弯曲平面，提供投影轮廓、缩短量和深度顺序的参考。代理仅是近似，不是角色真实三维表面。

先验证红美铃外露膝部：比较保留原视角的姿态表达与明确标注的斜视/风格化表达；后者需全角色一致，不能只旋转腿。保留抬臂时序、骨盆下降与支撑脚。原图无法提供所需可见面时，输出具体部位、角度、时段与需要的姿态素材，不生成假定真值。

关键帧实际轮廓改善后，才烘焙整段并检查连续性、接触、网格和官方渲染，再迁移 Alice、辉夜。同一通用策略不可写入角色名或三角形编号特判。

### C. 肩部连接与 Reach 遮挡

肩部只允许一次有明确假设的接触区域实验，保留远端和原预算；无可见改善则转为局部姿态附件或明确素材需求，停止继续调固定点求解。

Reach 使用源朝向、相邻帧和深度保持旋转分支连续，区分数值角度换支与真实转圈。前后关系先按手臂/躯干的结构区处理，结合稳定切换区间；混合深度不能强行整层排序，也不恢复无限三角形分区路线。真实 360° 转动涉及前后面素材，角度展开不能单独解决。

交付：同页对照中没有源动作之外的半圈突跳；肩缝、手臂穿身和排序切换有可见改善。缺面或混合遮挡未解决时保持受限，不默认采用。

### D. 整段与三角色验收

关键帧通过后检查源帧、中点、策略切换及异常时刻，进行官方 Runtime 数值和实际画面验证。核对 setup 重建、翻转、边长/面积、接缝、脚滑、轮廓、绘制顺序、时间连续性及导出身份。

全段通过再进入工作台默认策略；失败保留原候选并给出异常入口。Spine 导出目标 4.3.26 与当前捕获 Runtime 4.3.13 分别记录。

## M4.2 产品交付要求

- 一个动作中心：角色/动作选择、共用时间轴、源目标对照、异常与重建在同一上下文。
- 策略选择区分忠实投影、风格化适配、姿态附件；显示选择依据及限制。
- 已验证普通决定按用户授权默认采用，保留修改和撤销；不伪造人工验收。
- 任务阶段、失败位置、恢复方式清晰；重新构建不丢失已保存归属与未解决异常。
- 播放、验收记录和下载指向同一确切候选。

## M4.3 测量口径

分别统计构建完成、技术通过、视觉接受、受限、需补素材、失败；人工干预次数、实测有效操作时间、自动耗时另列。旧证据复用与新捕获分开。自动采用准确率仅以实际抽查判断为分母，默认采用不等于抽查正确；未测量项保持未测量。

## 范围、止损与工程质量

当前暂停新增脸部/发型体系、完整三维角色重建和深度袖装精修。服装复用已完成能力，仅修阻断整角色动作的问题。Anime2.5DRig 类脸发能力作为后续独立里程碑，不挤占 M4 主线。

每次只推进一个主要视觉问题；每条实验路线最多两轮明确假设差异。无关键帧改善即停止，不增加捕获数量、不放宽门槛、不删除失败样本。已有失败的插值、弯曲带、统一/定向覆盖不重新立项。

实现沿现有 MotionIR、版本适配器和播放器扩展，模块按来源、投影、形变、遮挡、验证、UI 分工；遵守现有文件长度约束。阶段结果写独立证据记录，本文保持简洁，不再累计实验日志。
