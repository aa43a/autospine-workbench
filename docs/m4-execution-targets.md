# M4 下一阶段目标（2026-09-22）

总目标：从工作台选择角色和外部动作，自动输出支持范围内可用的 Spine 动画。正常项目默认处理，异常同页调整；播放、验收与导出对应同一版本。本文件替代此前逐次追加的“下一切片”。本次仅核对证据和规划，没有重跑动作验收。

## 当前判断

导入、重定向、播放和导出已有基础链路；主要缺口是大动作的二维表达。三角色原 Breathing 已有阶段接受，新 Reach/Squat 实验尚未接受。当前 Reach 采样未发现旧版半圈跳变，但肩部遮挡及轮廓仍失败。Squat 保留源举臂，外露膝前屈读向及肩片拉伸仍不合格。

旧凹 inverse 裁剪被 Runtime 凸包化，最多丢失 596 个不透明像素，禁止采用。显式前后普通裁剪在 241 个独立姿态中没有不透明像素丢失，但仍有过滤差异，尚不是连续动画。目标 Spine 4.3.26 与实际官方 Runtime 4.3.13 分别记录。

M4-B 随已验证能力逐项交付，不等待所有实验结束。M4-C 在对应动作关键画面通过后扩大捕获。受限方案可单独交付，但不能据此把原六案例目标标为完成。错误自动采用率只使用真实抽查，默认采用不充当正确性证据。

## M4-A 执行顺序

1. **Reach 连续遮挡：下一切片。** 先用 Alice 右臂生成真正连续、可播放、可导出的普通裁剪候选。优先试验固定拓扑的局部凸裁剪，在三角形内部连续移动深度边界，而非整块三角形瞬时切换前后。保留原纹理、UV、权重和动作；先验证裁剪数量、包体和播放成本。这是待验证假设，不是已有能力。
2. **Reach 整体核查与推广。** 检查完整手臂独立重构、整角色遮挡、区域出生/消失、边界切换、插值及任意拖动时间轴。要求没有新增不透明像素丢失、可见硬切或闪动；过滤误差独立解释和验证。不能依赖躯干遮盖或局部相机掩饰缺失。通过后覆盖其他交叠及另外两角色。
3. **Squat 前屈表达。** 以红美铃外露膝验证起始、最低点、起身关键姿态，利用三维弯曲平面、深度和投影缩短，保持骨盆下降、支撑脚及源举臂。不能只反转膝点或以裙子遮腿替代验证。原正面素材无法表达时，比较明确标注的斜视方案或局部姿态附件；缺素材就列出部位、角度和时段，不暗中缩小动作。关键姿态改善后再扩展整段及其余角色。
4. **必要关节与材料修复。** 仅处理阻断上述动作的肩缝、肘膝折叠、近端袖片拉伸和过滤问题。先区分投影、遮挡、权重及素材原因，再做局部修正或姿态附件。完整手臂、整角色画面和几何共同验收；不扩展袖装专项。
5. **六案例集中验收。** 源骨架/角色同步对照，提供动作选择、可拖动时间轴及带时间定位的异常。技术通过后进行阶段视觉验收；通过策略立即接入工作台默认构建与撤销流程。

## 工作台与泛化边界

工作台清晰展示：来源准备 → 动作适配 → 整角色生成 → Runtime 检查 → 阶段验收 → 导出，各阶段显示现状、失败原因与下一操作。默认处理记录策略来源，用户集中处理异常和阶段结果，不恢复逐层确认。

FBX/BVH 与 Kimodo 共用后续 MotionIR 链路；Kimodo 生成任务独立提供进度、取消、恢复和来源记录，不污染已验证候选。固定集保留精确来源、策略、候选、Runtime 版本和验收身份；复用证据明确标注，不称为重新捕获。

三维骨架提供深度和弯曲证据，不等于角色三维重建。完整三渲二、脸部/发型新体系、任意 360° 翻面及袖装深度精修暂缓。角度展开不能生成缺失的背面素材。

## 止损与工程质量

每个新假设先验证关键时刻，最多一次针对明确原因的修正；仍无实际画面改善就记录失败并切换表示或提出素材需求。停止失败的整层瞬时排序、固定三角形无限细分、膝部覆盖和圆柱直接映射的重复调参。新方案不得绕过凹 inverse 拒绝检查。

投影、可见性、材料、验证和 UI 分模块，生产文件保持 400 行以内。测试针对真实失败与合同边界；通过后不无理由重复扩大验证。保留原素材、历史候选和用户决定，继续在 work/integrated-arm-review 分支开发。
