执行顺序：

1. **Reach 遮挡收敛。** 先完成 Alice 右肩连续裁剪的真实画面验证，再覆盖其他交叠和两角色。保持源抬臂时序，不再重复角度展开或增加固定三角形分区。
2. **Squat 关键姿态表达。** 先用红美铃外露膝验证前屈读向，保留骨盆下降、支撑脚和举臂；关键姿态画面改善后再扩展整段。辉夜裙子遮腿不能替代膝部验证。
3. **必要材料修复。** 仅处理阻断上述动作的肩缝、袖片拉伸；数值接触与自然轮廓必须同时成立。无改善则转局部姿态附件/补素材，不扩展袖装专项。
4. **每项通过立即接入。** M4-B 的界面和默认策略随可用能力逐项交付，不等待所有实验结束；最后进行六案例整体验收。

下一切片明确为：凹 inverse 裁剪已因 Runtime 凸包化而被拒绝。显式前后普通裁剪在 241 个独立姿态中不再丢失不透明像素，但尚无连续时间轴。先处理后方区域的出生/消失及拓扑切换，形成标准 Spine 可表达的连续候选；分片过滤误差独立保留。

技术决策：采用三维骨架深度和弯曲平面作为二维缩短/遮挡的辅助，不把近似圆柱当作角色真实表面。原视角无法表达时，提供明确标注的全角色斜视或风格化方案；缺少新可见面时指出部位、角度、时段并请求姿态素材，不能只反转膝点或暗中缩小动作。

止损：连续裁剪若仍闪动/硬切，只允许一次针对已定位原因的修正；仍失败则结束该路线。停止整层瞬时排序、固定三角形无限细分、失败膝部覆盖和圆柱直接映射的重复调参。每个新假设最多两轮；关键帧没有真实画面改善，不扩大采样与捕获规模。

暂缓：完整三维重建、脸部/发型新体系、任意 360° 翻面与袖装深度精修。真实翻面需要可见面素材，角度连续性不能单独解决。模块继续按投影、可见性、材料、验证、UI 拆分，遵守生产文件 400 行上限。
