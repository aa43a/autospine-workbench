## 当前判断

导入、重定向、播放和导出已有基础链路；主要缺口是大动作的二维表达。三角色原 Breathing 已有阶段接受，新 Reach/Squat 实验尚未接受。当前 Reach 采样未发现旧版半圈跳变，但肩部遮挡及轮廓仍失败。Squat 保留源举臂，外露膝前屈读向及肩片拉伸仍不合格。

旧凹 inverse 裁剪被 Runtime 凸包化，最多丢失 596 个不透明像素，禁止采用。新的固定四顶点普通裁剪已生成连续动画：Alice 完整隔离手臂在 481 个采样时刻没有不透明像素丢失，但组合手臂需要 478 个槽位，材料过滤仍有差异，肩部外观未接受。纯裁剪版本 scene 压缩至约 31.5 MB 不等于达到产品性能目标。目标 Spine 4.3.26 与实际官方 Runtime 4.3.13 分别记录。

独立深度重放是代理模型的一致性检查，不是真实表面的证明；当前 Alice 检查明确不覆盖近端材料覆盖策略。辉夜存在辅助骨骼深度未知项，不能默认解释为躯干后方。最新诊断工具尚在开发，不提升候选状态。

## 本次重新分解：先收敛表达，再交付默认流程

下一里程碑定义为：**受限但可用的外部动作自动交付**。用户选择角色和动作后，得到可播放、可导出的完整角色；系统说明原动作支持、适配候选或需要补充素材，并在同页定位异常。不能以“能播放”宣称大动作表达正确，也不要求无限逼近单张正面图无法提供的背面外观。

| 交付项 | 实际产物 | 验收条件 |
| --- | --- | --- |
| A1 表达诊断与路线选择 | 时间轴上的旋转突跳、投影退化、前后交叠、屈肢读向、材料不足和深度未知定位；原动作/适配方案对照 | Reach/Squat 已知失败能定位到部位和时段；未知保留未知；无静默裁幅、改速或改朝向 |
| A2 Reach 深度与连续性 | 原始时序、近退化方向连续处理、前后分区及必要近端材料；完整角色同步播放 | 三角色关键时刻先过关，再测整段；无半圈突跳、新增不透明缺失或可见硬切；肩部连接阶段接受 |
| A3 Squat 空间表达 | 保留源举臂、骨盆下降与支撑；比较源正面投影、明确标注的斜视适配和必要姿态附件 | 红美铃外露膝在起始、最低、起身有正确可读的前屈方向；无脚滑新增；随后覆盖其余角色 |
| B1 产品收敛 | 工作台选择来源、构建、同步播放、异常修改、重建和导出；支持范围及进度可见 | 成功路线无需脚本或手填 SHA；修改和失败跨重建保留；导出与验收为同一候选 |
| C1 固定集验收 | 六重点案例及三原 Breathing 回归，然后固定三角色八类动作 | 技术和视觉分别计数；受限/缺素材保留分母；未接受实验不替换默认结果 |

执行次序：A1 与 Reach 现有实验收口 → A3 关键姿态 → A2/A3 三结构整段 → B1 完整操作验收 → C1 扩展。已通过能力随时接入 B1，不等待全部大动作完成。

### 成本与停止条件

- 478 槽位的单臂版本保留为正确性参考，不直接作为默认产品方案。先在指定浏览器、设备及完整角色上记录构建时间、包体、首帧、播放帧耗时和拖动延迟，再冻结产品预算；当前这些性能指标未测齐，不填写虚构门槛或通过率。
- 近似裁剪合并已有两次失败，停止该路线继续调参。浮点存储压缩保持行为的验证可以沿用，不能用包体改善代替播放性能。
- 每种表示先验关键姿态，最多一次有明确原因的修正；仍失败则换表示或列素材缺口。正面深度退化时，连续角度不能恢复缺失形体；360° 数值展开也不能生成背面素材。
- Kimodo 是动作来源，不能替代二维表达修复。继续复用 MotionIR；本里程碑不扩展新的生成模型、完整三渲二重建、脸部/发型系统或袖装精修。
- 适配动作与原动作分别记录。若只能受限交付，明确标为部分完成，不把原 M4-A 六案例目标改名后宣布达成。

## M4-A 执行顺序

1. **Reach 连续遮挡：实验收口。** Alice 固定四顶点普通裁剪已完成连续候选与 481 时刻捕获。下一步核对深度插值、其他结构关键姿态及性能，保留原纹理、UV、权重和动作；不重复开发已完成的裁剪能力，不将高槽位参考方案直接默认采用。
2. **Reach 整体核查与推广。** 检查完整手臂独立重构、整角色遮挡、区域出生/消失、边界切换、插值及任意拖动时间轴。要求没有新增不透明像素丢失、可见硬切或闪动；过滤误差独立解释和验证。不能依赖躯干遮盖或局部相机掩饰缺失。通过后覆盖其他交叠及另外两角色。
3. **Squat 前屈表达。** 以红美铃外露膝验证起始、最低点、起身关键姿态，利用三维弯曲平面、深度和投影缩短，保持骨盆下降、支撑脚及源举臂。不能只反转膝点或以裙子遮腿替代验证。原正面素材无法表达时，比较明确标注的斜视方案或局部姿态附件；缺素材就列出部位、角度和时段，不暗中缩小动作。关键姿态改善后再扩展整段及其余角色。
4. **必要关节与材料修复。** 仅处理阻断上述动作的肩缝、肘膝折叠、近端袖片拉伸和过滤问题。先区分投影、遮挡、权重及素材原因，再做局部修正或姿态附件。完整手臂、整角色画面和几何共同验收；不扩展袖装专项。
5. **六案例集中验收。** 源骨架/角色同步对照，提供动作选择、可拖动时间轴及带时间定位的异常。技术通过后进行阶段视觉验收；通过策略立即接入工作台默认构建与撤销流程。

## 工作台与泛化边界

工作台清晰展示：来源准备 → 动作适配 → 整角色生成 → Runtime 检查 → 阶段验收 → 导出，各阶段显示现状、失败原因与下一操作。默认处理记录策略来源，用户集中处理异常和阶段结果，不恢复逐层确认。

FBX/BVH 与 Kimodo 共用后续 MotionIR 链路；Kimodo 生成任务独立提供进度、取消、恢复和来源记录，不污染已验证候选。固定集保留精确来源、策略、候选、Runtime 版本和验收身份；复用证据明确标注，不称为重新捕获。

三维骨架提供深度和弯曲证据，不等于角色三维重建。完整三渲二、脸部/发型新体系、任意 360° 翻面及袖装深度精修暂缓。角度展开不能生成缺失的背面素材。

## 止损与工程质量

每个新假设先验证关键时刻，最多一次针对明确原因的修正；仍无实际画面改善就记录失败并切换表示或提出素材需求。停止失败的整层瞬时排序、固定三角形无限细分、膝部覆盖和圆柱直接映射的重复调参。新方案不得绕过凹 inverse 拒绝检查。

投影、可见性、材料、验证和 UI 分模块，生产文件保持 400 行以内。测试针对真实失败与合同边界；通过后不无理由重复扩大验证。保留原素材、历史候选和用户决定，继续在 work/integrated-arm-review 分支开发。
