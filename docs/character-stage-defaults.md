# 阶段默认采用与异常复核

2026-09-15：按用户确认，将常规确认逐步改为系统默认采用，用户在阶段验收调整异常。

本切片接通整角色输出后的加权绑定：新构建经过 Runtime 几何检查后，对于覆盖完整、实际骨骼映射符合支持规则的区域，记录 `policy_auto` 决定。支持同侧手臂、腿鞋、现有袖装辅助骨、裙装辅助链及随头部的头饰区域。未支持的映射、残余区域和验证失败仍进入异常复核。

默认记录保存在任务的 `stage-defaults.json`，绑定项目、任务、输出、Runtime、图层和实际权重清单内容地址。它不修改源素材、旧人工记录或权重，也不代表人工确认、视觉通过或发布授权。旧任务不补写默认记录；下一次构建应用新策略。

用户可以在区域绑定中撤销默认采用。重建时保守保留该项目历史撤销涉及的图层，由明确人工确认解除当前候选的阻塞；不会重建后悄悄恢复默认。来源变化后重新计算策略，禁止沿用旧地址。

整角色视觉验收继续独立记录。策略准确率尚未测量，不能把默认采用计入人工真值或声称达到 98%。

保存关节复核后，工作台现在自动准备缺失绑定选项，并执行现有安全绑定规则直到没有可采用项；返回最新输入版本和采用数量。未完成关节复核不启动该步骤。后续自动绑定失败会单独报告，已保存的关节记录保留。

撤销简单绑定会在该条记录保留“用户撤销自动采用，保留人工复核。”备注。现有策略保留带备注的记录，因此后续保存不会立即重新采用。用户可明确修改该条绑定；清除备注会重新允许规则评估。

没有手动路线记录时，两侧已复核窄轮廓手臂可默认普通路线；双侧合层、仅因左右侧无法分类时，可先进入普通候选流程。这是可修改的路线默认，不是高置信度绑定采用，也不推断“无袖”。明确袖装、宽轮廓、其他证据缺失仍保留路线异常。已有选择（包括“稍后决定”）、过期人工选择和失败袖装修复不会被默认覆盖。

默认路线合同为 `project-route-default/v1`，从当前来源和几何证据确定性派生；整角色链绑定其内容地址。界面区分系统默认与已保存选择，选择“稍后决定”即可退出自动路线。

来源准备和低透明度残余处理仍待按同一约定接通；对缺少依据的跨部件归属保留异常。尚未达到完全仅异常复核。
