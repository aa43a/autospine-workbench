# 实时袖装标注

`tools/build-sleeve-regions.py` 生成的区域复核页支持并排编辑与动画：左侧始终在 setup 坐标中涂选，右侧按当前时间即时重新计算草稿权重和 FK 贴图。可拖动时间轴、播放/暂停、切换前臂/手/垂布及组合动作，并对比初始草稿。撤销、载入草稿和自动预填也会刷新动画。

修改后使用“下载草稿”保存；页面不会改写源文件或采用最终结果。旧的三参数 renderer 调用仍可生成纯标注页。

试算对一致归属的袖布移除手骨影响，对垂布增加腕部根节点的运动；混合边界和不确定区域保留基础权重。“手部刚性试算”是显式可选实验，不是默认采用策略。袖口求解、碰撞、离线局部修正和官方 Runtime 验证仍在后续管线执行；Canvas 三角形采样不作为接缝 QA 证据。

验证：Web 486 项通过，区域合同和工程质量各 3 项通过。灵梦已标注的 1176 个三角形生成实页，在 Chrome 检查手部三角形改为袖布后当前帧改变、撤销后画面恢复、播放推进时间及区域切换，无脚本错误。历史正式资产和用户原始草稿保持不变。
