# 有界连续接缝参数

本实验在已选定的局部目标弧段上求连续参数，处理离散配对的平台和回跳。它不修改动画，也不等同于接缝形状求解。

## 数学与预算

使用冻结原对应的目标投影参数为参考；尖角多选项取弧长参数均值作为拟合参考，明确属于算法构造，不是新观测。保持上一切片的源样本顺序，分别检查正向和反向目标参数。

目标为最小化 `sum((t_i - reference_i)^2)`。相邻有向参数至少相差 0.1 条纹理边，每个参数最多偏移 2 条边，且必须处于原局部弧段内。将最小间距移入变量后，使用带逐项上下界的 pool-adjacent-violators 解有界保序回归；不重新排列或删除样本。

选取代价较小的可行方向，保留方向代价差。这里的代价衡量参考参数改动，不是世界空间距离、切线或面积能量。0.1 和 2 是此实验 profile 的固定限制，并非已校准的通用生产参数。

连续参数在像素单元边上插值，再嵌入 UV 三角形。任何锚点不能嵌入、或距原目标像素中心的 setup 世界位移超过 2 px，都不能作为可行方向。所有方向都失败则保持 blocked；不扩大预算重试。

参数单调不意味着连续形状映射已经可用：源侧仍是固定样本顺序，尚未构建完整驱动曲线和目标曲线间的形状约束，也没有证明动态网格面积或空白改善。

## 入口与证据

设置 `PYTHONPATH=src` 后，从仓库根运行：

```powershell
python -m autospine_workbench.benchmark.continuous_parameter_cli `
  --manifest docs/benchmark/manifest-frozen-v1.json --workspace .. `
  --source ../tmp/r2b-seam-arcs/alice-v1.json `
  --output ../tmp/r2b-continuous-parameters/alice-v1.json `
  --html ../tmp/r2b-continuous-parameters/alice/index.html
```

`autospine.continuous-seam-parameters/v1` 引用局部弧段工件，编译重放其来源链，reader 重建内容地址。语义 validator 检查严格参数顺序、预算、有限重心权重以及每条原对应恰好保留一次。

页面橙色显示参考参数，蓝色显示拟合参数。无对应角色不计为通过。状态仍为 `needs_review`，无生产权，不导出新 Spine 动画；此前原对应和同帧栅格验算口径保持冻结。

下一步将可行连续锚点接入局部 corrective 约束，结合切线和网格面积保护进行 Bake，再跑原对应、同帧栅格和官方 Runtime 对照。预算内无解的组单独保留，不以候选子集通过宣称整条接缝通过。

## 本次三角色结果

9 个组、100 条原对应得到严格单调参数；Alice 最大 setup 世界位移 1.030 px，琪露诺 0.707 px。2 个不足三条对应的组和 1 条未分组对应共 5 条仍保留。105 条原对应均可追溯，未删除。铃仙无接缝关系。

此处“不满足预算”只表示两个方向各自的参数最优解没有通过后置嵌入／世界位移检查，不证明所有带世界空间约束的非线性解都不存在。
