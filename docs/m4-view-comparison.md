# 自动比较源投影视角

动作中心的已编译源任务提供“自动比较投影视角”。对同一份已验证的源数据，按工作台的正面与侧面坐标约定检查完整动作的八条四肢骨段；使用既有 20% 可见长度与相对首帧 0.5–1.5 倍门槛，不改变阈值。

当前视角合格就保留。只有替代视角完整合格时，才提供“生成建议视角版本”；服务器重新计算并核对比较摘要后，复用重投影任务保存独立版本，记录选择策略和证据身份。两个视角都不合格时不自动选择分数较高的失败结果。手动选择视角的原有入口仍可使用。

八个固定真实源动作的结果见 [比较证据](benchmark/m4-view-comparison-v1.json)：

| 动作 | 建议 | 源投影结论 |
|---|---|---|
| 呼吸待机 | 保留正面 | 两个视角均通过 |
| 行走 | 侧面 | 正面 3 个骨段不合格 |
| 抬臂 | 侧面 | 正面 1 个骨段不合格 |
| 转体 | 无 | 正面 5 个、侧面 6 个骨段不合格 |
| 下蹲 | 侧面 | 正面 2 个骨段不合格 |
| 拳击 | 无 | 正面 2 个、侧面 1 个骨段不合格 |
| 伸手 | 侧面 | 正面 2 个骨段不合格 |
| Kimodo 挥手 | 保留正面 | 侧面 1 个骨段不合格 |

这是源动作离散采样的投影判定，不是角色动作验收。侧面投影不会生成角色的侧面或背面贴图，也不保证裙装、袖装及手臂遮挡正确。必须另建角色候选检查几何、支撑与遮挡。原三角色×八类动作正面固定回归继续保留，不用这些建议替换失败组合。

接口为 `GET /api/motions/{job}/compare-views`。新服务通过 `view_comparison_available` 声明页面入口可用。部署时等待当前捕获结束后的安全维护间隙，不中断回归任务。
