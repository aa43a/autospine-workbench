## 最近里程碑：M4-A，两个问题动作的整角色保真闭环

固定 Alice、辉夜、红美铃 × squat、reach，共六组合；不扩大角色或动作范围。

1. **统一诊断入口**：同一时间轴对照来源正面/侧面骨架、目标骨架和真实贴图；标出原始举臂、投影退化、接触及遮挡异常，保留旧版对照。
2. **完整姿态适配**：保留源初始姿态；结合关节点位置、骨长、三维屈肢平面和时间连续性。先将实验投影接入完整候选构建，再重算接触与深度，避免孤立修网格。
3. **退化区间处理**：对朝向镜头的肢体区分方向不稳定与真实旋转；允许固定斜视或明确标记的表现性近似。不能只靠角度展开、压小幅度或删帧。
4. **联合约束**：下蹲按来源接触阶段稳定脚部；膝盖朝前、手臂抬起与遮挡必须能从源三维信息解释。接触修正后重新检查姿态、网格与深度，不能互相破坏。
5. **六组合验收**：动作发生顺序与来源一致，无无依据的突然半圈旋转；支持范围内采样无网格翻转、脚部无明显漂移，部件连接与前后关系可接受；关键帧和插值区间均检查，保留实际渲染和阶段反馈。

出口：六组合逐项给出“支持／带异常阶段可用／当前不支持”，明确原因。若仍有组合不支持，不能宣布六组合保真完成；可交付受限范围并继续保留未完成项。数值检查不得自动代替视觉接受。

## M4-B：大幅度动作的形状与可表达范围

在 M4-A 姿态稳定后推进肘膝轮廓、局部 corrective、前后遮挡和附件切换。
优先使用轻量三维代理提供深度、投影缩短和屈肢平面；不将完整三维建模或卡通着色列为前置条件。
单张正面纹理不能提供掌背、背面和被遮挡细节；需要时明确提出替代附件或支持限制。
宽袖沿用现有方案，仅处理阻碍整角色闭环的回归。

出口：扩展固定三角色 × 八类动作，逐项记录形状、接触、遮挡和 Runtime 结果；已接受低幅度动作无回归。不能把不支持的大角度动作标为成功。

## M4-C：默认自动工作流交付

通过验证的适配策略以独立版本接入工作台：导入/生成 → 自动适配 → 完整角色预览 → 异常调整 → 重建 → 导出。
默认处理有证据的事项，阶段验收集中查看异常；同页选择动作、拖动时间轴、定位问题并撤销调整。
每个输出保存源动作、投影视角、算法版本、候选身份和支持范围。记录自动耗时、实际人工操作时间和失败类型，缺失测量不补造。

出口：三角色 × 八动作都有可复现输出或明确阻塞，播放和导出内容一致；默认策略不会覆盖历史人工决定，也不会冒充人工验收。

## 本轮直接开发任务与边界

下一切片先完成可选绝对姿态适配与原完整构建链的集成测试，并生成红美铃 squat 的接触/深度联合候选；确认不会破坏已通过部分后再扩展六组合。
motion_target_pose.py 与 motion_target_worker.py 的集成按下述实测结果评估；实验入口不代表默认策略已经启用。
姿态拟合、接触、遮挡、局部修正及报告保持独立模块；每次提交含相关回归证据。
暂缓新增模型、脸部发型系统和更多独立袖装实验，直至两个问题动作的主要错误得到解释和控制。

### 完整链首次实测

可选适配已接入完整构建函数并通过 25 项原流程回归及 11 项相关测试，尚未启用工作台默认策略。
红美铃 squat 的独立候选完成 623 帧官方 Runtime 数值检查，采样翻转为零；但双脚漂移仍为 68.74/86.11 像素，约 0.722 秒的联合接触求解无法满足端点残差约束，另有四处深度跨越失败采样。
截图仍显示膝盖不自然折叠和双脚抬离，候选不采用。见 [完整链证据](benchmark/m4-full-source-pose-v1.json)。
下一步从“方向与轴向长度拟合”推进到“关节位置、人体比例、源屈肢平面与接触联合求解”；现有面积修正不能替代这一步。

### 固定屈肢方向的接触可行性

新增独立实验求解器，在保留两段腿的投影方向和弯曲符号的条件下，联合求公共根位移与每条腿统一长度补偿。实验边界显式为根位移不超过参考腿长 15%、长度补偿不超过 15%，不是对默认策略的放宽。
同一红美铃候选的 623 个采样姿态中，235 个仍无法达到参考腿长 1% 的端点残差门槛，最大残差 14.799 px，长度因子范围 0.9871–1.15。
逐帧可行也不证明跨帧连续或网格质量，因此本实验未写入动画；结果位于 tmp/m4-source-pose/squat-fixed-bend-feasibility-v1.json。
这说明仅添加有限腿长补偿不足以解决当前接触问题；后续需要联合髋部位置与目标人体比例标定，不继续单独放大腿长预算。

### 髋部旋转中心校准

源根关节 Hips 与目标脚下 root 的旋转中心不同。新增独立策略使用源左右髋中心的位移，校准目标髋中心轨迹，保留骨架与原旋转。默认构建不变。
红美铃 squat 中原髋中心偏差峰值 74.73 px，校准后源采样点数值误差小于 1e-9 px；双脚漂移降至 44.98/13.78 px，623 帧官方 Runtime 数值检查通过。
接触求解现可生成完整有界时间轨，但原几何门禁仍拒绝。精确重放该未采用方案，623 采样姿态无翻转，投影面积参考仍有 40 条失败，不能解释为仅旧面积阈值误报。
见 [髋部补偿证据](benchmark/m4-hip-center-v1.json)。下一步对接触后的姿态重算局部变形，随后重验接触、深度与 Runtime；不能沿用接触前的局部修正当作完整验证。

### 接触后重新求解局部变形

已精确重放未采用的接触提案，仅移除该动作已有自动修正的完整 deform 清单，并在接触后的骨骼时间轨上重新求解。源纹理、骨架与提案骨骼时间轨均保持不变；遇到其他 deform 清单会拒绝覆盖。
红美铃 squat 的 623 个采样姿态脚踝最大漂移 1.1123 px、无翻转、投影面积参考失败 0，官方 Runtime 数值检查通过。原几何门禁保持未通过，未将投影参考替代旧门禁。
按新姿态重查手臂/躯干深度仍需复核，该检查不覆盖膝盖和裙腿。实际截图仍有膝部折叠轮廓与鞋子朝向问题，不能把脚踝稳定说成脚掌站稳，候选未采用。
见 [联合验证证据](benchmark/m4-post-contact-repair-v1.json)。下一步核对源脚面朝向、目标脚面运动与屈膝轮廓/深度，再扩展三角色回归。

### 源脚面朝向

源 squat 左/右脚三维朝向最大变化仅约 0.000068°/0.0852°，目标鞋子却一直继承小腿旋转。独立 BVH 脚面适配现从明确映射的脚关节读取相对旋转，在相机平面内拟合；通过旋转、缩放和 shear 时间轨抵消父骨仿射畸变，保留脚踝位置与 setup 结构。投影不可辨识时拒绝，不猜测脚背素材；尚未接入 Kimodo 脚面适配。
38 项相关回归测试及 843 帧官方 Runtime 数值检查通过，截图鞋子朝向改善。但 layer-003 有 160 次翻转累计，投影面积参考有 289 条失败，脚踝连接区出现回归，候选不采用。采样网格不同，不能把累计次数与此前候选直接比较成错误率。
见 [脚面适配证据](benchmark/m4-foot-orientation-v1.json)。下一步定位脚踝过渡的混合权重与局部网格约束，保留源脚面方向，不能通过重新让鞋子随小腿翻转来消除问题。

### 脚踝近端过渡带

定位确认翻转发生在 layer-003 的角色右脚踝（画面左侧），不是角色左脚踝。原 6 个混合权重点未找到满足约束的局部解；新增通用规则仅允许邻接混合区、距离脚踝较近的近端单骨顶点参与 deform，保留远端单骨顶点、原权重和原位移预算。
规则按直接父子骨链、拓扑邻接和局部边长确定范围，不硬编码角色、图层或三角形编号。本例每侧增加 3 个近端过渡点；未改变鞋子朝向拟合。
完整 623 帧检查无翻转、投影面积参考失败 0、脚踝最大漂移 1.1123 px，官方 Runtime 数值通过。膝部轮廓、局部透明缺口与深度问题仍在，原几何门禁不改，未自动采用。见 [过渡带联合证据](benchmark/m4-ankle-collar-v1.json)。
下一步优先扩大到其他结构角色，验证规则泛化，再联合处理轮廓与 alpha/深度问题；不把单角色采样通过当作 M4 完成。

### reach 固定视角可辨识性检查

对同一已验证来源的八段肢体检查固定 yaw=-30/-15/0/15/30 度。正视右前臂最小投影长度比 0.03954，20 个源采样低于 0.2，最大相邻采样方向变化 31.685°；+15 度时最小比值 0.22048、最大步进 6.210°，八段肢体均无低于 0.2 的源采样。+30 度进一步改善，但意味着更大视角变化。-15 度会令右上臂出现 35 个低可辨识采样，不能只优化前臂。

证据：tmp/m4-source-pose/reach-view-diagnostics-v1.json，绑定原来源身份。这里只检查源方向，不证明目标贴图、深度、接触或插值表现。下一步优先验证整段固定 +15 度的完整姿态候选；禁止逐帧切换视角来隐藏异常。

局部修正新增可选进度回调，报告几何采样、图层、求解采样时间和细化轮次；默认输出身份保持不变。当前已运行任务不会被强制重启，后续运行使用此进度入口。

### Alice 翻转定位

精确候选定位到 0.866667 秒、layer-001-r 的脚踝区域（calf_r/foot_r），不是膝部。四块翻转三角形为 286、288、295、297；286/288 在修正前面积比均约 0.7183，修正后约 -0.4866，是正常近端区域被拖动后的新增翻转。295/297 在修正前已翻转（约 -0.5505/-0.5462）。共享近端顶点 180 移动约 10.73 px，仍在 14.87 px 预算内；其相邻固定顶点未移动。这证明仅限制位移预算不足以保证邻域质量。

局部求解器报告 no_feasible_patch_found，这不是数学上不可行的证明，也不能通过进一步随意放宽预算解决。下一步需要联合限制正常邻域的有符号面积，检查固定边界与混合区的可行性；保留来源脚面朝向和已稳定的脚踝接触。定位文件 tmp/m4-source-pose/alice-collar-failure-v2.json 记录精确候选摘要、世界坐标、权重和修正前后面积，不修改候选。

### reach 固定 +15 度肢体实验

独立投影入口支持固定 yaw 并记录身份；源方向图随同一视角转换，明确躯干和原贴图未整体重投影。9 项相关测试通过。红美铃候选 `b2d152de19cd5ac786ef2b97d52bf3c890e5d313f5530b4b5d189b3af8401c9b`（tmp/m4-source-pose/reach-yaw15-temporal-v1）完成 481 帧官方 Runtime 数值验证，采样翻转 0、投影面积失败 0。原几何仍失败，最小面积比约 0.1224；接触和深度尚未重接。

实际第 288 张采样对应的捕获画面中，右手仍明显压缩、弯折，不能作为自然伸手接受。固定斜视减少方向退化，但手部朝向、轮廓及躯干一致性仍缺失。下一步检查源手关节朝向与目标 hand 骨骼的世界姿态，避免仅适配 upperarm/forearm 后让手部继续继承不合适的父级仿射变形；不将采样几何通过替代视觉判断。
