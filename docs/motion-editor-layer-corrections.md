# 动作编辑中的图层校正

入口：http://127.0.0.1:8918/motion-editor.html 。图层编辑位于角色画布下方，与动作时间轴共用。

## 操作

1. 选择已绑定角色及源动作，在“图层编辑 · 整段校正”列表选择附件。列表显示源图层名称与附件编号，顶部为最前方。
2. 使用“向前一层／向后一层／置于最前／置于最后”调整遮挡顺序。这不改变骨骼父子关系。
3. 开启画布点选／拖动，选中图层显示网格与包围框。拖动时暂停播放；旋转与横纵缩放用数值输入，变更后即时应用。
4. 平移以角色世界像素为单位，正值向右／向上，旋转正值逆时针。旋转与缩放围绕该附件初始姿态包围盒中心，作用于整段动作。
5. “撤销编辑／重做”同时覆盖角度与图层校正；一次拖动为一次撤销。可恢复所选图层位置，或恢复全部位置与绘制顺序。
6. 保存草稿后可刷新页面、重新选择相同角色版本与源动作，再恢复；也可下载／导入 JSON。切换角色清空当前图层校正，避免应用到另一个角色。
7. 点击“构建当前动作候选”。完成后“在编辑区对照导出结果”，可载入构建时的完整编辑草稿；下载此候选的 Spine 包。

修改不会改写源 PSD、角色绑定或历史动作候选。选中高亮只用于编辑界面，不进入导出。

## 导出与检查

`slot-world-affine-v1` 校正作用在骨骼蒙皮之后。导出通过每个骨骼影响的逆变换写入独立 deform 轨道，保留原网格、骨架与未编辑附件；排序写入 drawOrder 动画。

采样合并现有动作关键时间及 60Hz 网格，每段中点检查最大误差必须不超过 0.25px，否则构建明确失败。该检查是有限采样，不是连续时间误差证明。
生成后重新执行最终姿态与 Runtime 几何检查。图层移动和排序可能改变连接、鞋底接触与遮挡，因此不能沿用修改前的视觉通过状态；异常记录保留。

本切片支持当前工作台生成的加权 Mesh。非支持附件或附件切换动画明确拒绝，不会默默丢弃修改。画布点选按网格三角形覆盖判断，透明区域重叠时可从列表精确选择。

实时姿态栏仍是源动作映射预览，后台的局部修形与接触修正只出现在实际导出栏。校正会在两处应用，但这两栏不保证逐像素相同；实际导出栏与独立 Spine 播放器使用同一候选。

本次不包含逐帧图层校正关键帧、改绑骨骼或修改骨骼父子关系。
