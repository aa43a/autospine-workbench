# 从资产中心导入与管理项目

工作台顶部选择“资产中心”，或打开 `/assets.html`。

选择或拖入 PSD 后，页面显示上传百分比，再显示解析和登记状态。
完成后点“打开新项目”进入图层与关节复核。刷新页面可以继续查询同一个任务；
服务中断导致解析未完成时，会明确提示重新导入。

首版支持 RGB、8 位、PSD v1 的像素图层与组。非像素层需先栅格化。
限制为 256 MiB 文件、8192 单轴、约 1600 万画布像素、256 层、约 6400 万累计图层像素，
解析子进程超时为 180 秒。当前尚无操作系统级内存配额。
图层偏移、可见性、alpha、顺序和合成图保留；原 PSD 使用独立托管快照，源文件不修改。

项目 ID 依据完整源内容哈希确定；同一文件重复导入不会覆盖项目或恢复已归档/删除状态。
同名不同文件分别登记。名称可以独立修改，不改变源资产和历史工件身份。

归档退出默认工作台列表。移入回收站为可恢复的目录状态，不删除源文件、校正或输出；
恢复回收站项目会回到删除前的分类。运行中产品任务会阻止归档和移入回收站。
此版本不清除共享工件，不提供永久删除。直接项目链接仍可读取原工件。

2026-09-11 实际通过页面文件输入导入 flandre.psd，资产由 11 个增至 12 个；
工作台展示 24 个图层与合成图。此结果证明导入接通，不代表该角色已完成绑定或动画验收。
芙兰经用户关节复核后，已通过工作台按钮生成 2 秒、6 个加权网格图层的动画候选，
CPU 诊断播放已验证。候选仍有待复核项，不等同于官方 Runtime 或视觉验收通过。

## 选择处理路线与保存袖装标注

打开项目的“袖装修复”，顶部显示自动建议与独立保存的路线选择。
可以选择普通绑定、袖装处理或稍后决定；选择不会启动任务或批准任何区域。
当前建议依据语义、名称与有效图层边界；handwear 不会直接判定为袖子。
连通域和骨段用于后续网格准备，尚未作为经过验证的袖装自动分类器。

先在“绑定规划与复核”准备来源并完成关节复核，再点“创建袖装标注”。
打开标注画布后可调笔刷、涂选归属、拖动时间轴试播，点“保存到项目”直接登记草稿。
回到袖装修复，点“刷新标注与构建状态”，然后“一键构建袖装”。
保存草稿允许保留不确定项；这不代表归属复核完成，也不授予发布权。

标注绑定当时的骨架、网格与源版本；旧标签不能静默套用到新网格。
来源改变后重新准备并复核。保存冲突不会覆盖更新版本，页面会保留当前编辑并提示刷新。
历史临时目录草稿仍可读取；新项目使用内容寻址存储，无需手工搬运 JSON。
资产卡会显示当前运行的任务和阶段。展开“查看流程状态与下一步”，按需读取当前来源、
草稿和持久化袖装任务结果，区分阻塞、待复核、撤回及中断；点“刷新流程状态”重新核对。
未显示旧来源任务不等于成功。详细 QA 和动画结果仍在项目内查看。
