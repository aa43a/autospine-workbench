# 从资产中心导入与管理项目

工作台顶部选择“资产中心”，或打开 `/assets.html`。

选择或拖入 PSD 后，页面显示上传百分比，再显示解析和登记状态。
完成后点“打开新项目”进入图层与关节复核。刷新页面可以继续查询同一个任务；
服务中断导致解析未完成时，会明确提示重新导入。

首版支持 RGB、8 位、PSD v1 的像素图层与组。非像素层需先栅格化。
限制为 256 MiB 文件、8192 单轴、约 1600 万画布像素、256 层、约 6400 万累计图层像素，
解析子进程超时为 180 秒。当前尚无操作系统级内存配额。
图层偏移、可见性、alpha、顺序和合成图保留；原 PSD 使用独立托管快照，源文件不修改。

项目 ID 依据完整源内容哈希确定；同一文件重复导入不会覆盖项目或恢复已归档/删除状态。
同名不同文件分别登记。名称可以独立修改，不改变源资产和历史工件身份。

归档退出默认工作台列表。移入回收站为可恢复的目录状态，不删除源文件、校正或输出；
恢复回收站项目会回到删除前的分类。运行中产品任务会阻止归档和移入回收站。
此版本不清除共享工件，不提供永久删除。直接项目链接仍可读取原工件。
