## Runtime 采样反馈切片

36 项相关测试通过，包括真实 FK 在原节点/中点之间出现接触偏差的反例，以及身份不匹配、缺失时刻、预算溢出和历史路径兼容检查。该策略保持实验状态，不修改工作台默认候选。

Alice 第二版反馈清单为 2046 个时刻，包含旧 Runtime 全部 1023 个时刻。完整重建后的同帧接触最大误差由 0.249207143 降到 0.249206894 px；原几何仍失败。最终 Runtime 捕获状态以 `../tmp/m4-motion-center/source-axis-feedback-rebuilt-alice-v2/report.json` 为准，不用骨架检查代替 Runtime 或视觉接受。

该版实际 2046 帧官方 Runtime 数值检查已通过，捕获身份和时间清单已核对；没有新增视觉接受。原几何失败仍阻止采用。

## 有界局部形状恢复：不采用

在最新 Alice、红美铃候选的四个真实失败姿态验证两种默认关闭的目标：最小源顶点位移、最小源面积损失。保持原固定顶点、位移预算、投影面积和边长约束。第一种目标没有稳定恢复重点区域；第二种将四个重点三角形的 setup 面积比分别从 0.225/0.200/0.212/0.235 提升到 0.311/0.280/0.360/0.348。

独立检查全部三角形后发现，四项分别新增 29/19/16/20 个原 setup 几何失败，整层最小面积比也全部下降。因此四项均不具备整段实验资格，不烘焙新动画、不运行昂贵的整段捕获、不改变默认策略。求解均达到 400 次预算而未宣告收敛；即使独立投影约束通过，也不能冒充原几何或视觉通过。14 项相关回归测试通过。

证据见 [局部恢复回归](benchmark/m4-source-area-recovery-v1.json)。停止这一路线的目标权重调参；下一步检查混合权重关节区域的拓扑与固定边界可行性，并将原几何非回归作为全邻域约束。该实验不证明所有局部解都不可行。reach 的退化投影处理仍属于当前里程碑，不因 squat 局部失败无限延期。

日期：2026-09-22。本文替代 `m4-delivery-goals.md` 中的后续执行排序；该文件继续保留历史证据。规划不改变候选、技术门禁或人工验收状态。

## 最近里程碑 M4.1：下蹲与伸手可解释、可用

固定 Alice、辉夜、红美铃 × squat/reach 六组合。交付同一工作台中的源/目标同帧播放、适配结果、异常时段与修改入口。六项逐项记录完整支持、局部支持或不支持；局部支持不计入完整动作通过。

| 顺序 | 工作包 | 交付与验收 |
| --- | --- | --- |
| 1 | 动作忠实度基线 | 固定视角、坐标、左右与时间映射；对照源 3D 正侧视，定位下蹲膝部前后变化及 reach 抬手关键时刻；区分源姿态、投影、骨架适配和 deform 的影响。形成六项基线，不能用面积指标代替动作判断。 |
| 2 | squat 局部变形 | 对四个真实失败姿态尝试相邻区域联合求解，保持固定点、接触、预算和原几何限制。目标是减少额外压缩且不转移到相邻区域；有改善才进入全时序重建。 |
| 3 | reach 连续表达 | 检查父子局部角、角度展开与近零投影区间；可靠区间保持源动作时序，退化区间采用明确记录的连续候选或标记素材不足。不能用冻结手臂或隐藏半圈来伪装还原。 |
| 4 | 深度与遮挡 | 同帧源深度、现有分区和时间连续性联合决定手身、裙腿前后关系。先用现有绘制顺序能力；同层需要局部前后切换时再引入最小必要分区。证据冲突留异常，不自动强制排序。 |
| 5 | 六项统一验收 | 对精确候选执行全时序几何、接触、Runtime 和关键画面检查；保持三项 breathing 回归。用户只做阶段视觉反馈，不重复逐层批准。 |

退出条件：六项均有明确可复现结论；完整支持项必须通过技术检查和阶段视觉验收。尚未完整支持的项保留在六项分母中，阻止宣称六项全部完成。

局部实验预算：下一次仅做一次相邻区域联合求解验证；若关键压缩无改善或引入其他异常，就停止同类参数搜索，转向过渡区拓扑/绑定自由度分析。只有固定姿态改善，才投入整段动画与 Runtime 验证。不先默认采用实验算法。

## 完整时间轴实验结论

支撑时间轴已接入默认关闭的姿态优先选项，维持进入/退出、根位移、角度及速度门禁；默认调用保留原版本。新增测试覆盖接触进入、释放和稠密接触检查，15 项相关测试通过。

`tools/m4_pose_support_timeline_probe.py` 已运行三个真实完整片段。`source-axis-timeline-v1` 以 1e-4 px 单帧残差运行；`source-axis-timeline-v2` 改用各原候选已经记录的接触最大误差作上限，仍未获得完整时间轴：Alice 在 1.028125 秒、辉夜在 0.758333 秒、红美铃在 0.729167 秒失败。结果位于 `../tmp/m4-motion-center/`，未生成或采用新整段动画。

对 v2 三个失败时刻独立求解均找到精确接触单姿态，但从各自实验前一帧直接接过去，需要约 392、3177、6431°/s 的局部修正角速度，超过原 180°/s；根位移速度也超过原限制。证据 `source-axis-timeline-v2/independent-failure-probes.json`。这是独立最优点无法直接连接的证据，不证明全部连续路径不可行。

因此停止将单帧姿态最优直接串联的路线。下一步以已存在的连续接触轨迹作为可行参考，采用有限时间窗口联合优化，兼顾源骨轴、未来接触与连续性；不得放宽速度或删除失败时刻来通过。只有完整时间轴成功后才投入网格重建、Runtime 和工作台默认策略集成。

## 固定端点窗口验证

新增独立的仿射窗口模型、窗口优化器及完整 FK 复核工具。实验在既有连续支撑轨迹的 33 个节点窗口上使用 9 个控制节点，固定两端，在原节点和中点共 65 个时刻检查接触、位移、角度与速度。只处理窗口内接触关系不变的双脚支撑；接触切换窗口明确拒绝，不冒充通用步态求解。
