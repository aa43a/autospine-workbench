# M4 侧身与大角度旋转的视觉处理

目标是将 3D 动作适配到已有分层立绘，同时保留真实动作来源。投影、
遮挡和旋转诊断已有实验实现；下述自动分区和替代姿态仍是后续开发项，
不能将其描述为已经支持任意侧身。

## 侧身：躯干形变与局部遮挡分开处理

1. 在角色局部坐标中，用肩线、骨盆线和躯干轴估计朝向。去掉已经由
   骨骼承担的画面内旋转，避免贴图再旋转一次。
2. 将肩、腰控制点投影到指定视角，生成横向压缩、剪切和受限纵向缩放。
   在躯干网格上平滑传播；头、手臂根部同步移动，保留各自的局部运动。
   现有实现和范围见 [躯干投影](m4-torso-projection.md)。
3. 使用运动来源的深度证据，检查实际 alpha 重叠位置。整条手臂同处
   前方或后方时，才可能使用整附件绘制顺序；同一附件同时跨越身体
   前后时，需要局部分区，不能仅交换整个 slot。
4. 后续分区应共享原纹理和 UV，使用稳定的源区域标识；切换采用深度
   裕量和时间滞回，防止近共面时来回闪烁。必须检查切换中间帧、接缝、
   网格翻转和官方 Runtime 合成结果。
5. 缺少深度的袖布保持异常状态。人体骨骼深度不能直接作为宽袖表面
   深度；需要服装代理面或单独的服装运动证据。

接近侧面时，正面贴图会退化成很窄的形状。超过可靠范围时应提供
侧面/背面 attachment 或标记需要美术处理，不能通过无限剪切制造
不存在的背面内容。冻结回归中的完整动作仍保留；裁剪或降低幅度只能
作为另一个明确标注的候选，不能替换失败证据。

## 大角度旋转：先确定是哪一种旋转

| 情况 | 处理方式 |
| --- | --- |
| 表示边界从 +179° 跳到 -179° | 在连续证据支持下展开为连续角度，避免插值绕远路 |
| 真实多圈绕转 | 保留累计圈数和方向；不能直接取模或强行限制到 ±180° |
| 3D 投影的骨段长度接近零 | 标记方向不可观测，不能仅凭相邻 2D 角差推断真实旋转 |
| 手臂沿自身长轴扭转 | 使用侧面/掌背贴图切换或经复核的替代姿态；普通 2D 骨骼旋转无法表达 |
| 一个采样间隔转过过大角度 | 提高原始时间采样或读取源旋转信息；仅凭稀疏端点不能恢复圈数 |

已有诊断边界见 [旋转诊断](m4-rotation-diagnostics.md)。后续沿骨轴扭转
可从源旋转分解出 swing 与 twist，分别驱动屏幕内骨段方向和贴图视角。
但需要骨轴约定、连续四元数和对应美术资源，不能只凭一个二维角度估计。

## 下一实现顺序

先完成固定三角色八动作的局部深度覆盖审计，保留原有几何与接触失败。
再选择深度充分、几何合格的普通手臂区域实现局部分区与切换滞回，随后
进行同帧和中间帧 Runtime 验证。宽袖与缺失侧背面素材单独列为异常，
不阻塞其它可靠区域的候选生成，也不自动当作已通过。
