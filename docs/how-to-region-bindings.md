# 查看图层绑定候选

当前入口把已复核坐标生成的骨架与原PSD图层关联，生成逐层绑定选项及离线位置叠图。
输入为上一切片已经封存的骨架JSON，用户无需填写SHA。

```powershell
python -m autospine_workbench.benchmark build-region-bindings `
  --manifest docs/benchmark/manifest-frozen-v1.json --workspace .. `
  --skeleton ../tmp/r2b-skeleton/crino-v2.json `
  --html ../tmp/r2b-bindings/crino-v1.html `
  --output ../tmp/r2b-bindings/crino-v1.json
```

替换 `crino` 为 `alice` 或 `lingxian` 可查看另两个开发角色。
草稿更新后先重建并封存骨架，再使用新的输出文件名；同一输入幂等。
页面为只读候选列表，绿色线是骨段选项，淡色人物是位置参照。
页面按源图层记录顺序排列，不把该顺序当成正式Spine绘制顺序。

`conservative-region-binding-v1` 使用现有名称语义建议：脸和头发建议head，颈部建议neck，
躯干/上衣建议chest，裙子/裤子建议pelvis。分段臂腿、手、脚和鞋保留左右两个选项。
不使用名称中的l/r或画布左右直接确认角色侧别；名称建议也不等于正式身体语义。
袖子、饰品、整臂/整腿及其它不支持语义不会强制绑定。空、隐藏、越界图层保留记录并阻塞。

所有选项按bbox中心相对骨骼的逆变换计算局部位置，局部旋转抵消setup骨骼旋转。
测试逐一重建四个角点，确保绑定变换不会移动原图层。这里仅证明setup几何，
不证明图层分割质量、遮挡正确、多动作变形或接缝质量。

| 角色 | 图层数 | 有待复核选项 | 当前阻塞 |
| --- | ---: | ---: | ---: |
| Alice | 23 | 5 | 18 |
| 铃仙 | 21 | 5 | 16 |
| 琪露诺 | 18 | 5 | 13 |

三角色共62层，15层有选项、47层阻塞；琪露诺的一层同时为空且隐藏，不重复计数。
实际选项四角重建最大坐标差约1.14e-13 px。[结果清单](benchmark/region-bindings-2026-09-08.json)
记录地址及原因统计。Chrome已实际渲染检查琪露诺页面；上衣图层仍混有其它部件，
因此名称命中只列为建议，后续需要语义和拆层复核，不能自动绑定后宣称正确。

验证包括4项纯核心测试、2项CLI端到端测试、3项质量门禁及8项上游骨架回归，共17项通过。
源图片变化、候选字段篡改会拒绝回读；骨架阻塞时返回CLI退出码2且所有层无选项。
骨架有效时返回0、整体状态needs_review，即使部分或全部层阻塞也不是构建完成声明。
本切片未运行全量Python/Web回归或官方Runtime，未改旧Spine适配器及历史工件。

下一步接入可保存/恢复的绑定复核草稿、语义及拆层异常处理，再接正式决定与完整region预览。
当前不写入采用决定、生产RigIR或Spine导出；不使用模型辅助标注宣称独立GT精度达标。
