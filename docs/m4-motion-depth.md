# 外部动作深度诊断

新角色适配请求记录 `external-arm-torso-depth-review-v1`。旧请求不增加深度文件、不更改重放身份。目标任务从已验证源包快照读取数据，生成 `motion-depth.json`，并把身份纳入候选文件清单。

BVH 使用既有三维 FK 的深度坐标，Kimodo 使用矩阵一致性校验后的 SOMA77 位置。当前视角 profile 明确约定映射深度正方向朝相机；来源字节、映射、角色、动作包和输出 skeleton 身份均保留。裁剪时保留原源帧编号，报告时间平移到目标片段起点。

根据有效网格权重识别左臂、右臂和直接胸部附件。混合归属、头颈、腿部、裙链和未知附件不推断成躯干。对肩、肘、腕相对源上躯干的深度建立配对证据，复用已有 Schmitt 迟滞：进入差值为源参考腿长 4%，退出差值 2%，连续三帧产生换序建议。单帧抖动不换序；同一手臂跨越躯干前后超过迟滞带时，保留原顺序并报告跨平面区间。

入口：**动作中心 → 新建角色候选 → 查看遮挡时间点**。报告把连续跨平面帧合并成区间，可以跳到同一候选的官方 Runtime 时间轴；完整 JSON 保留逐帧记录。结果说明源深度关系，不宣称目标像素重叠或最终遮挡已经通过。当前尚未写入动态 drawOrder。
