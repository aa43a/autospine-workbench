# M4 交付目标重分解（2026-09-22）

本文件是当前执行优先级，替代 m4-execution-targets.md 中已完成的“下一切片”顺序；原 M4 六案例质量目标、失败记录和验收条件继续有效。本次为证据核对与规划，不代表重新运行验收。

## 总目标

从工作台选择角色及外部动作，自动生成完整角色候选；可用结果直接进入阶段验收和导出，异常在当前页面定位与调整。需要改变视角或补充姿态素材时明确给出方案，不静默缩小动作、不把技术通过当作视觉通过。

## 分阶段目标

### M4.1：异常可定位、处理有入口（立即执行）

交付工作台内的动作问题检查器：选择异常即可定位动作时间、角色区域、原始纹理和网格；同步查看源三维姿态与二维候选。区分角度跳变、投影缩短、面积/边长失败、遮挡、接触和未知深度，不凭单个指标自动判定“必须补图”。

支持三类处理：沿用已验证表示；生成明确标注的适配候选；建立待复核的分区/姿态素材需求。所有修改可撤销，关联当前候选，重建后未解决异常继续保留。

完成条件：

- Reach 肩部与 Squat 膝部已知问题能在同页定位，不跳回素材检查，不手填 SHA。
- 可从失败记录进入对应时间与区域，纹理与网格共用坐标，压缩和扩张均定位到各自实际失败时刻。
- 当前候选、技术状态、阶段视觉状态与下一操作清晰可见；旧证据不能误用于新候选。
- 新增诊断模块及接口尚在开发，未测试代码不计作已交付。

### M4.2：解决大动作表示，再验证六案例

按原因选择表示，不继续把所有问题归给权重：

| 问题 | 下一方案 | 成功标准 |
| --- | --- | --- |
| Reach 近退化投影及前后穿越 | 保留三维深度与时序；验证连续遮挡和肩部材料连接 | 无突跳、缺片、硬切；完整肩臂阶段接受 |
| Squat 投影缩短及膝轮廓 | 在同一关键姿态对照原素材、原网格与投影参考；仅对必要区域比较姿态附件或新分段表示 | 前屈可读、无膝缺口，支撑与源举臂保留 |
| 素材没有提供侧面/背面 | 明确部位、视角、时段和所需附件；先做最小素材验证 | 新素材与原图风格、接缝和切换均可接受 |

首先验证红美铃 Squat 的起始、0.8/0.9 秒问题姿态及起身；同时收口 Alice Reach 的肩部表示。关键姿态成功后才扩展整段，再覆盖 Alice、辉夜、红美铃六个 Reach/Squat 案例。

旧分段和膝部覆盖试验已经失败，不原样重复。新假设最多一次有明确原因的修正，仍失败就记录并切换表示。角度展开不能补出背面；三维骨架可提供深度与弯曲证据，但现阶段不承诺完整三渲二角色重建。

完成条件：六案例分别通过技术检查与阶段视觉验收，三个原 Breathing 回归无新增问题。仅部分可用就报告部分完成，不能变更分母宣告整个 M4 完成。

### M4.3：默认流程与固定集交付

已验证能力随时接入工作台，不等待 M4.2 全部结束。统一来源选择、准备、构建、进度、取消/恢复、同页异常调整、播放、验收与导出；输出对应同一候选。默认采用已有充分证据的策略，用户只处理异常及阶段验收。

FBX/BVH 与 Kimodo 继续共用 MotionIR；补齐当前 BVH 专属脚部观测策略的其他来源支持与回归。先固定三角色八类动作，再扩展十角色，分别统计构建成功、技术通过、视觉接受、受限、缺素材及失败。人工时间与自动采用错误率只使用真实记录，不以默认采用推定正确。

交付前实测完整角色包体、槽位、首帧时间、播放帧耗时和拖动延迟，并冻结设备与预算。高成本参考实现保持实验状态。

## 最近三个开发切片

按姿态启用覆盖片已做到原姿态 PNG 与父候选完全相同，114 时刻 Runtime 数值通过；但渐变帧出现半透明加厚和双轮廓，仍未采用。见 [姿态素材覆盖片实测](benchmark/m4-pose-material-v1.md)。下一步处理局部材质过渡，保留原面积失败，不追加全带叠加调参。

局部 UV 假设已验证两个凹口中心的 alpha 从 0 改善为 255，但静态方案会改变原姿态映射，且非线性 UV 源图检查不支持；未采用。见 [局部 UV 实测](benchmark/m4-joint-uv-v1.md)。下一步验证按姿态启用与轮廓/切换副作用，不把两个采样点改善当作整段修复成功。

最新证据：同帧 Runtime 高亮已交付；双腿隔离及两个凹口中心的 GPU/UV 核对发现“网格覆盖但透明纹理采样”。见 [膝部透明采样诊断](benchmark/m4-squat-alpha-hole-v1.md)。下一修复试验优先比较局部姿态素材/有界 UV 处理，不继续单纯扩大网格；大腿面积失败独立保留。

1. 完成几何异常详情接口和同页纹理/网格定位，检查失败时间、版本一致性及实际浏览器交互；不改变验收门槛。
2. 将 Squat 膝部及 Reach 肩部整理为可比较的表示方案与素材需求，以关键画面决定是否继续整段计算。
3. 把通过的策略接入统一构建入口，记录支持范围和回退原因，再进行六案例验收；失败项继续展示。

继续使用现有 MotionIR、异常队列和版本合同；诊断、求解、存储与 UI 分模块，生产文件不超过 400 行。保留原始素材、已确认结果及未提交工作。规划文档不代表自动接受当前实验。
