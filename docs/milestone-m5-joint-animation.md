# M5：脸部、头发与服装联合动画

规划日期：2026-09-28。状态：已规划，待开发。

## 原定目标与本次更正

用户引用的 [spine auto M3](thread://01a0bd6f-ab74-7d63-bf80-ef342b823da4?hostId=local)
明确规划：M4 为外部动作中心，M5 为脸部、头发与服装联合动画，M6 为完整自动化生产流程。
本计划恢复这一分工。此前以 M5 编号提出的大幅动作修复，归入
[M4 质量后续工作](m4-motion-quality-followup.md)。

M5 的用户结果：**身体动作叠加基础表情、发束摆动和裙袖响应，在同一编辑页播放、
调整和烘焙，进入同一个 Spine 包，并验证连接、遮挡、循环和官方 Runtime。**

以已有阶段接受的身体动作作为起点。M4 侧背面、拳击、下蹲等遗留问题继续保留，
仅在影响当前联合动画时处理；无需先清空所有 M4 异常才能开发 M5。

| QA | 几何、接触、遮挡、Runtime 与版本化阶段记录 | 效果叠加、循环、随机定位、通道隔离、主动作非回归 |

## 用户操作与完整链路

在 `/motion-editor.html` 选择角色和身体动作 → 自动检查表现素材/骨链 →
启用表情、头发、衣料 → 共用时间轴调整与预览 → 构建联合候选 →
检查新增异常和整段表现 → 下载同一版本的 Spine 4.3.26 包。

- 中央视窗以整角色为主，可切换原身体动作/联合结果和局部放大。
- 时间轴按身体、表情、头发、衣料分轨显示；支持效果独立开关、强度、关键帧和撤销。
- 侧栏只显示当前部位/轨道参数。选中眼睛、发束或裙袖区域后可在画布调整锚点和影响范围。
- 默认生成有依据的配置；只对缺素材、根部歧义、跨部件归属及实际穿插集中处理。
  既有骨骼/区域确认继续复用，不恢复逐层重复批准。
- 单项缺失只影响对应效果。例如缺闭眼差分时标记眨眼缺项，视线、头发和衣料仍可构建。
  联合结果必须列明实际启用项，不能把被跳过的效果计为完成。

## 开发顺序

| 切片 | 内容 | 可验收交付 |
| --- | --- | --- |
| M5.1 联合动画基础与最小贯通 | 角色表现清单、版本化通道配置、写入权、编辑入口、联合烘焙/导出 | Alice 一个已接受身体动作叠加一项可用面部控制、一条发束和一个裙摆区域，同页对照、暂停/拖动、关闭效果、恢复及下载 |
| M5.2 基础表情 | 开闭眼与眨眼、视线、眉毛、基础口型；有限小幅转头/五官相对位移 | 面部锚点可调，手动关键帧与自动眨眼不争抢；眼口遮罩/附件切换在真实 Spine 中正确 |
| M5.3 发束响应 | 自动发束与根部建议、辅助链/权重、固定步长弹簧、角度限制、简化碰撞 | 发根稳定，发束随最终头部运动滞后/回弹；同一时刻与播放顺序无关，正常参数下不失稳 |
| M5.4 裙袖响应 | 复用既有辅助骨和归属，加入身体惯性驱动、连接约束、碰撞及修形复核 | 裙腰/袖口连接保留；手掌旋转不会拖走整片袖布；与原修形显式合成，能单独关闭新响应 |
| M5.5 联合验收与默认策略 | 三角色、多动作、效果组合、循环和导出回读 | 完整角色同时包含表情、发束与适用服装效果；技术与阶段视觉结论分别保存 |

M5.1 先建立共享合同并贯通最小组合，不要求首切片完成所有表情和服装形式。
合同冻结后 M5.2 与 M5.3 可并行；M5.4 复用次级运动求解器和已确认服装根部。
初始 M5.1 不是 M5 完成条件；仅诊断缺项或生成独立局部报告也不算联合动画交付。

## 通道、求解与导出规则

### 明确写入归属

| 通道 | 驱动与允许修改范围 |
| --- | --- |
| 身体主动作 | 引用精确 M4 候选；保留身体骨骼、来源时序、相机与已有修正 |
| 面部 | 指定眼口/眉毛附件、控制骨或局部 deform；继承 head，受限转头作为显式局部增量 |
| 头发 | 根部继承最终头部姿态；仅发束辅助骨/指定 mesh 接受弹簧结果 |
| 衣料 | 根部沿用已确认 chest/pelvis/forearm 等挂点；仅指定辅助骨/区域接受新增响应 |

同一属性只有一个最终编译结果。手动表情键、表情预设和自动行为有显式优先级；
既有 deform 与新修正必须在兼容的坐标/拓扑合同下合成。不能用字典覆盖丢掉旧动画。
裙装原正弦探针需替换或关闭，避免和惯性驱动重复摆动。

新效果全部关闭时，应重现原动作；新增中性辅助骨不得改变 setup 外观。
候选身份包含基础动作、角色版本、素材与映射、通道配置、求解器版本、步长和随机种子。
来源或配置变化后缓存失效，原阶段接受记录不迁移到新候选。

### 表情与素材

先采用有实际图层依据的状态和可受控的局部变形。缺闭眼/闭口差分时，提供原画对齐的
模板或生成候选、替换入口及来源记录；未经外观核对不能当作原画差分。
首版基础口型使用人工关键帧/预设，不以随机张嘴冒充音素同步。
小幅转头只在素材可表达范围内工作，不承担完整侧背面重建。

借鉴 [Anime2.5DRig 官方项目](https://github.com/852wa/Anime2.5DRig) 的锚点编辑、
眼口参数及发束行为思路。其文档描述了独立 WebGL 渲染与 PNG/视频输出；本项目需要
把所选行为适配为 Spine 骨骼、mesh deform、附件切换及可支持的裁剪，不能直接等同导出兼容。
实现前固定所参考代码版本，先做单能力适配验证，不将整个外部渲染器作为工作台依赖。

### 发束与衣料

使用有界、固定步长、可重复的离线求解。根部由主动作/面部最终姿态驱动，
独立辅助骨接收相对运动；质量、阻尼、刚度、重力和角度限制通过预设与局部参数暴露。
读取物理驱动时区分身体运动与观察相机旋转，避免转镜头凭空产生衣料惯性。

首版优先简化头身碰撞与根部/袖口/裙腰连接约束；自动骨链或归属没有充分依据时，
保留局部调整入口。不能通过把整层归为一个自由摆动骨来绕过已确认连接。
复杂三维布料求解、直播面捕、完整音素识别不作为本阶段必要项。

求解完整片段后读取烘焙轨道，反向拖动不反向积分。交互中的轻量预览须标明状态；
最终预览与导出使用同一烘焙结果。循环采用有限预热/首尾收敛检查，未收敛的效果单独报错，
不能静默重置物理状态或把非循环动作强制接回第一帧。

同一个 Spine 包至少包含可直接播放的联合动作，不能依赖本工作台浏览器脚本才产生表情或摆动。
单效果轨道可以保留作编辑与调试，但不以多个互不组合的动画代替最终联合输出。

## 验收范围

先用 Alice 已接受的呼吸动作做最小贯通，再覆盖 Alice、辉夜、红美铃三种结构。
第一固定集使用各角色已经阶段接受的呼吸、挥手，共六个联合样本；
再加入各自已接受行走作为九样本扩展检查。实际输入固定到具体来源、角色、视角和候选版本。

- 每角色至少一份完整联合结果包含基础表情、发束运动和适用服装响应；
  无袖角色的袖装为不适用，但裙装/其他已声明服装仍按其实际结构测试。
- 基础表情覆盖眨眼、视线、眉毛和基础口型；缺项逐项列出，不能通过缩小名称声称全功能完成。
  缺素材不阻塞其他切片开发，但会保留该角色/效果的验收缺口。
- 开启/关闭单项效果验证通道隔离，原身体动作和既有修正无意外改变。
- 检查发根、头颈、袖口、裙腰连接，以及发—眼、袖—手、裙—腿的实际遮挡与新增穿插。
- 顺播、倒拖、随机跳转至同一时刻结果一致；重复构建在冻结环境下输出可复现。
- 循环素材至少检查两次接续的姿态、速度和显隐连续性，非循环动作按其实际起止处理。
- 原关键帧、效果关键帧、切换边界及中间帧进入 QA；做官方 Runtime 同帧捕获和导出回读，
  检查完整角色，不能仅通过局部线框或浏览器自定义预览验收。

基线已有 M4 异常单独列明；新增连接、几何、接触或显隐回归不能因原基线有异常而豁免。
技术通过、素材缺失、阶段接受、受限可用分别统计。默认采用不充当人工准确率证据。
用户只在异常和整段阶段结果上介入，保留调整与撤销能力。

## 首个切片的实施任务

1. 生成角色表现清单：眼口素材与锚点、发层/根部、裙袖区域/辅助骨，复用已有确认。
2. 定义联合配置与通道合成器，验证关闭效果复现原动作、冲突拒绝和身份失效。
3. 编辑页增加表情/头发/衣料入口及轨道开关，当前选区参数留在同页。
4. Alice 呼吸叠加一项有素材依据的面部控制、一条发束和一个裙摆响应，完成实际烘焙、
   同页播放及 Spine 包下载；缺闭眼图时可先验证视线通道，眨眼缺项仍保留。
5. 验证重载恢复、反向拖动、同帧导出对照及整体外观，再扩展 M5.2–M5.4。

本轮交付为规划更正。实现按此文逐切片推进；M4 质量后续清单作为按需支撑，
M6 仍负责 PSD + 动作/描述到仅异常调整和输出的完整生产编排与扩大角色集。
