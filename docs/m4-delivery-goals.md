## 总目标

用户在动作中心选择角色和 FBX/BVH/Kimodo 动作后，自动得到可播放、可导出且标明支持范围的整角色候选。普通情况默认处理；异常定位到动作、时间、部件，并允许在同一页面调整、重建和恢复原方案。

本轮先固定 Alice、辉夜、红美铃，优先解决 squat/reach 六组合。先把已有能力接成完整工作流，再解决影响这六组合的运动表达问题。暂不扩展新角色或新增布料物理主线。

## 当前基线

- 已有导入、Kimodo 生成、MotionIR、整角色适配、官方 Runtime 播放、时间轴和导出基础。
- 三角色八动作已有历史构建与验证记录；只有三份 breathing 有用户阶段接受记录，技术异常仍保留。不能据此宣称 24 项视觉通过。
- 源姿态与髋中心策略已可从动作中心显式选择，但仍是实验候选；并未包含所有离线接触、脚踝和肩部修正。
- 真实工作台任务 `motion-138be48a1c004545a4895225ead2074e` 构建完成，623 帧 Runtime 记录仍报告几何异常与接触漂移。构建完成不等于合格。
- squat 涉及投影方向、脚部接触、裙腿遮挡和肩部连接；reach 涉及投影退化、旋转连续性及掌面表达。它们不能仅用同一个权重修补解决。
- 任务卡策略说明与报告读取还有未完成的浏览器/下载闭环验证，先收尾再扩大算法范围。

## 目标 A：动作中心可操作闭环

交付：选择来源与角色 → 自动检查适用条件 → 构建 → 验证 → 同帧源/目标播放 → 定位异常 → 重建或恢复 → 下载。

1. 收尾当前策略卡、依据入口、真实播放器与下载验证；任务状态分别显示构建结果、技术检查和阶段验收。
2. 将已有可复用修正组成版本化策略，明确哪些已接入，哪些仍只在离线实验中。通过的区域保留，修改限于异常作用区。
3. 在同一页面选择动作、拖动时间轴、显示/隔离部件；异常点击直接跳转对应时间与区域，保留当前播放上下文。
4. 提供恢复旧候选、重试、取消及失败原因；输入变化后的旧验收不得自动转移。

完成条件：固定三角色均能从工作台完成一条真实构建、播放、异常定位与下载链，不需要手填路径、摘要或命令行；下载包与所播放候选一致。技术失败仍清晰可见，不能以可下载代替质量通过。

## 目标 B：下蹲与伸手的动作表达

按以下依赖顺序实施，不同时堆叠多个未经验证的修正。

| 切片 | 交付内容 | 核验方式 |
| --- | --- | --- |
| B1 源动作忠实度 | 固定坐标与视角、保留抬臂时序、髋部位移、角度连续性；识别投影接近零长度的区间 | 源 3D 正/侧视与目标共用时间轴；突跳必须追溯到源变化或被标记异常 |
| B2 关节连接与体积 | 复用有界局部修正，优先肩、肘、膝、踝；保住已通过区域和脚部接触 | 按同帧基线检查翻转、面积、边长、接触和 Runtime 画面，不能只证明求解器成功 |
| B3 前后关系 | 仅对实际相交区域分析深度；整层顺序不能表达时评估已有分区，加入时间连续性 | 下蹲裙腿、抬臂手身遮挡在完整角色中检查；深度证据冲突保持异常，不强制自动排序 |
| B4 表达能力边界 | 对侧身、掌面和真实转圈判断现有贴图是否足够；支持视角明确标注 | 区分角度跨界、投影退化和真实旋转；缺少侧背面素材的区间不靠拉伸宣称还原 |

完成条件：三角色 × squat/reach 六组合逐项达到约定的动作忠实度、连接和遮挡要求，并取得阶段视觉结论。局部或不支持区间单列，不能计作完整动作通过。保留 breathing 回归。

三维信息先用作运动、深度和体积约束；完整三维角色重建或三渲二素材生产另立目标，不作为当前链路的隐式依赖。

## 目标 C：默认自动处理与固定动作验收

在 A 可用、B 策略验证后，再提升为默认策略：普通动作自动采用有充分证据的处理方案，异常保留修改入口。策略选择绑定来源和版本，不依赖角色名称或三角形编号特判。

重新对三角色 × 八类动作的当前候选核验，统一记录：构建完成率、技术通过率、视觉接受率、不支持范围、人工干预次数/实测时间、自动处理时间、已抽查错误率和未抽查数量。未测量项保持未测量。

完成条件：24 项均有精确可复现结论；支持范围内的结果有实际播放、导出和验收依据；失败可以定位并恢复。先冻结三角色支持范围，再开展十角色扩展，不能把不支持项从固定分母中删除。

## 范围和停止规则

- 不继续无边界袖装精修；复用已有结果，只有阻塞整角色链路的回归才进入当前工作。
- 暂缓新脸部/发型系统、任意 360° 侧背面和完整布料物理。
- 每个切片必须交付可操作功能、可播放改善或明确的失败归因；报告数量和 Runtime 帧数不作为完成率。
- 同一策略连续两轮没有改善目标且无新证据时，暂停参数搜索，转查表达能力、拓扑或约束冲突；不降低门禁伪造通过。
- 按策略选择、姿态拟合、局部修正、深度、验证和 UI 分模块；不持续扩充单一 worker 或控制器。
- 默认归属与普通前置步骤沿用用户授权自动推进；仅真正需要素材语义判断或阶段视觉反馈时请求用户介入。
