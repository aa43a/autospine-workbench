# 角色动作编辑与连续视角工作流

目标：角色选择 → 现有/导入动作或 Kimodo 生成 → 源骨架与角色贴图共用时间轴、
水平 360° 实时映射 → 固定视角或角度关键帧烘焙 → 检查 → Spine 4.3.26 导出。
该目标独立于已交付的 M4，不能用 M4 的固定视角候选替代实时映射。

## 开发顺序与完成条件

1. 编辑页：同页角色、来源、双画布、播放与连续角度轨道；识别准确源/角色身份。
2. 共用求解：生产后端与当前帧预览使用同一相机、重定向及退化处理规则。
   360° 边界保留旋转方向，折叠或失去观察条件时显示异常，不凭空翻转骨骼。
3. 真实二维联动：角色 Mesh 使用已确认绑定与权重，源时间/角度变化实时更新。
   先保证固定角度与完整源时间一致，再支持角度关键帧；旧构建证据不继承。
4. 同页导入/生成：复用任务进度、取消、重试与来源；新动作可直接选择。
5. 冻结及烘焙：完整来源、角色版本、相机轨道形成独立可恢复任务，
   烘焙与预览同源；接触、几何、遮挡和官方 Runtime 检查后可导出。
6. 实测：三结构角色、正侧背角度、跨 360°、正反拖动、过期响应、来源变化、
   固定角度与关键帧输出一致性、原候选/验收不变；明确未支持素材范围。

所有步骤完成之前目标保持进行中。正面角色贴图无法自动成为可信的背面素材；
背向投影须提示素材缺项，完整转身外观需多视图附件或三维代理的另行证据。
不通过隐藏后半圈、缩短动作或把二维骨架线框称作角色动画来完成目标。
