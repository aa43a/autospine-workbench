# 风场与次级运动

风强、风向和阵风共同驱动现有头发、裙摆、宽袖及挂饰响应，保留身体动画和已保存的角色绑定。结果烘焙为普通 Spine 骨骼轨道，播放端无需另行接入风场求解器。

## 在动作编辑页使用

打开 `http://127.0.0.1:8918/motion-editor.html`。页面顶部的“风场与次级运动”可直接定位操作面板。

1. 在“已有身体候选”中选择已完成的身体动作，点击“载入身体候选与联合动画”。新动作先按现有流程构建身体候选。
2. 在“全局风场”点击“启用风场与可用受风区域”。此操作只选择能够处理的区域，并进入撤销历史；原有不支持区域及其绑定保留。
3. 调整风强、吹向和阵风，第一次点击“构建联合动画”，为选定区域生成受风预览轨迹。任务结束后，修改风场、回弹、阻尼和受风系数即可在结果画布即时比较。
4. 用共用时间轴检查动作。勾选“无风对照”仅移除风力，身体运动引起的惯性仍保留。再次构建后，点击“下载此候选 Spine 包”取得实际烘焙结果。

风强采用 0–100 的视觉单位，没有按角色真实尺寸标定为米/秒。0° 向右，90° 向上。圆形箭头可拖动；方向键每次调整 1°，Shift 加方向键调整 15°。每类区域及局部区域均可调整受风系数。

风场面板的“有风 / 无风 · 同帧同尺寸对照”使用相同身体姿态和取景范围，分别显示当前风场及保留身体惯性的无风结果。可选择全身、头发、裙袖或挂饰放大；窗口显示材料顶点最大位移、当前显示尺寸下的位移及画面变化像素数。它沿用同一求解器，不改变导出数据。中间画布标为“身体动作预览 · 不含风场”，右侧结果和风场对照才显示次级运动。

在当前时间输入风强、风向并点击“记录当前时间”，可制作最多 128 个关键帧。风强线性过渡，风向沿较短方向过渡，例如 345° 到 15° 会穿过 0°。有关键帧时，输入框和滑条显示当前时刻的实际数值，修改会暂停播放并立即插入或替换当前时间的键；其他时间的键保留，改动可以撤销。“清空风场关键帧”会把当前实际风强、风向保留为整段固定值。

非循环动作的首帧从静止开始，因此此时有风与无风可能相同。播放或拖到后续时间观察响应。循环动作使用周期求解的初始状态，仍需检查首尾。

参数、关键帧及来源身份随联合草稿保存。撤销、重做和恢复草稿均可使用。无风对照只影响画布，不保存为构建参数，也不会修改历史候选。关闭即时预览会退出对照并显示实际烘焙结果。

## 求解与导出

风向采用固定的世界 XY 平面。带种子的两组谐波调制风强，平方风强进入角向外力，再与身体惯性、回弹和阻尼共同求解。种子、参数和来源相同，输出相同。

后端以 120 Hz 固定步长计算完整轨迹，约 60 Hz 烘焙，保留误差超过 0.05° 的中间样本。前端使用同一算法重算完整轨迹，再按时间查表；播放、暂停、往返拖动不会累积物理状态。级联发束使用上游求解后的运动作为驱动。

新增辅助骨保持原身体父骨。发根、衣料连接与挂点的固定规则沿用现有生成器。几何保护逐区域降低新增响应增量，不改变原身体动作；降低比例和跳过原因显示在候选摘要及同帧窗口中。UV、纹理、原骨骼和绘制顺序沿用既有输出合同。

新候选默认使用“自然摆动”：外力按回弹刚度和摆动上限标定，减少风强滑条过早达到角度上限的问题。二维头部、躯干胶囊只能检查投影覆盖，无法判定前后分离的素材是否发生物理碰撞；自然模式将这些覆盖变化保留为视觉检查记录，不据此压低全部摆动。网格面积、翻转、边长拉伸保护仍执行。“兼容旧候选”沿用原外力及覆盖限制，旧文件不会自动切换模式。

改动参数后的即时预览使用上一次构建的网格和保护比例，尚未重新执行几何、接触及 Runtime 检查。固定根部、挂点、新增区域和面部改动明确列为需要重新构建。旧下载始终指向原不可变候选，不会把画布草稿当成已验证导出。

循环模式将阵风频率调整为整周期，检查外力首尾、辅助骨位置和速度。风强或风向关键帧首尾不一致时，仍报告循环异常；不会靠减小几何幅度或静态区域掩盖外力不连续。原身体动画自身的循环异常单独保留。

## 数据与兼容性

联合参数新增可选的 `wind` 字段：

```json
{
  "schema": "autospine.wind/v1",
  "enabled": true,
  "strength": 25,
  "direction": 30,
  "gust": 0.25,
  "frequency": 0.5,
  "seed": 713,
  "response_profile": "bounded-equilibrium-v2",
  "keys": []
}
```

`hair`、`cloth`、`objects` 的 `wind_response` 及各自 `overrides[slot].wind_response` 取值 0–2。0 表示该区域不受风。`response_profile` 可选值为 `bounded-equilibrium-v2` 或 `legacy-angular-v1`；字段缺省时使用旧算法，旧冻结配置不增加字段、不改哈希。编辑页恢复尚无风场字段的旧草稿时补充默认关闭的风场。关闭风场移除外力，身体惯性仍保留。

现有 `POST /api/motions/<body-job>/joint-animation` 使用这一配置，继续创建独立候选。`joint-animation.json` 保存风场证据及预览文件哈希。新增 `wind-preview.json` 保存来源矩阵、辅助骨、区域和保护比例，绑定父级骨架、最终骨架及配置哈希。接口只允许从指定任务的已验证候选读取该文件，前端再次核验哈希；资源失败会显示原因并保留实际导出姿态。

## 当前支持范围

- 固定观察角度下的二维响应。身体候选含动态相机旋转时，仍拒绝把相机运动混入惯性；不会据此宣称已经支持真实三维风场或任意 360° 视角。
- 发层须有兼容素材和绑定；服装使用已存在的裙袖辅助骨；挂饰采用兼容的单一父骨。已有多骨局部修形、附件切换和边缘残余会保留或明确跳过。
- 采用辅助骨弹簧与角度限制，没有布料自碰撞、与身体的完整碰撞、气流遮挡或侧背素材重建。
- 新增风场候选仍需阶段视觉验收。已有遮挡和接触缺测不会因本功能通过数值检查而消失。

新的爱丽丝关键帧候选及辉夜固定风强 75 候选使用自然模式，共完成 4,332 帧官方 Runtime 几何检查和 139 张图像捕获，零几何失败，固定根部误差为 0。Spine Core 4.3.13 各复核 21 个时间点，浏览器重算与烘焙轨道最大误差低于 9e-14°，顶点误差不超过 0.000123 px，身体通道保持。旧爱丽丝候选重新复核，沿用旧模式的轨道仍一致。

### 裙摆固定边缘过渡

用户继续反馈裙摆差异不明显。Alice 当前草稿末帧的裙摆有风／无风差异为 1.25 px，在裙袖观察窗只有 0.83 屏幕像素。旧绑定在固定腰部边缘仍保留少量躯干权重，而相邻自由行立即完全归给响应骨骼。窄三角形因此限制了整片裙摆的幅度。

新增 `cloth.response_profile: "material-falloff-v2"`。从既有固定顶点沿 setup 网格边求最短距离，使用同一服装区域的最大可达距离归一化，再以 smoothstep 逐渐释放响应权重。固定边缘与自由端的变化斜率均为零；短小的已固定分离区域沿用整片服装的过渡宽度，避免一条窄边就承担全部摆动。没有固定点的独立区域保留原运动，并在 `response_falloff.unanchored_vertices` 中记录。该方法没有角色名、指定三角形或人物坐标判断。

原有辅助骨与新响应子骨仍分担同一个材质顶点的权重，每个旧 deform 分量复制到对应影响项。新响应为零时保留原身体与局部修形姿态，固定点不随风移动。三角形翻转、面积与边长限制仍执行；不会通过放松几何检查来制造可见摆动。

编辑入口是“联合动画 → 裙袖响应 → 固定边缘过渡”。新草稿使用平滑过渡及 8° 摆动上限；历史草稿和冻结请求缺少该字段时继续使用旧算法及旧幅度。切换过渡模式需要先构建一次新的网格，页面明确提示等待重建。摆动上限、回弹和阻尼的合法数值输入立即更新草稿，随后风场参数可以同帧比较。草稿保存、恢复、撤销以及下载继续绑定实际候选版本。

新增验证覆盖窄固定／自由接缝、微小躯干权重、分离的小区域、缺少固定点的区域、缩放与平移不变性、稀疏 deform、固定点保持、旧配置兼容，以及浏览器预览的重建提示。真实候选和视觉差异证据见 `wind-cloth-falloff-verification.json`。这仍是辅助骨次级运动，不包含布料自碰撞或完整三维风力。

Alice 使用用户已保存的两帧风场（0 秒为 45 / 345°，9.933333 秒为 79 / 60°，阵风 0.1、3.65 Hz），将裙袖摆动上限设为 10° 后创建独立候选。末帧有风／无风最大差异为 7.77 材质像素，在当前裙袖观察窗为 5.12 屏幕像素。即时改为风强 25 时差异降至 0.85 px；改为水平风向 0° 时为 14.13 px。试验后已撤销，导出保留用户的 60° 方向。风向大部分朝上时，侧向摆动自然小于水平吹风。
