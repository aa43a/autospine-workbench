# 风场与次级运动

风强、风向和阵风共同驱动现有头发、裙摆、宽袖及挂饰响应，保留身体动画和已保存的角色绑定。结果烘焙为普通 Spine 骨骼轨道，播放端无需另行接入风场求解器。

## 在动作编辑页使用

打开 `http://127.0.0.1:8918/motion-editor.html`。页面顶部的“风场与次级运动”可直接定位操作面板。

1. 在“已有身体候选”中选择已完成的身体动作，点击“载入身体候选与联合动画”。新动作先按现有流程构建身体候选。
2. 在“全局风场”点击“启用风场与可用受风区域”。此操作只选择能够处理的区域，并进入撤销历史；原有不支持区域及其绑定保留。
3. 调整风强、吹向和阵风，第一次点击“构建联合动画”，为选定区域生成受风预览轨迹。任务结束后，修改风场、回弹、阻尼和受风系数即可在结果画布即时比较。
4. 用共用时间轴检查动作。勾选“无风对照”仅移除风力，身体运动引起的惯性仍保留。再次构建后，点击“下载此候选 Spine 包”取得实际烘焙结果。

风强采用 0–100 的视觉单位，没有按角色真实尺寸标定为米/秒。0° 向右，90° 向上。圆形箭头可拖动；方向键每次调整 1°，Shift 加方向键调整 15°。每类区域及局部区域均可调整受风系数。

风场面板的“同帧角色预览”直接显示结果画布的当前姿态，便于调参时观察。它与主结果共用同一次绘制，不运行另一套物理，也不改变导出数据。

在当前时间输入风强、风向并点击“记录当前时间”，可制作最多 128 个关键帧。风强线性过渡，风向沿较短方向过渡，例如 345° 到 15° 会穿过 0°。有关键帧时，输入框用于记录或替换当前时间的键，不会自动重写其他键；面板另行显示当前时刻的实际风场。

参数、关键帧及来源身份随联合草稿保存。撤销、重做和恢复草稿均可使用。无风对照只影响画布，不保存为构建参数，也不会修改历史候选。关闭即时预览会退出对照并显示实际烘焙结果。

## 求解与导出

风向采用固定的世界 XY 平面。带种子的两组谐波调制风强，平方风强进入角向外力，再与身体惯性、回弹和阻尼共同求解。种子、参数和来源相同，输出相同。

后端以 120 Hz 固定步长计算完整轨迹，约 60 Hz 烘焙，保留误差超过 0.05° 的中间样本。前端使用同一算法重算完整轨迹，再按时间查表；播放、暂停、往返拖动不会累积物理状态。级联发束使用上游求解后的运动作为驱动。

新增辅助骨保持原身体父骨。发根、衣料连接与挂点的固定规则沿用现有生成器。几何保护逐区域降低新增响应增量，不改变原身体动作；降低比例和跳过原因显示在候选摘要中。UV、纹理、原骨骼和绘制顺序沿用既有输出合同。

改动参数后的即时预览使用上一次构建的网格和保护比例，尚未重新执行几何、接触及 Runtime 检查。固定根部、挂点、新增区域和面部改动明确列为需要重新构建。旧下载始终指向原不可变候选，不会把画布草稿当成已验证导出。

循环模式将阵风频率调整为整周期，检查外力首尾、辅助骨位置和速度。风强或风向关键帧首尾不一致时，仍报告循环异常；不会靠减小几何幅度或静态区域掩盖外力不连续。原身体动画自身的循环异常单独保留。

## 数据与兼容性

联合参数新增可选的 `wind` 字段：

```json
{
  "schema": "autospine.wind/v1",
  "enabled": true,
  "strength": 25,
  "direction": 30,
  "gust": 0.25,
  "frequency": 0.5,
  "seed": 713,
  "keys": []
}
```

`hair`、`cloth`、`objects` 的 `wind_response` 及各自 `overrides[slot].wind_response` 取值 0–2。0 表示该区域不受风。旧冻结配置不增加字段、不改哈希；编辑页恢复旧草稿时补充默认关闭的风场。关闭风场的求解结果与原算法一致。

现有 `POST /api/motions/<body-job>/joint-animation` 使用这一配置，继续创建独立候选。`joint-animation.json` 保存风场证据及预览文件哈希。新增 `wind-preview.json` 保存来源矩阵、辅助骨、区域和保护比例，绑定父级骨架、最终骨架及配置哈希。接口只允许从指定任务的已验证候选读取该文件，前端再次核验哈希；资源失败会显示原因并保留实际导出姿态。

## 当前支持范围

- 固定观察角度下的二维响应。身体候选含动态相机旋转时，仍拒绝把相机运动混入惯性；不会据此宣称已经支持真实三维风场或任意 360° 视角。
- 发层须有兼容素材和绑定；服装使用已存在的裙袖辅助骨；挂饰采用兼容的单一父骨。已有多骨局部修形、附件切换和边缘残余会保留或明确跳过。
- 采用辅助骨弹簧与角度限制，没有布料自碰撞、与身体的完整碰撞、气流遮挡或侧背素材重建。
- 新增风场候选仍需阶段视觉验收。已有遮挡和接触缺测不会因本功能通过数值检查而消失。

构建仍执行完整验收链。爱丽丝固定风场任务的次级运动阶段用时约 4.6 秒，已有遮挡阶段约 104.6 秒；不能把整次构建时间理解为风场重算时间。
