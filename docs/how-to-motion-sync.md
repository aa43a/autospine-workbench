# 源动作与角色共用时间轴

动作中心构建区新增“姿态策略 → 源姿态与髋中心（实验候选）”。它通过工作台任务队列生成独立候选，使用同一来源方向、投影长度与髋中心，随后继续接触、几何、Runtime 与下载流程。当前只接受完整片段、原来源视角，不与恒定偏转或躯干投影混用。失败重试保留策略；已有任务省略此字段时保持原行为。此入口尚非默认策略，也不包含后续 margin/肩部实验的自动采用。

从固定动作矩阵进入“集中播放与验收”，选择动作和角色，在左侧播放或拖动时间轴。源骨架显示最近的预览采样，目标使用官方 Runtime 在请求时刻实时渲染。右侧播放控件在同步后锁定，避免两个播放器分别计时。

异常详情中的时间定位也使用共用时间轴，不再重载角色页面。切换角色会清除旧同步状态；候选身份或时长不一致时拒绝同步并显示原因。此功能适用于当前完整片段矩阵，不宣称裁剪片段具有相同时间原点。

“观察视角”可在来源、正面 X/Y、侧面 −Z/Y 间切换，保留时间并使用整段固定画幅；它不会改变目标投影。源坐标的深度符号不能单独当作人体朝向证据。

打开“比较该角色的已有视角候选 → 在当前页比较”后，已核对的替代候选也跟随共用时间轴。异常跳转同时定位两份候选；各自的验收仍绑定各自版本。身份或时长不一致会拒绝同步。

实时观察不会生成捕获证据或保存人工验收。页面下方的“局部修正实验对照”可以打开已登记的实验，与原候选共用时间轴。实验保留原几何、面积保留和深度失败，不提供自动采用或人工验收按钮。

播放器时间轴下方新增“部件与遮挡对照”：选择部件 A/B，切换完整角色、仅看所选或隐藏所选。局部观察保留当前时间与完整角色镜头，方便检查部件交叠；“恢复完整角色”立即恢复。它只修改本次渲染，不改变源附件、绘制顺序或验收。可在 Alice 实验选择 `layer-001-r` 与 `layer-005` 检查右腿和裙摆；缺少独立腿附件的角色不能用该功能推断腿部验证通过。

实际官方 Runtime 检查在 Alice 1.633333625 秒验证隔离、隐藏和恢复，恢复后的原始 framebuffer SHA-256 与初始完全一致；时间未改变，页面错误为零，所有接口请求均为 GET。复验：`tools/check-motion-layer-inspection.mjs`。此结果证明预览操作可恢复，不证明动作或遮挡质量已通过。

三个 squat 的 margin-v1 实验已绑定各自原动作任务。登记工具 `tools/m4_register_pose_experiment.py` 核对原任务、角色、MotionIR、父候选及 Runtime 身份，将精确候选与报告存入不可变存储，保存独立登记记录，不伪造新的 adapt 成功任务。更换原任务或候选身份后拒绝沿用。当前只支持完整、未裁剪的 post-contact 实验。

三个实验均已完成实际浏览器加载与共用时间轴定位检查，同时复测原六组合及红美铃 reach 替代视角，页面异常为零。实验接入仅复用已有捕获，不新增捕获或视觉通过结论。

“检查膝盖方向与深度”按同一源时刻比较髋—膝—踝骨轴，区分投影反转、目标接近拉直、源弯曲藏在深度中。原候选和修正实验都有入口，可跳到各类情况首次出现的时刻。它检查骨轴，不检查贴图轮廓、裙腿遮挡或连续时间；不能将方向一致视为视觉正确。当前裁剪片段明确拒绝，避免错误时间对应。
