## 总目标与现状

用户导入或生成动作后，自动得到保持动作意图、可播放和可导出的整角色候选。支持范围内默认处理；异常定位到时间与部件，可原地调整、重建和恢复。

导入、MotionIR、三角色八动作候选、Runtime 和导出链路已建立，动作质量尚未闭环。仅原三角色 breathing 有阶段接受记录。squat 存在源姿态与支撑约束冲突、腿部压缩和肩部连接异常；reach 存在近正对相机时的投影退化与方向偏差。

最新红美铃反馈重建的 993 帧 Runtime 数值通过，同帧接触最大误差由 1.132525 降为 1.132524 px，但原 setup 几何未通过、深度待复核，未采用。证据位于 ../tmp/m4-motion-center/source-axis-feedback-rebuilt-hongmeiling-v1/report.json。Alice 共享时间清单的反馈实验通过骨架检查，尚不能推定最终网格与 Runtime 通过。

## 里程碑一：解决 squat 与 reach 的实际失真

固定 Alice、辉夜、红美铃 × squat、reach 六项，提供同时间源 3D 正侧视与最终角色对照。

| 顺序 | 工作包与交付 | 验收标准 |
| --- | --- | --- |
| 1 | 统一求解、骨架、网格、Runtime 的检查时间清单与失败归因 | 最终新增采样不漏检，同一异常能在播放器准确重现 |
| 2 | squat：联合处理源姿态、脚部支撑、连续性，修复腿部额外压缩与肩部连接 | 接触、原几何和连接共同通过；下蹲方向与动作意图正确 |
| 3 | reach：可靠区间保留源方向和时序，退化区间结合深度、邻帧与弯曲平面 | 不出现非源动作导致的突发半圈；不以冻结、删帧或限幅冒充还原 |
| 4 | 深度遮挡：源深度、部件拓扑、稳定排序及必要的最小分区 | 手身、裙腿前后关系合理，排序变化无明显闪跳 |
| 5 | 六项整段播放、技术检查和阶段验收 | 精确候选技术通过且视觉可接受，三项 breathing 无回归 |

六项分别报告完整支持、受限支持、需补素材和技术失败。失败项保留在分母，有诊断结论不等于通过。不得以 Runtime 数值成功代替几何与视觉成功。

下一切片先完成已有反馈候选的统一采样核验，再针对最终失败帧修复网格。reach 必须在本里程碑内交付，不能被持续 squat 调参挤出。

## 里程碑二：默认适配与异常修改闭环

统一工作台源动作/角色播放器、动作选择和可拖动时间轴，异常可点击定位。按来源观测可靠性和素材能力选择版本化策略；提供视角、保守幅度和局部修正的对照重建及撤销。幅度调整必须可见，不声称保持原动作。

验收：三个角色各走通导入或生成 → 自动适配 → 异常定位 → 修改 → 重建 → 导出 → 恢复。播放、检查、下载对应同一候选；旧人工决定不丢失。来源缺少深度或关节信息时明确标记，不静默套用完整策略。

## 里程碑三：冻结策略并推广

先验证三角色八动作 24 项，再扩展首批十角色。失败与不支持项不从分母删除。分别统计动作支持率、技术通过率、阶段接受率、人工干预次数与实测时间、自动耗时。默认采用不是人工正确性抽查；错误率只使用实际抽查分母。

验收：固定集合每项具有来源、策略、候选与验收记录，支持范围有实际播放和导出证据；同一冻结策略能跨角色使用，新增例外单列。

## 范围和停止条件

脸部、发型次级运动与更深服装模拟保留为后续独立能力包。当前 3D 主要提供深度、弯曲平面、朝向和投影证据；完整三维重建与全面三渲二不进入本轮。缺失侧背面或手掌素材需要补素材，不能靠无限形变解决。

每种局部算法先验证失败帧，改善后才跑整段。连续两轮没有实际改善，转向拓扑、表达能力或素材问题分析；不继续只调参数，不放宽原门禁。角色名、图层编号、三角形编号不能成为通用算法条件。

按来源观测、投影、支撑、局部变形、遮挡、验证和 UI 拆模块，维持文件长度约束。每个切片交付可播放改善或能改变下一决策的证据，实验通过统一验收后才接入默认策略。
