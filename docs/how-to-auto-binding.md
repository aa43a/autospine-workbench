# 一键处理安全绑定

在“绑定规划与复核”的“自动绑定与异常复核”区域，点击“一键处理所有安全绑定”。无需先点检查；如果只想查看候选，可使用“检查可自动绑定项”。

系统使用现有策略检查已复核头颈锚点、紧凑脚部和已绑定面部的眼口细节。每轮采用后重新读取当前来源、再次检查依赖项；没有安全项时结束，其他项保留在异常列表。已有人工选择和带说明的待复核项不被覆盖。准确率没有因连续执行而变成已校准。

每批决定仍独立保存为 policy_auto，可从撤销批次列表检查和撤销。多批有依赖时优先撤销后产生的批次。一次运行最多 32 轮；重复命中、无进展、来源变化或错误会停止。已保存批次仍保留，界面刷新后显示实际状态，可以核对再继续，不会把一次点击伪装成全有或全无的事务。

返回的 binding-auto-run/v1 只是本次操作摘要，引用已保存的内容寻址决定，不替代其身份。采用绑定可能使下游候选失效，需要重新构建；不会提交视觉验收或发布。
