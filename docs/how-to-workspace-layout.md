# 按步骤使用工作台

主界面将构建和复核移到中央工作区，右栏只保留选中图层、关节属性及校正备注。

1. **素材检查**：查看原图、图层与关节点，在右栏编辑所选对象，使用顶部保存校正。
2. **绑定规划与复核**：在「全角色规划」查看分类和缺失前置证据；定位后进入「图层绑定」。切换到「关节复核」拖动标注，或在「来源准备」同步已保存校正。
3. **动画预览**：选择动作、构建候选并播放。异常集中在底部队列。
4. **导出**：构建静态 Spine 预览并下载；动画候选下载保留在动画预览页。

底部「异常队列」按动画、静态、素材 QA 切换。点击定位将打开对应画布或绑定表单。
「报告与证据」集中放置能力、候选、拆分与 Mesh 详细证据。

切换工作区只移动和显隐原有控件，不重建表单、不保存草稿、不自动批准绑定。
未保存修改与构建门禁继续生效。规划、关节和播放的放大入口仍可使用。

服装与分区的下一步见 [R3-A 前置检查](milestone-r3a-garment-readiness.md)。
