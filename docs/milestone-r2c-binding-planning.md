# R2-C2：完整角色绑定规划与异常复核闭环

本里程碑把离线 Rig Planner 接入主工作台，让每个源图层都有可解释的处理路径，并能定位到现有绑定复核入口。
验收范围为 lumia、huiye、uuz、yaomeng 四个可见测试角色。保持三个开发样本及 holdout 的用途，不逐图添加特殊规则。

## 交付与验收标准

| 交付 | 验收条件 |
| --- | --- |
| 全层规划 | 每个源层恰好出现一次，含原始层名、已保存决定、策略、原因及后续动作 |
| 真实几何证据 | 读取精确 PNG 字节、alpha 连通域和骨段可见像素采样；空图或缺图不能伪装成可用方案 |
| 类型化路径 | 刚性、加权 Mesh、分区 Mesh、眼口、次级运动、语义/拆分复核六类；不支持的路径明确保留异常 |
| 工作台闭环 | 一次点击生成规划；分类筛选并定位图层，使用既有复核保存流程；保存后旧规划失效，可重建新规划 |
| 精确来源 | 绑定当前项目、candidate、skeleton、bindings、draft 身份；源变化不显示旧规划；相同输入复用内容寻址报告 |
| 保持复核边界 | 生成规划不变更任何绑定决定、不创建人工批准、不授予生产权；编辑未保存或正在构建时禁用分析 |
| 工程质量 | 独立小模块，保留原 Rig Planner 合同与算法；文件长度、API 边界、来源与 UI 回归通过 |

规划闭环与整角色动画验收是两个不同范围。这里完成的是可测量的处理路径与复核入口；宽袖/裙装多链权重、次级运动 Bake、残余像素归属及完整 Runtime 视觉验收仍属于后续 R3/P5 工作。

## 实现步骤

1. 复用 `autospine.rig-plan/v1` 和 `semantic-alpha-bone-strategy-v1`，增加项目级准备、内容寻址报告与当前来源读取。
2. 在主工作台新增「全角色绑定规划」面板，展示证据、六类处理路径和定位入口，不新增第二套决定存储。
3. 用四角色全量层集合验证覆盖、缓存一致性及生成前后决定不变；测试保存新决定后重建规划。

## 操作方法

打开工作台的「可变形动画候选预览」，展开「全角色绑定规划」。
默认启用「自动分析当前来源」：来源已保存且工作台空闲时，先读取缓存；没有当前规划时自动分析一次。失败后手动重试，不循环请求。可取消勾选，在本次页面会话中改为手动分析。
按规划类型筛选，查看角色底图上的分类颜色和图层范围。点击矩形或用「选择规划图层」下拉框选择重叠部件，再点击「定位选中图层复核」检查已有绑定选项。「放大绑定规划」可打开完整角色视图；定位复核时自动返回侧栏。
矩形表示源图层 bbox，不是像素分区、骨骼影响范围或已求解的权重图。列表保留连通域、骨骼采样证据和后续建议。
在现有「图层绑定复核」保存明确决定后，重新分析规划，查看更新后的当前决定。没有支持方案的层保留待复核、语义复核或拆分说明。
规划不会自动启动动画构建，也不会把已选择绑定等同于通过 Mesh 或 Runtime QA。

本轮四个测试项目的规划已生成，刷新页面即可读取。
