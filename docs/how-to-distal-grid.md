# 踝／腕局部网格加密实验

在已经精确回放的 `partition-full-alpha-supported-v2` 上增加远端关节附近的横纵支撑线。
不修改旧工件、绑定决定、原始图层或残余归属。当前三个角色八个区域仍阻塞，不能用于正式导出。

```powershell
python -m autospine_workbench.benchmark.distal_grid_cli --manifest docs/benchmark/manifest-frozen-v1.json --workspace .. --mesh ../tmp/r2b-region-mesh/alice-coverage-v2.json --html ../tmp/r2b-distal/alice-density-v1.html --output ../tmp/r2b-distal/alice-density-v1.json
```

这是独立的实验 CLI，避免继续扩大 benchmark 主入口。报告包含新网格、修正样本、前后对比及精确来源地址；
使用现有 16 MiB 内容寻址存储。`read_experiment` 从旧网格及其分区、骨架、图像来源重建并逐字节校验结果。
JSON Schema 为 `distal-grid-experiment-v1.schema.json`，复用现有网格字段与 corrective 合同。

## 固定实验条件

- 支撑线间距为 `max(1, floor(相邻两根远端骨骼中较短长度 / 4))`，局部半径为同一较短骨长。
- 插入横纵轴坐标后使用共享网格线，形成贯穿相应行列的支撑带，避免 T 接缝；不声称只改变圆形关节区域。
- 保留 alpha≥8 的可见主组件门槛，实际网格覆盖所有 alpha≥1 像素。
- 不改变三骨权重规则、48 次投影、9 个远端角度或原有 QA 阈值。
- 位移预算仍为较短骨长的 10%，相对于半角基底；纯单骨顶点固定。
- 单骨鞋区原样保留，三骨区域重新检查全部 27 个单关节探针；corrective 只检查 9 个远端探针。
- 新网格仍受 4096 顶点、8192 三角形与报告大小限制，超限阻塞。

## 2026-09-08 结果

十二个区域均无 alpha 漏覆盖；八个远端区域的混合权重顶点从 2–6 个增至 53–76 个。
四个单骨鞋区保持原结果，八个远端区域仍然阻塞。部分小角度改善，另一些小角度退化；
八处最差面积比全部变差，因此不采用本方案作为新的默认网格。

细分改变三角形总数，不能直接把“翻转三角形数量”当作跨网格改善指标。
对照页展示相同角度的失败数和最小面积比；红线为加密后的原始 LBS，青线为加密后的修正结果。
淡色原图仅作 setup 参照，不是纹理动画。

最差失败三角形的三个顶点都属于混合权重区，半角基底在投影之前就已有负面积。
这排除了“仅增加混合顶点即可解决”的假设，但尚未证明唯一根因。
下一步应独立试验由 alpha 横向宽度约束的权重过渡，记录过渡宽度、基底面积和位移预算之间的关系，
保持当前失败样本作为回归基线；不得修改骨骼位置或放宽阈值来掩盖问题。

24 项针对性测试通过，包括无 T 接缝、低 alpha 岛覆盖、setup 重建、同预算、输入不变、
非法来源、资源上限及篡改拒绝。三个真实报告通过 Schema，Alice 完整来源回放通过。
三个旧corrective的内容地址保持一致，四个刚性鞋区逐字段不变。
本次未运行完整 Python/Web 套件或官方 Runtime；组合动作、接缝、连续插值和发布授权仍未验证。
