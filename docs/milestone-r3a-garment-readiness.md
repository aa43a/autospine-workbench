# R3-A：服装与分区候选前置检查

全角色规划中，`weighted_mesh`、`partition_mesh` 和 `semantic_review` 现在附带当前来源的前置检查。
通过现有项目规划接口读取，不改变 `rig-plan/v1` 的历史内容地址，也不保存绑定决定。

## 如何处理

在全角色规划中定位有前置问题的图层，进入对应复核：

- 语义缺失或语义异常：明确该层实际物件及是否需要拆分；名称推断不能代替明确语义。
- 分区候选：需要真实分区归属工件；多个 alpha 连通域不代表已经完成左右归属。
- 单个连续图层：只有明确语义、唯一 2–3 骨选项且所有骨段都有 alpha 采样支撑时，才列为可继续几何复核。
- 多选项、支撑不足或多个连通域：保留阻塞原因，不能自动转成可导出的 Mesh。

检查结果的 `needs_review` 仅表示下一项检查可定位，不表示网格生成、权重正确、接缝安全或 Runtime 通过。

## 合同与边界

`autospine.rig-plan-readiness/v1` 引用当前输入身份与规划内容地址；使用独立的
`garment-partition-readiness-v1` profile。纯分析器复核绑定候选内容地址、图层清单和纹理身份，
并提供逐字节结果重放验证。现有 GET/POST 项目规划响应可携带该结果。

不改动已保存的候选规划、绑定草稿或正式工件；不根据 `bind` 状态跳过缺失的几何证据。
