# 相邻三角形联合覆盖候选

`aligned-low-alpha-union-v2` 使用同一网格的三角形联合覆盖，允许纹理像素跨越
内部三角形边界。旧版 `aligned-low-alpha-v1` 保持原结果，默认选项不变。
工作台勾选残余归并后，可选择“相邻三角形联合覆盖（候选）”。

算法将像素转换为单位正方形，逐个减去三角形覆盖的凸多边形区域。
只有剩余面积不超过 1e-9 个像素时才判定覆盖；不累计重叠面积。
UV 对齐、唯一来源、alpha 1–7、目标透明等原有约束仍有效。
不扩大网格，不改权重，不删除网格外像素，不自动确认绑定。

两角色使用同一规则，无角色名称或逐图参数：

|角色|旧版转移|新版转移|剩余|
|---|---:|---:|---:|
|辉夜|1006|1052|54|
|小恶魔|754|844|42|

`a1ecade72a5c001f7d8fc385d30ceda10c0d9ccd2fa3eb2180a6c4836406083a`。
辉夜旧版重跑仍为 `7d6c2f7dbe5a6edbc65b7de7001f9d8b241a89f388948a99ee584d58656f993e`。

测试覆盖内部空洞、重复覆盖、部分边界、三角形顺序和绕序、坐标旋转缩放、
旧版重放及纹理冲突。候选必须继续通过实际 Runtime 验证和视觉复核。

官方 Runtime 两角色共 3,737 帧通过（辉夜 2,062、小恶魔 1,675）。
同帧图像对照分别为 27、21 帧；证据为
`benchmark/character-texture-union-huiye-v1.json` 和
`benchmark/character-texture-union-xiaoemo-v1.json`。
这是采样数值及图像证据，不代表人工视觉采用。
