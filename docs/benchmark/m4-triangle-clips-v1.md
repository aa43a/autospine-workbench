# Reach 固定四顶点普通裁剪实验

2026-09-22。候选未采用，M4-A 尚未完成。

## 实现与身份

对源手臂三角形上的线性深度场生成两个互补半平面，以非退化矩形普通裁剪表示。所有裁剪保持四个顶点，通过 deform 时间轴变化；不使用 inverse，不改变纹理、UV、骨骼轨迹或原加权 deform。裁剪只覆盖对应三角形，前后副本分别放在躯干前后。编译器复用已有加权顶点及 deform 压缩。

来源：Alice Reach torso-reference-v2/0，准确身份如下，避免依赖路径名称：

- 父候选：`21969ed99dd41e85171f52842fc4754a8d8c4bd425fd722cf87a78ce94b9d437`
- 新候选：`971b6206f3eec435e1d0767bdc4ea1fbce3b0e16ddfef0ab40c237aae9e77c78`
- 输入：`tmp/m4-motion-center/reach-depth-field-v1/report.json`，包含 241 个时刻的顶点坐标和深度值。
- 输出：`tmp/m4-motion-center/reach-triangle-clips-v1`（相对 localset）。
- 目标 Spine 4.3.26；实际官方 Runtime 4.3.13，JS 摘要与 scene 摘要记录在 reconstruction/report.json。

## 实际结果

源网格 394 个三角形：275 个在所采样时刻均位于前方，119 个需要动态裁剪。119 个三角形的前后副本和裁剪，再加静态部分，共 477 个隔离手臂槽位；不是 477 个原始角色图层。

官方 Runtime 实际加载同一个连续 skeleton，在 241 个键时刻及其中点，共 481 个时刻绘制整条隔离手臂：

- 新增不透明像素缺失为 0。
- 8 个时刻存在超过 8/255 的预乘颜色/alpha 差异，每个时刻最多 1 个像素；最大差异 71/255，发生于 1.29166675 秒。这里的 8/255 只是差异统计阈值，不是放宽验收线。
- 移除全部手臂的负对照确实检测出缺失；从末尾回退起点，像素结果完全复现。
- 同步播放器检查通过：身份、同步时间、播放暂停与回退；已查看 2.4 秒整角色对照图，肩部外观仍不能据此判为自然。
- 两个隔离动画 481 时刻的绘制、读回和比较共约 9.56 秒。这包含检测开销，不是实际播放器帧率。

新增 scene 为 51,880,886 字节，原 scene 为 21,569,390 字节，均包含纹理。当前槽位数量及数据增长不适合作为未经优化的默认方案。

## 测试及下一步

13 个相关单元测试通过，覆盖半平面正负分类、镜像绕序、常量场、非退化矩形、非法输入、加权 UV/deform 保持，以及原裁剪/顶点压缩回归。

下一步检查哪些相邻三角形可以共享同一裁剪平面并保持误差约束，减少槽位和重复时间轴；不能无限细分。还需验证深度边界插值、整角色遮挡、肩部材料轮廓与实际播放性能。零像素缺失仅证明当前采样的重构性质，不证明遮挡语义或连续时间质量，不推广其他角色，不继承旧视觉接受。
