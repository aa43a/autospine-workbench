# 膝部局部 UV 假设验证

2026-09-22。原候选 `051cb629d2a3f1b963c03ebbef3d585d0c3e1c551705d9e57a7b83f423c2d918`；隔离实验 `c721a1a969e4eb0216504a47ed8eb85ef3e33d582602e8db2d23199d4a8e0084`。实验未采用。

从原绑定姿态的 calf/thigh 锚点反查源 UV，以原骨链长度确定膝部局部范围。仅沿截面收缩源纹理坐标，强度 0.4、最大位移 16 纹理像素，范围外不变；拒绝 UV 翻转。算法不使用截图中的凹口像素作输入，未改变骨骼、动作、权重、网格顶点或原纹理字节。

## 实测

- 双腿分别移动 75、69 个 UV 顶点，最小 UV 面积比约 0.600，未翻转。
- 5 个关键时刻的官方 Runtime 数值通过，最大位置误差 0.0001084 px；仅为 5 个样本，不替代原 2169 时刻验证。
- 原姿态源图对照器拒绝非线性 UV：`character_setup_source_transform_unsupported`。总捕获流程保持失败；随后只导出已验证数值的诊断播放器，没有跳过门禁宣告通过。
- 统一原候选相机后，重复 15 张隔离/完整画面捕获。0.9 秒原两个凹口中心的 framebuffer alpha 从 0 变为 255。
- 查看图像，凹口中心覆盖改善，但膝部线条/阴影仍有折叠感；这不证明整个区域自然。大腿面积失败继续存在。

## 限制和下一步

这是静态 UV 试验，原姿态映射也改变，不能直接成为默认动画；两个探针改善不等于全轮廓通过。下一步需要保留原姿态的按姿态启用方案，并验证透明轮廓增量、线条拉伸、切换连续性及遮挡。不能通过无条件扩大纹理覆盖来换取“无裂缝”。

产物：`localset/tmp/m4-motion-center/squat-joint-uv-v1`，`probe.json` 保留未采用与管线失败状态，`uv/runtime` 包含数值捕获和诊断播放器，`isolation` 包含同相机对照。
