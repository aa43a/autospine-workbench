# 异常区域编辑：实际笔刷命中与路线说明

2026-09-24。检查肩部遮挡修正入口时发现：当前 partition 操作是刚性重绑，
不是遮挡区域策略。其名称由“重新划分区域”改为“区域刚性重绑”，
明确会改变选区权重、不调整前后顺序；后端 action 和历史记录格式保持不变。

修正同一编辑器的选取缺陷：原先只判断三角形中心是否落在笔刷内，
大三角形边缘会选不中，稀疏 pointermove 也会漏掉途经区域。
现在使用笔刷圆及两次事件之间的扫掠区域与三角形相交测试；
沿边、内部、线段穿越均能命中，退化 UV 三角形不全局命中。
松开、取消、丢失 capture、清空、切换路线和恢复草稿均结束当前笔画。

保存仍绑定精确候选与 mesh SHA；没有自动保存、构建或采用。
同一编辑器的 textureOnly 模式继续保持原权重，未改其合同。
