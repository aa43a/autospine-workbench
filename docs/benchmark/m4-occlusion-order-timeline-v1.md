# 覆盖区整段顺序预检查

2026-09-25。覆盖区原预检查只显示标注事件所在时刻，现在同一返回结果新增整段绘制顺序区间，前端在“整段动作的前后顺序”中展开查看。

区间采用 Runtime Float32 时间、左闭右开；末帧单列，防止把最后一帧恢复 setup 顺序误报成整个前一区间。相同顺序合并，零时长动画只报告端点；超过 1024 个绘制顺序关键帧返回未检查，不算通过。复用原先的非法关键帧、时间碰撞及 slot 身份校验。

这只是确定的绘制顺序，不代表纹理重叠或衣料真实深度。当前时刻的覆盖标注不会因此延伸成整段的人工决定；时间表不改变原预检查门禁、不修复、不自动换序，也不清除异常。
