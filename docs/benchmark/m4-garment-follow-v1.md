# 三结构裙腰随躯干位移验证（2026-09-26）

此前 Alice 裙腰修正只有单例实验，本切片把相同计算提取到
`attachment_root_bake.build`，再对 Alice、辉夜和红美铃的固定下蹲候选做成对比较。
算法只平移已经声明的服装辅助骨链的材质影响，不改变骨骼运动、权重、UV、原图、
绘制顺序或其他附件。没有恢复肩部覆盖区约束，没有改用角色名称分支。

## 复用与前置条件

输入为已烘焙的躯干候选、声明的辅助骨链根部及完整检查时间。
从原角色的 `skirt-trial.json` 读取已确认 chest 裙腰及生成骨链记录，
核验 bones / skins / slots 与候选一致；不从空间最近骨骼猜测服装归属。
重复祖先、已继承 chest 的根部、不支持的来源范围、无有效权重和非加权网格会拒绝。
只替换目标附件的 deform，保留已有其他属性。Float32 重合时间在可表示时刻重新计算，
独立检查仍保留所有原检查时间，并加入新关键帧及中点。

模块已供现有独立实验工具复用，**尚未接入默认构建或自动采用**。
先通过三结构技术验证，不把完整动作质量、视觉验收或新 GPU 捕获推定为完成。

## 验证身份与限制

三例再各取 129 个均匀时刻，在 Node 中用与现有环境 SHA 一致的官方 Runtime **4.3.13**
重新读取目标 Spine **4.3.26** 动画，检查受影响网格的世界顶点。
最大误差分别约 0.000101、0.000171、0.000163 px，小于 0.01 px 数值检查门槛。
这是 129 时刻的官方 CPU 顶点验证，不是 3,713 帧官方捕获，也未运行浏览器或生成新 GPU 图像。

10 个测试通过，覆盖根部/后代位移、重复变换拒绝、旧属性保留、来源范围、
Float32 时间、独立合并及原失败检查点保留。
当前代码重算三例 skeleton SHA 与已测文件一致；原候选、默认策略和人工记录未改动。
