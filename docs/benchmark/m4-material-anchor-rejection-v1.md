# Reach 肩部材料锚点：三结构反例

2026-09-24。此实验不改变默认工作台、源动作、历史候选或人工验收。
输入为 `reach-live-yaw-comparison-v1/torso-reference-v2/{0,1,2}` 的不可变
AnimatedStore 产物；逐项校验 `reach-depth-replay-v1` 的候选身份。

## 假设与边界

setup 中被躯干 alpha≥254 遮住、自身 alpha≥8、距肩根不超过上臂长度
0.65 倍的网格点，作为候选材料锚点；用躯干三角形重心坐标携带它们。
上臂长度范围内的其他顶点解调和位移，外围顶点保持原姿态。
遮挡是几何证据，不是这些点实际缝合在躯干上的语义证明。

仅检查原动作 0、1.725、4 秒，未烘焙新 Spine 动画或进行新 Runtime 捕获。
独立几何门槛仍为面积比 0.5–2、边长比≤2、零翻转。

## 约束必要条件检查

新增网格最短路径反例检查：任意两个固定端点的目标直线距离若超过
它们 setup 最短网格路径长度的两倍，则路径内至少一条边必然超过
当前两倍边长上限。检查保留端点、路径和所需最小拉伸比。

三角色九姿态均未找到此反例。**未找到反例不证明可行，也不能证明
锚点语义正确**；本次失败只否定当前锚点选法与调和平滑的组合效果，
尚不足以否定所有满足固定条件的网格解。
