# 同片段视角取舍接入工作台

入口：动作中心或集中验收页 → 检查膝盖方向与深度 →
比较视角对膝盖、手臂和躯干的影响。

对当前候选绑定的真实来源和片段计算 −90° 至 +90°、间隔 15° 的 13 个视角；
当前角度若不在网格内，额外保留该角度。旧命令行扫描与产品接口复用同一肢体
投影实现。各视角同时显示膝部最大隐藏弯曲、至少损失 30° 的腿部采样、
手臂投影长度不足原长 20% 的采样和来源躯干检查。缺少躯干证据保持“无法观测”。

读数仅用于比较，不推荐或自动采用某个角度，不改变角色、纹理、动作和原验收。
来源躯干范围内不等于正面角色素材支持该视角。侧背面缺图、关节轮廓、
接触和服装遮挡仍需在实际角色候选中验证。

“定位”跳到当前候选的相同源时刻，不显示所列角度的新候选。
裁剪片段保留独立的播放器时间和原动作时间；后端核对 MotionIR、来源角色及
片段身份，前端拒绝错误候选、缺少视角、无效计数与错用源时间的定位。
