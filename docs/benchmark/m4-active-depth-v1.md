# 切换附件的重叠检查

2026-09-25。修复任务的重叠检查现在按当前活动附件选择网格、UV、纹理和 deform。独立 ActiveProbe 每个时刻构造精确视图，保留旧固定网格 Probe 的限制，避免其表面深度消费者误读新的附件拓扑。采样记录保留活动附件名称；隐藏附件为零重叠。像素预算跨帧累积，已测结果可以复用，逆向拖动不沿用其他时刻的纹理。

character_capture 超时预算改为读取数值参考的真实帧数，不再从分附件几何记录反推；附件分段不会低估完整捕获时长。

12 项相关测试通过，覆盖透明贴图切换、另一个 deform、正反向采样、恢复原附件、隐藏、结果复用及原重叠检查回归。没有执行新 GPU 捕获。源动作深度仍是代理数据，本轮只修复实际投影重叠测量，不证明新视角表面深度或复杂遮挡正确。局部表面深度模块仍需单独适配或明确报告不支持。
