# 修正不得加重已有压缩：独立约束实验

## 原因与约束

固定修复带使用投影参考的 0.5 下限，会允许邻近三角形比原权重结果更小。已有 from_pose 保护上限为参考面积的 1 倍，因此原权重面积虽小于 setup 的 0.5、但大于投影参考时，仍可能被缩小。

新增显式 `raw-compression-preservation-v1-experiment`：对原面积为 setup 的 0–0.5 倍的三角形，要求结果不低于原面积。反转不作为应保留形状；原过度扩张不锁定。若与原投影面积上限冲突则明确拒绝。旧调用仍只允许 0.5–1 范围下限，新合同显式允许到 2；原几何 QA 未更改。
