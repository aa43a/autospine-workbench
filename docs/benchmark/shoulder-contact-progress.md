## 第一版过渡实验：不通过

`build-shoulder-transition.py` 已提供独立候选入口。采用同一源重叠检测，以 0.35 倍上臂长度平滑衰减胸部权重；增加影响骨时同步展开稀疏 deform，并保留原零权重影响项的偏移位置。原始纹理、三角形、骨骼及非选中附件动作不变。

爱丽丝实验地址 `23a316ce0755fc4bea3e86c7ee85e865a189145ebc23e4b0505b1ce23d57d604`，setup 最大误差 1.28e-13 px。四动作 1028 帧检查中，walk 双臂分别 75、95 帧压缩超限；wave-left 左臂 233 帧失败，面积比最低 -2.3563，最大边长倍率 4.965。候选 blocked，未进入官方捕获，未替换工作台选择。

这反驳了“将全部近端重叠像素直接固定到胸部就足够”的方案。下一版应约束局部连接边界，同时给相邻袖布留下变形自由度；不能放宽几何门槛或减小原动作来掩盖失败。稀疏 deform 与零权重影响项的重映射已有独立回归测试。

## 局部边界与自适应时间采样

第二条路线只固定有源 alpha 接触支持的近端网格边界，允许邻近袖布通过现有局部形状求解器调整；远端顶点保持原动画。相同参数用于三角色，不含角色名规则。只对稠密检查失败的插值时刻追加求解，最多三轮、每附件每动作最多 257 个求解点；预算耗尽或仍失败时保持 blocked。

- 爱丽丝：全部几何检查通过；挥手边界点最大误差 0.3705 px；官方 Runtime 2,156 帧通过。
- 铃仙：全部几何检查通过；挥手边界点最大误差 0.3544 px；官方 Runtime 2,138 帧通过。
- 露米娅：仍有两个挥手中间帧翻转，未运行新候选的官方捕获，保持 blocked。原工作台候选不变。

三者骨骼、slot 顺序、皮肤/权重/UV、源 PNG 和 Atlas 完全不变；未选中附件和远端固定顶点的动作误差均为 0。稠密最大位移单独计量，不能用较少的求解关键帧峰值替代。完整来源、失败记录和 Runtime 摘要见 [三角色证据](shoulder-boundary-progress-v1.json)。这仍不证明连续时间、视觉连接或通用自动采用完成。

可重复入口：`build-shoulder-transition.py --boundary` 生成初始边界候选；`--refine-trial SHA` 从相同源候选精确补充失败时刻。参数仍需 `--state-root`、`--character` 和 `--output`。工作台尚未自动选择这些实验结果。

爱丽丝同帧复核页位于工作区 `tmp/character-shoulder-boundary/alice/comparison/index.html`：九个挥手时刻、相同相机及官方环境，可拖动并播放离散帧。捕获工具支持按动画补充指定精确时刻；不存在的时刻明确失败。对照工具核验报告来源与截图摘要，不使用近似时刻冒充同帧。人工视觉接受尚未记录。
