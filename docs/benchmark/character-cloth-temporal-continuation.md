# 帧间约束与连续初始化

2026-09-12。仅更新独立布形试验，不修改工作台当前角色、人工决定或动作登记。

## 实现

新增线性世界路径面积极值检查，以及使用实际 Spine 骨矩阵的子帧映射。
后者把子帧位置表示为下一求解姿态的仿射函数，包含多骨权重、原有 deform
和左右端点的旋转变换；每个求解区间检查 1/4、1/2、3/4 位置。
仍需独立密集验证，不以三个子帧样本声称连续时间证明。

约束求解新增可选上一帧世界姿态初始化，避免先经过静态 ARAP 求解后跳入另一形状分支。
既有 v1 行为仍保留，新方法有单独 profile 和显式开关。

修复 deform 叠加：原时间轴和新增量在全部关键时刻的并集上相加。
这保留原时间点之间的极值，固定顶点的原修正不再被粗采样覆盖。
非线性曲线明确拒绝；新增带中间极值的回归测试。该修复没有独自消除真实中点失败。
