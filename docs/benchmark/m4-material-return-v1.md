# 姿态素材回交入口

2026-09-23。推进 M4-B 的异常处理链路；尚未完成素材映射及重建。

入口：动作候选 → 变形区域与处理方案 → 当前异常的处理草稿。
保存“补充姿态附件”后下载任务包。在“回交姿态素材”选择包内 request.json
及修改后的同画布 RGBA PNG，保存后可“查看已回交版本”。

服务端重新生成当前任务身份并逐字段核对。候选、异常事件、处理草稿、原纹理
任一不匹配均拒绝；撤销/覆盖草稿后旧任务不能回交。校验与发布处于同一任务锁。
图片限制 8 MB、1600 万像素、单帧 RGBA PNG、原画布尺寸，校验解码完整性。
图片原字节和 request.json 存为不可变内容寻址包。重复提交相同内容幂等，
不同图片保留不同版本，不覆盖历史候选。未修改原纹理会明确提示，不伪称修复。

API：`GET/POST /api/motions/{job}/material-return`。
POST 接受 `{request, png_base64}`；采用现有同源及 mutation intent 检查。
GET 返回历史回交记录；它不代表当前草稿已采用这些图片。

验证：15 项后端测试覆盖既有任务包/草稿及新增回交，包含不可变存储恢复、幂等、
错误角色/候选/附件、撤销、损坏 PNG、尺寸和颜色模式。
独立 Chrome 组件测试覆盖跨任务阻止、文件选择、提交编码、成功提示及隐藏过期入口。
浏览器测试使用模拟 HTTP，不是运行服务的端到端导入验收。

后续必须完成：局部区域/UV 映射、姿态适用时段、独立候选构建、Runtime 与视觉验收。
本次没有新美术素材，没有宣称 Reach/Squat 表达已修复，也没有改变默认采用策略。
