# 工作台独立覆盖区

2026-09-25。承接 Alice 披肩覆盖袖子的人工结构确认，修正原编辑器把
“允许滑动的遮挡区”与“沿边滑动约束”混称的问题。

## 已实现

衣料连接画布新增紫色 `occlusion`（覆盖区，可相对滑动），旧 `sliding`
明确显示为沿边滑动约束区。两者分开存储，旧记录不自动迁移。
覆盖区保留原运动，不产生固定材料点目标或沿边约束；与固定区共享且
要求不同运动的顶点继续报冲突。与过渡区共享的顶点也保留原运动。

预检查单独返回 `rendered_overlap_not_checked`，界面说明仍需实际画面检查。
没有局部约束冲突不等于遮挡通过，更不等于整段动作可采用。
该类型仍是处理草稿，未接入自动修复执行器或改变动画绘制顺序。

新草稿兼容旧三类和四类请求，加入空覆盖区字段；已有持久化历史不重写。
不根据一句结构确认生成用户未画过的三角形标签，也未替换 Alice 已有
姿态附件草稿或阶段验收。
