进行了只读盘点。字节 SHA256、文件大小、画布、PNG alpha bbox 与 PSD 层名见

## 实测结果

- 20 张 PNG 均为 RGBA，均含透明像素；画布为 1024×1536、1086×1448 或 1536×1024。
- `png/芙兰朵露.png` 为 1536×1024 横幅，尚不能称为统一正面全身输入集。
- 18 张 PNG 的非零 alpha bbox 触达至少一条画布边缘。它可能包含细小残留像素，
  不等同于人体被裁切；需结合可感知 alpha 阈值、连通域与人工图像复核判断。
- 12 个新增 PSD 均可读取，全部为 1024×1024 或 1280×1280，像素层为 18–26 层。
  首轮盘点只读取层元数据；随后仅对 alice 做了隔离审计，结果见下文，未评估绑定质量。
- 32 个文件的字节 SHA256 均不重复；这不能证明不存在视觉近似或同角色变体。
- 已排除 `seethrough_output.psd`、`seethrough_output (2).psd` 和
  `seethrough_output (5).psd` 三个历史文件，未修改现有成功或失败基线。

## alice 单样本隔离审计

2026-09-07 完整阅读既有审计脚本后执行了一次 alice 审计；脚本仅读取源 PSD、
调用本地图像库并向指定输出目录写入派生图片与报告，无模型或网络调用。
执行前检查目标目录不存在，随后运行（工作目录为 `localset`）：

```powershell
python tmp/psd_audit/audit_psd.py alice.psd --output tmp/psd_audit/benchmark-2026-09
```

退出码为 0。输出位于 `tmp/psd_audit/benchmark-2026-09/alice/`，未写入 `results`，
未接入项目发现或生成任何人工决定。27 个输出文件包括 `audit.json`、`composite.png`、
`embedded_composite.png`、`layers_contact_sheet.png` 和 `layers/` 下 23 张图层 PNG。
源 PSD 的审计后 SHA256 与 inventory 完全一致。
