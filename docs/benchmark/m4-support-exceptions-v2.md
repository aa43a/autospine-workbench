# M4 集中异常索引

支持范围报告增加技术异常、证据待核实、阶段结论待处理三组索引。
固定候选、已登记的独立改进和替代视角逐个保留身份；点击定位可到达对应报告详情。
索引条数是检查事项数，不是失败角色数、错误采用率或通过率。
工作台生成报告后可直接打开，不必先下载。JSON 同时保存 `exception_index`。

已有阶段接受不清除技术失败；基线接受不传播到替代候选。过期结论、缺失检查、
无法读取或不完整的比较清单继续作为待处理项。导入的局部视觉结论不当成整候选接受。
读取和导出不修改任何绑定、候选、验收或默认采用状态。

未登记的本地实验明确不在工作台清单内。尤其 Alice −55° 下蹲的局部修复实验
仍是独立诊断：17,452 个时刻 Runtime 数值与采样几何通过，不抵消 254 个材质
覆盖失败时刻。固定 UV/纹理/拓扑下，8px 裙片与 2px 腿部预算不能覆盖全部已定位
露出区域；后续应处理姿态／视角表现，不继续将几个点的覆盖当成视觉修复。
详见 `m4-squat-view-knee-tradeoff-v2.md` 及原始实验报告。
