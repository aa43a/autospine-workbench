# M4 未知深度权重定位

2026-09-24。沿用辉夜候选 `b6941a46bdd2f2bf0cb65a6229342517d79e1b92e71525e22d0806e5aaa59dd5`，只检查双袖辅助平面均有效的 4.9666665、7.44999975 秒。未更改权重、源动作、动画或验收。

## 发现

两时刻均定位到相同的左袖 7 个、右袖 9 个未知深度顶点。相关人体骨骼的源深度存在，但顶点在骨骼局部轴上的位置全部超出模型允许的 `[-0.25L, 1.25L]` 范围。其中有纯人体骨权重，也有人体骨与服装辅助骨混合权重。

| 区域 | 未知顶点 | 4.9666665 秒未知像素 | 7.44999975 秒未知像素 |
| --- | --- | ---: | ---: |
| 左袖 | 0, 92, 93, 119, 123, 130, 132 | 2925 | 2608 |
| 右袖 | 3, 92, 102, 112, 113, 114, 123, 124, 125 | 2249 | 2317 |

左侧人体骨轴坐标约为 -0.28L、1.34–1.82L；右侧约为 -0.26L、1.40–1.86L。当前同骨链深度区间要求至少有一个轴范围内的人体骨贡献；移除辅助骨后，这些顶点没有该支持，所以保留未知。服装平面有值并不补足剩余人体骨权重的深度。

此结果证明是深度代理适用范围不足，不能据此认定原绑定错误；也不能直接丢弃人体骨贡献、重新归为垂布，或扩大轴向阈值强制通过。像素数来自完整重叠分类；逐三角形诊断中的像素观测可能重复，不可累加代替分类数。

## 可复用定位工具

`tools/m4_depth_unknown_probe.py` 读取已登记检查的候选身份与现有有效辅助平面时刻，复算逐像素分类，输出相关三角形编号、未知顶点、实际权重、局部轴坐标和源骨深度是否存在。前后核对任务状态及候选身份；拒绝覆盖既有报告，不写入候选或验收记录。

真实运行四组检查完成，输出 `tmp/foot-v2-huiye-workbench-v1/unknown-weights-v2.json`，包含输入证据哈希。四组结果与首次定位逐项一致，输入哈希核对通过。这是限定时刻的原因定位，不是全段几何或 Runtime 新验收。

## 对后续开发的影响

停止将这些位置当作袖装绑定失败追修。下一步按深度证据充分性区分“可自动确定前后”和“模型外、需阶段观察”；现有时间轴可直接定位。若尝试轴范围外的深度包络，必须作为独立模型保留不确定区间，不能当作真实布料观测或默认通过依据。M4 三角色八动作及大动作质量要求继续有效。
