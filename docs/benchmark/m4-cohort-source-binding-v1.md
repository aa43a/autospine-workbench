# 集中验收的来源关联与片段时间修复

2026-09-26。对应[只读核对记录](m4-cohort-source-binding-v1.json)。

## 问题与行为

此前集中页分别验证源任务和目标候选，却没有读取候选实际引用的来源。
两份各自有效但不相干的任务仍可能通过页面的初步检查；同样，截取候选直接
与完整源时间同步，会因时长不同停止同步，无法准确定位片段中的异常。

现在播放入口和固定集状态统计都核对候选的源任务、源文件、完整编译身份、
采样速率、帧数和截取范围。新 `source-link.json` 仅返回已验证的关联元数据，
不读取大型候选包或捕获图像。原 `source-comparison.json` 保留完整预览功能。

集中页按候选的实际区间加载源骨架，将绝对源时间换算为候选局部时间；
几何、膝部、旋转、遮挡等定位回调反向换算。替代视角必须对应相同的源区间及
采样约定；相同时长但不同起点、不同帧率不能直接同步。已有改进候选若能验证
相同片段，则使用同样的偏移；不能核实片段归属的记录保留独立播放。

同步失败或切换目标时恢复此前由同步模式禁用的播放控件。来源核对失败会清除
该行旧的统计快照，不能继续显示旧验收为当前通过；验收历史本身不改变。

## 适用限制

本次修复对照与定位，不改变动作本身、技术门槛或固定集质量通过数。

三角色八类动作的最终支持范围与其余阶段结论仍未完成，M4 继续进行。
