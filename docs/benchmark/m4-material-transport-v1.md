## 方法

原纹理、UV、权重、骨骼和槽位不变。把静态修正 UV 的逆映射转为原顶点的三角形插值，按前一试验的姿态触发系数追加 deform；原 deform 时间保留。只绘制一个表面，不使用透明叠加。

第一轮严格映射遇到超过 0.75 重心坐标外推预算的顶点，构建拒绝。受限试验明确保留每侧 8 个超预算顶点的原运动并记录未处理清单，不放宽预算，不将它们视为已修正。

## 下一假设与停止条件

粗网格顶点采样加局部未映射回退，不能保证组合 UV 映射的分片连续性。下一次有针对性的修正应同时约束 UV 域边界，并构造原 UV 与修正 UV 三角形的共同细分，避免一个输出三角形跨越两种映射区域。若仍翻转或轮廓不自然，停止这条自动材质搬移路线，转入明确的姿态素材需求；不继续叠加偏移或放宽 QA。
