# M4 实测插值余量重烘焙

日期：2026-09-27。接续 [完整动画插值失败](m4-joint-boundary-animation-v1.md)。
状态：明显减少失败，仍未采用。

## 实现

`joint_boundary_margin.measure` 核对诊断动画身份，重新采样各失败三角形的实际
面积缺口，将两倍缺口加数值余量作为相邻两端关键帧的求解目标。沿用既有
`interpolation_area_margin.LIMIT=0.02` 上限；达到上限的观察仍计数，不视为解决。
只为可动三角形生成目标，固定区域保持未解决证据。原始验收下限完全不变。

烘焙使用固定 503 键。新验证加入八分点，并保留原始和前轮全部时间点。
来源父包、骨轨道、绑定、UV、拓扑和范围外固定点继续保留。旧动画和报告不覆盖。
