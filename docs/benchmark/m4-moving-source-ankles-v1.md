# 保留源脚端运动的三角色试验

2026-09-25。

新增 `source_ankle_targets`：从已验证来源提取双踝世界轨迹，使用候选实际相机 yaw
投影，按目标腿长/源参考长度缩放位移，并保留目标首帧脚端位置。
不使用“低速所以应静止”的推断，不删除源右脚的小幅移动，也不更改源 MotionIR。
支持现有 BVH 与 Kimodo 位置解码入口；本轮真实数据实测是 BVH，未完成 NPZ 端到端验证。

对 `m4-three-reach-contact-v1.md` 中三个确切候选，每个原 Runtime 的 817 时刻、
每时刻双腿分别使用现有 affine IK 的默认 30° 上限求解。原候选未改写，
没有提高搜索预算，也没有把各帧独立解拼成已验证动画。

| 角色 | 脚端检查数 | 找到有界旋转解 | 未找到解 | 其中超出腿链保守外界 |
| --- | ---: | ---: | ---: | ---: |
| Alice | 1,634 | 937 | 697 | 672 |
| 辉夜 | 1,634 | 964 | 670 | 584 |
| 红美铃 | 1,634 | 935 | 699 | 677 |

结论：在保持当前髋位置与腿部缩放的前提下，只修正两节腿的旋转不能覆盖全部源
脚端轨迹。超出保守外界是该固定结构的可达性反证；其他无解样本只是有界搜索失败，
不能都称为数学不可达。因此继续增大旋转范围不是合理的统一处理方式。

下一约束应联合考虑源髋部与脚端位置、腿部投影长度和两脚运动，验证时必须保留
已经通过的肩臂形状与根骨运动意图。当前没有新候选、没有新 Runtime 捕获或阶段接受。

工具 `m4_source_ankle_probe.py` 核对候选、来源、骨架摘要与既有采样时刻，输出
`tmp/m4-source-ankle/{alice,huiye,hongmeiling}.json`。有界旋转求解复用既有模块。
新增 3 项测试验证初始脚位保留、移动脚不被锁住、Y 轴换算、尺度协变、输入不变和
非法时间/尺度拒绝。仅为脚端表示与可达性证据，不能替代网格、时序、鞋底或视觉检查。
