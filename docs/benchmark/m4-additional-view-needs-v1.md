# M4 新视角素材需求入口

2026-09-25。动作异常处理草稿的“补充姿态附件”现在区分同画布换图与侧面、背面、弯曲关节素材需求。

新需求与精确候选、附件、动画、异常事件和草稿内容身份绑定。导出的 view-needs.json 列出透明素材、视角坐标约定、源区域对应、姿态几何及激活区间要求。保存需求不证明缺图，也不修改原候选或继承视觉验收。

同画布回交继续保留原网格、UV 和变形；新视角需求不能通过该接口回交，以免把不同坐标或几何的素材误套到旧网格。新视角映射构建尚未实现，页面明确显示此限制。旧任务不增加新字段，保持请求身份兼容。

验证：24 项 unittest 通过，覆盖草稿恢复、非法范围、任务导出、误用回交拒绝及旧素材映射流程。JavaScript 语法检查通过。修复一个旧映射测试的 skeleton fixture 缺失 slots 问题，没有放宽生产校验。尚未完成浏览器交互验收或更新运行中的工作台。

下一项是定义并实现新视角素材与目标姿态几何的对应输入、局部候选构建和完整区间 Runtime 检查；入口本身不构成大幅 Reach/Squat 质量验收通过。
