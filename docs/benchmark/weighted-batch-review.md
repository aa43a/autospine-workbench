# 有效加权区域批量复核

在整角色面板的“确认已有区域绑定”中，查看每层实际骨骼与区域清单，勾选需要确认的图层，再点击“确认勾选区域”。“勾选待确认”可以一次选中尚未确认的有效区域，但不会保存决定。也可勾选已经确认的图层，统一撤销。初始无勾选；切换候选或项目时清空，未保存校正和正在构建时禁用。

这是人工批量决定，不计作自动采用。静态残余和缺失区域不进入该操作；没有通过当前 Runtime 与几何检查的候选不能确认。确认绑定后，整角色外观、遮挡和动作仍单独验收。

同一请求内核对全部选中项、候选身份、当前复核版本和沿用证据，再追加一条历史记录。任一项无效就不写入复核记录，避免逐层请求导致半批成功。批量撤销保留未选中的确认。旧的单层请求和历史 v1/v2 记录保持兼容，不改写历史地址。

入口为现有 `POST /api/projects/{project}/automation/character/jobs/{job}/weighted-review`，使用 `layer_ids` 列表替代单个 `layer_id`；两者不可同时提供。请求合同见 `schemas/character-weighted-review-request-v1.schema.json`。历史输出继续使用原合同。

回归验证批次原子性、混合无效范围、并发版本冲突、部分撤销、默认不选、一次提交、候选切换以及旧确认沿用。批量复核不扩大权限，也不代替固定十角色的实际视觉反馈。
