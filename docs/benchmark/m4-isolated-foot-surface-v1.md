# 独立鞋骨实验：鞋形恢复不能替代腿鞋连接

2026-09-24。仅隔离实验，不接入默认策略，不继承人工验收。

输入为 pose-attachment-variant-v1 的红美铃 Squat，document
`1ded2804907575e54987322ec2cfc32fbc2189ffe1375d2ce579777c2c33c0b5`。
沿用前次脚部世界变换补偿，新增同父级的 foot_l-material / foot_r-material，
仅将纯脚骨驱动的 layer-007 / layer-008 鞋网格转交辅助骨。
其他附件、原骨骼、绘制顺序、UV 与 deform 保持原样。
输出 document `81f80853472adc28fde59623a9c1400452224d7bd856e34f107ac76d6699e294`。

## 结果与限制

697 时刻的现有几何检查中，两鞋通过；三条腿部附件记录仍失败，失败帧数
分别为 227、587、243。独立辅助骨避免了前次整体恢复脚骨导致的腿部新增变形，
但没有修复原膝部问题。本候选没有新的官方 Runtime / GPU 验收。

冻结源图中，腿层包含白色袜脚，鞋层包含覆盖它的黑鞋。这是两层材料的共同
运动关系，不能误认为腿层内有一份应删除的重复黑鞋。

在 setup 中选择两层 alpha 均至少为 128/255 的重叠像素，每侧抽取 64 个材料
坐标探针。原候选同一探针的腿鞋位置基本重合；初始五姿态检查中，独立鞋骨
候选左侧最大分离约 13.82 px，右侧约 99.09 px。因此不能仅凭鞋形改善采用。
这里的分离是材料点的世界坐标距离，不是 framebuffer 裂缝宽度，也不是
脚底接触错误的直接测量。

`tools/m4_leg_shoe_material_probe.py` 已去除特定动作的硬编码五时刻，改为比较
两份动画全部关键帧的并集及相邻中点，并拒绝时长改变。纹理改变时拒绝材料
对应；输出每侧 UV、纹理身份及逐时刻距离，便于复核。

证据目录：`localset/tmp/m4-motion-center/isolated-foot-surface-v1/`。
其中 `material-separation.json` 为初始五姿态检查；整段报告另行保存，不能用
五帧结果声称全动画通过。六项单元测试覆盖鞋骨隔离、其他动画保持、混合网格
拒绝、无关动画修改拒绝、双时间轴采样及时间范围一致性。

整段报告 `material-separation-full.json` 已完成 697 时刻、每侧 64 探针检查：
左侧峰值 17.6475 px（0.233333 秒），右侧 151.1263 px（0.666667 秒）；
原候选对应峰值均小于 1e-12 px。报告 SHA256 为
`c8b104cb6f73ac25b24a1d61bfa6ed8b2cdb3fe5e8ae9c6ead198b947b659180`。
本结果确认鞋骨隔离破坏了两层原有的材料共同运动，拒绝默认采用。
第一次整段运行在写文件时被权限拒绝，未产生结果；获得输出目录写权限后
重跑成功。上述六项及已有脚部补偿、端点约束四项测试合计十项通过。

## 后续约束

下一候选必须把腿层内袜脚与鞋作为共同的远端材料运动区域，明确小腿到脚的
过渡，同时检查原膝部失败。不能直接把整张腿交给鞋骨，不能删除袜脚像素来
掩盖分离，也不能把独立鞋骨的几何通过当作整角色通过。若现有混合权重交界
不能满足形状与连接，应改变局部表示并在同一动作回归；不继续扩大修正预算。
