# 项目人工工作计时

工作台阶段导航下方的“项目人工工作计时”在所有工作区可见。展开后选择来源准备、关节调整、绑定修改、袖装标注、整角色验收、自动绑定抽查或其他处理，点击开始，工作结束点击“暂停并保存”。

同一项目切换工作区不中断计时。切换项目会暂停并在当前页面会话内保留未保存草稿，回到项目后可保存；刷新或关闭浏览器前务必保存。保存失败保留草稿，可刷新服务器记录后重试；放弃草稿不删除已保存记录。记录列表支持逐条撤销，原历史文件保持。

每段记录包含显式开始与结束时间、秒数、阶段和唯一 ID，绑定项目 PSD 来源身份。累计保存使用来源与最新历史摘要检查，拒绝重复 ID、重叠时段、无效时钟和跨来源提交。正常关节或绑定修改不会抹去同一素材的既有操作时间；更换素材后历史保留，但不混入当前来源合计。

统计仅表示已记录的导入后人工操作段。未记录阶段显示未知，不计为零；不与候选视觉复核或抽查计时相加，以免重复计算。没有覆盖导入前、未计时操作和全部历史返工，因此完整流程人工总耗时继续为未知。固定三角色与十角色评估器将这些数据单列为 `project_work_timing`，不能用其替代完整耗时。

合同：`schemas/project-work-session-v1.schema.json`。接口为 `GET/POST /api/projects/{project}/automation/character/work-sessions`，受现有同源写入限制。此功能不提交绑定、复核判断或发布授权。
