## 消除整三角形包络的过度保守

两网格比较器新增显式 pixelwise 模式：在实际 alpha 重叠的像素中心，
分别对两侧顶点深度区间做重心插值，再比较完整区间，不取中点代替区间。
同一像素被多个三角形覆盖时仍取包络，未知贡献继续保留，分块与非分块结果一致。
该模式有独立 profile，计入额外像素预算；原默认行为不变。

不是全部变为手在前方。剩余不确定位于 0.4833335–0.55 秒。
