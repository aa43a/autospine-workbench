# 适配任务重试保留原策略

原重试从旧请求提取少数用户参数，再调用当前默认提交入口。旧请求中省略的推断接触、深度和 Runtime 存储策略可能因此被新增或升级。

现在普通适配重试先核对来源和角色身份，再完整复制已保存请求，只替换任务 ID 并记录原请求摘要。不存在的旧字段继续不存在，显式策略、裁剪、视角和视角选择依据均保留。不复用旧结果或视觉接受；当前代码仍会重新执行，故不承诺跨代码版本输出字节相同。修复候选继续使用原有草稿有效性检查路线。

20 项相关测试通过：覆盖显式和缺省历史参数、原请求不变、来源/角色校验调用、角色变化不创建任务，以及原导入、适配和生成回归。此修复不代表大动作质量通过。
