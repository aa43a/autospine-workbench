# 实时角色播放保持动作时间

角色播放器原本将单次帧间隔限制在 0.1 秒，显示延迟 250 毫秒时只推进 100 毫秒动作。高负载下会产生未声明的慢动作，且与源骨架时间轴的实际时间推进不同。

现改为使用非负实际间隔乘以用户所选速度，掉帧只减少显示采样，不减少动作时间。页面隐藏仍暂停，循环、片尾钳制与反向 seek 保留。该变更不修改任何动作或候选文件。

`tools/check-motion-player-clock.mjs` 在真实 Kimodo 候选 `motion-8ca66333718c4e9698c2de4261be5878` 上使用可控 requestAnimationFrame 时间验证：250ms 延迟、2×速度、暂停恢复、跨多个周期、片尾停止和从片尾重新播放均通过，无脚本错误。首次测试因覆盖 RAF 后仍用 RAF 轮询 ready 而超时，改为独立定时轮询后通过。它是播放时序回归，不是性能或视觉验收。

工作台通过静态应用资源即时使用修复。历史已导出的独立 HTML 保留其原脚本，不静默重写。
