# Squat：视角与修正的整角色验证

2026-09-25。结论：改变视角能减少腿部投影退化，但当前 Alice 素材和整体连接仍不能据此通过 Squat 验收。没有修改源动作、放宽门槛或继承 Reach 的人工接受。

## 可复现工具

- `tools/m4_source_view_scan.py`：读取已验证来源，按 5° 比较 −90° 至 90°；同时列出各肢体缩短、方向未定义、相邻采样角变化及现有躯干限制。仅诊断，不自动选取“通过视角”。
- `tools/m4_corrective_runtime_probe.py`：验证修正只改变指定 deform，重建整段数值参考、执行完整几何检查，再捕获官方 Runtime。渲染包不继承父候选的接触、深度、复核或接受记录；保留父身份。

源动作来自既有 Alice Squat request `motion-3954d8fe062b4a439b26a90667e97781`；完整身份见同目录 JSON。所有新输出在 `tmp/m4-moving-workbench/`，旧候选保持不变。

负向 55° 修正后两腿最小面积比分别 0.526017、0.504377，没有翻转。官方 Runtime **4.3.13** 对目标 Spine **4.3.26** 包完成 **1,245** 个数值采样检查；这不代表所有帧均输出 PNG，也不代表视觉验收通过。

已查看 `alice-squat-shared-minus55-runtime-v1/runtime/frames/external-motion-640.png`：肩部/披肩附近仍有空隙，裙装右侧有脱离主体的浅色区域。头部正面形象与偏转躯干也未形成可靠侧身表现。保留这些异常，不请求用户接受明显未修好的结果。

播放入口：`alice-squat-shared-minus55-runtime-v1/runtime/player.html`。这是隔离诊断包，不是在线工作台已采用候选；接触及深度需要对新 skeleton 重新验证。

## 下一步约束

不能只优化“腿投影可见度”或“网格面积通过”。后续需要同时解决躯干、裙装、肩部覆盖和视角素材的一致性；在这之前不把负向 55° 设置为默认视角。该结果不能证明 2D 素材适合所有侧身，也不能证明需要放宽面积阈值。

验证：5 个针对性测试通过，覆盖投影退化、角度跨 ±180°、非法源数据及旧验收证据不会随修正包继承。实测记录见 `m4-squat-view-corrective-2026-09-25.json` 和 `m4-squat-source-view-scan-with-torso-2026-09-25.json`。
