# 裙装滑动支持与固定区定义

2026-09-25。本轮替代失败的源材料点锁定，在当前覆盖三角形中搜索附近的可靠不透明材质。搜索限制为邻近 8 个纹理像素、8 px 世界距离；候选 texel 的 3×3 邻域 alpha 均须不低于 128。没有扩大网格或改写纹理。

实际找到裙装三角形 108 上的支持点，距离目标约 **3.027 px**，比上一轮固定源点所需的约 198 px 明显更近。但当前实验将所有带 chest 权重的点冻结，支持顶点 58、60、74 全部被排除，未生成候选。

保存的权重说明该冻结规则过于粗糙：58、60 的 chest 权重约 10.303%，其余随裙摆骨；74 的 chest 权重仅约 0.417%，其余随裙摆骨。这些是混合过渡点，不能只凭非零胸骨权重证明它们是真实固定裙腰。

这不是布料结构无解，也不是需要重绑整个裙装的证据。下一步应读取已经确认的腰部接触/根部定义，用实际固定接触点约束腰部，并允许过渡区域参与受限修正。不能为了此次试验直接换一个随意的权重阈值。

实现包括 `sliding_material_support.py` 及关键姿态工具的显式 `--sliding` 选项；固定支持不足或位移超出预算时保存失败原因，不写候选坐标。混合固定/自由三角形可通过重心权重分配增量，但绝不解锁固定点，也不超过 8 px 增量预算。

8 个相关测试通过，覆盖透明区域拒绝、邻近支持、固定顶点保留与位移超预算拒绝。证据摘要 `m4-skirt-sliding-support-2026-09-25.json`。正式候选、历史接受记录和在线工作台均未修改，视觉问题尚未解决。
