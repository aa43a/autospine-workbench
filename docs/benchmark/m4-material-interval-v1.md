# 肩部区间联合约束：连续采样通过

2026-09-25。上一轮的 112 条面积异常集中在 layer-004 的三角形 8、9，位于约 0.366667–0.383268 秒和 1.358301–1.366667 秒。端点合格并不能保证区间内面积合格。

首先增加线性世界顶点运动的面积二次多项式极值检查。实际骨骼/权重动画与该模型存在约 0.008202 / 0.007206 px 的顶点偏差，因此不能把这个解析模型直接作为实际动画的连续证书。模型只用于解释端点之间的收缩和膨胀。

随后实现区间联合修正：每个区间只允许失败三角形中原本可移动的四个顶点产生增量，两端增量为零，中间使用一个局部 deform 修正。用实际骨骼变换和权重推导整个区间的响应，同时约束 33 个均匀时刻及存储后的中点时刻；保持原位移预算、材质覆盖、面积与边长要求。失败求解不烘焙增量。

两个区间均找到可行解，最大新增位移分别为 0.014041 / 0.011382 px。独立烘焙后检查保留全部旧时刻，最终 **14,924 个时刻、0 条失败记录**：

- 材质覆盖区域最大比例 0.993167。
- 固定远端误差约 2.27e-13 px；锁定接触点误差约 0.009931 px。
- 原始位移预算最大使用比例 0.961380。
- 未修改附件误差为 0；结构检查确认相对上一版仅 layer-004 的 deform 改变。
- 区间边界最大偏差约 8.77e-8 px，来自旧/新时刻的浮点存储合并，低于现有 1e-7 保持位置检查值；不能描述成逐位相同。
