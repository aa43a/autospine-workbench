2026-09-24。新增仅用于实验的裁切器：原 alpha=8 等值线保留外轮廓和内孔，每个原三角形与该区域相交后做约束三角剖分；新增点通过原三角形重心坐标插值 XYZ、UV 和骨骼权重。不外推未知区域，不编辑源 PNG。
