# 附件退出边界修正：脚部插值通过，膝部问题仍保留

2026-09-24。承接 6a9ea03 的联合袜脚/鞋候选。所有结果仍为隔离候选，默认
工作台与历史人工决定不变，没有新增视觉接受。

## 根因与实现

v2 在 layer-003 的 0.6981770992279053 秒出现面积比 0.498619。
原附件最后一个修正键位于 0.6963542103767395 秒，下一个修正键却在它重新
启用的 1.2000000476837158 秒。0.7 秒之前的可见区间因此向重入姿态插值，
而没有朝向当前退出边界的目标。此处增加任意中间键只会缩短错误区间。

新增 `attachment_exit_pose`：从真实附件时间轴识别退出边界，在 float32
Runtime 时刻固定该槽位的退出附件进行求值，保留其他动画通道。烘焙时仅
允许已核实的退出记录使用这一求值方式，不能把任意未激活附件冒充边界。

两处退出姿态均按原有脚部区域及硬约束重新解算：0.699999988079071 秒的
原腿附件，1.2000000476837158 秒的姿态腿附件。没有改纹理、原动作幅度、
固定小腿点、几何门槛或位移预算，也没有简单删除冲突采样。
