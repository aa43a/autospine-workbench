# 保旋转混合实验：未采用，路线停止

2026-09-22。根据三结构 Kimodo 同源回归的异常区域，验证是否可以用分开混合旋转与对称伸缩的方式减少多骨塌缩。原纹理、骨骼、源动作及权重不变，仅对指定失败附件生成独立 deform。算法为本项目的二维极分解实验，不是 AnimatedDrawings 或标准双四元数蒙皮实现。

输入来自 `kimodo-foot-target-v1/cohort-summary.json` 的三个精确父候选。每角色检查起始、1.9833335、3.966667 秒三个时刻，不声明三时刻之间插值可用。

## 第一版：加权骨骼原点作为旋转中心

三角色均完成独立 Runtime 捕获。红美铃中点最小面积比从原候选的 0.449683 降至 0.016282，末帧降至 0.022667；不采用。旋转中心落在肩肘之间，不能保持实际肘关节连接位置，因此只进行一次针对这一原因的修正。

## 第二版：层级中的共享关节中心

按骨骼祖先关系寻找连接关节；多组权重的关节中心由成对权重组合。单骨顶点保持精确原运动。不相关骨链明确拒绝，未静默回退到旧中心。

| 角色 | 原候选末帧最小面积比 | 新方案 | 结果 |
| --- | ---: | ---: | --- |
| 红美铃 | 0.284966 | 0.187762 | 更差，拒绝采用 |
| Alice | 0.297189 | 0.155561 | 更差，拒绝采用 |
| 辉夜 | — | 不生成 | 辅助骨链不是同一祖先链，明确 unsupported |

红美铃、Alice 三时刻官方 Runtime 数值核对通过，但几何未通过。单骨顶点变化不超过约 2.55e-13 px；混合区域最大位移约 8.21、8.64 px。已查看 Alice 末帧实际 Runtime 图，无人工接受记录。不能把“每顶点的旋转矩阵没有塌缩”解释为“空间变化的整个三角网格不会塌缩”。

本路线停止，不扩展整段、不修改默认候选、不放宽门槛。剩余工作应转向关节周围的表示及可见轮廓，而非继续替换混合公式或扩大局部修正。

## 复现与证据

`tools/m4_polar_skinning_probe.py COHORT OUTPUT` 为第一版；`--shared-joint` 为第二版。`--resume` 仅复用父身份、策略及 Runtime 身份均一致的已完成结果。当前第二版前两角色已捕获，辉夜明确记录 unsupported；失败保留在三角色分母。

目录：`localset/tmp/m4-motion-center/polar-skinning-v1` 和 `polar-skinning-v2`。各目录含精确候选、三时刻捕获及播放器；第二版辉夜只有 failure.json。六项测试覆盖 bind pose、单骨精确性、共享中心连接、反向旋转歧义、不相关骨链拒绝及非法输入。实验模块没有接入自动构建或验收。
