# 短支撑区间的采样覆盖

2026-09-25。

最终检查使用与 Runtime 对齐的固定采样时刻。若支撑区间位于两次采样之间，
原实现会对空样本调用 `max` 并异常退出。现将这一情况记录为
`contact_interval_not_sampled`，该区间 `passed=null`、位移和最差时刻均为 null。
总报告在没有已知失败而存在缺测时为 `insufficient_contact_samples`，不记作通过。
存在其他已测失败时总结果仍失败，缺测区域同时保留。

工作台动作卡和接触复核页增加“部分支撑区间未采样，接触证据不足”说明；
表格显示“未测量”，定位链接指向区间起点，并明确不是最差帧定位。
没有补入未被 Runtime 验证的时间，也未降低采样或通过阈值。

32 项相关单元测试及动作中心 JS 语法检查通过，包含最终复测、可渲染报告、
全部缺测、缺测与已知失败混合、裁剪窗口、修正策略与原候选不变。
当前服务重启仍被策略阻止，本轮仅完成代码验证，未声明在线加载或新 Runtime 捕获。
