# 工作台局部姿态修形候选

2026-09-24。M4 仍未完成；本切片连接显式姿态编辑与现有动作候选队列，不宣称大幅动作质量已解决。

## 操作

在动作任务的几何异常处理区域点击“在当前页编辑异常附近的姿态”。页面以内嵌窗口展示当前三角形及其一圈邻接顶点。拖动时间轴，移动黄色顶点，松开后保存本地关键姿态；可撤销、删除、导入或导出草稿。取消“显示补丁”可对照原候选。

“保存并构建独立候选”将当前草稿封存到新任务，不覆盖原候选。链接进入已有任务中心查看进度、取消、重试及结果。未提交的编辑保存在浏览器；不同候选、附件、动画、顶点区域及区间分开存储。此版本没有独立的服务器草稿版本列表，服务器记录由不可变任务请求承担。

## 构建与身份

- `POST /api/motions/{job}/pose-geometry-execute` 要求同源操作意图，接收候选哈希和编辑器导出的 `pose_geometry`。
- 校验父候选、骨架及网格身份，冻结原动作请求。沿用现有隔离 worker、进度、Runtime、深度检查与修复历史链；重试保留姿态补丁，不退回普通重定向。
- 仅修改指定附件的 deform；纹理、UV、拓扑、骨骼及其他动画通道保留。
- 重新计算整角色数值参考与几何检查、最终时间轴脚踝代理接触。旧 Runtime/遮挡结论不继承。
- 保留所有父参考采样，并合并编译器的关键帧及中点，不递归细分密集父采样。超过 4,097 采样明确拒绝。
- 几何失败仍生成待复核候选，不自动采用。脚踝代理通过不等于 GPU 鞋底接触、接缝或视觉验收。
