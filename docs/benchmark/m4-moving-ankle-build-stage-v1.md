# 移动脚端进入统一候选构建阶段

2026-09-25。`build_candidate` 新增可选 `moving_ankles` 来源观测参数。
不传参数的历史任务保留原行为；本次尚未开放工作台提交入口，也未部署到在线服务。

阶段位于躯干投影之后、深度顺序与最终验证之前。核对原 MotionIR 身份、
动作包身份、投影视角及完整时间范围；裁剪片段尚不支持，明确拒绝，不能静默套用全片轨迹。
目标初始位置取当前候选首帧，再叠加源踝部投影位移。

联合求解失败时保留输入动画，写出失败原因，不返回局部成功动画。
成功后按最终插值采样重算真实 FK 误差，继续接触检查、setup 基准网格检查、
数值参考生成和原有 Runtime 路径。来源、求解与最终检查写入
`motion-moving-ankles.json`，参与候选清单身份。成功不继承任何旧视觉接受。

回归同时发现并修复：接触推断不可用且没有区间时，缺少时间单位会造成报错。
空区间现在保留不可测状态；非空区间仍要求原有时间单位约束。

32 项相关测试通过，包含成功与不可达、来源/视角/裁剪拒绝、最终骨骼被后续
步骤改变时检测失败、不可用接触推断、原文件保留、最终几何与清单输出。
这不是一次新 Runtime 捕获，三角色原实验的验收不能自动转移到本阶段新输出。

下一步：将版本化策略接入任务提交与界面，明确与静止接触修正的选择关系，
再通过实际角色重新生成候选及 Runtime 验证。
