## 处理

根据原始 setup 上衣不透明遮挡和源肩关节位置，在距肩关节不超过上臂长度 0.65 的范围生成连接片。该半径沿用 shoulder_source 的近端支持范围，是实验策略，不是已确认语义。其余手臂源像素保留为自由材料；连接片始终在上衣后方，自由材料继续使用原深度实验。

原图 RGB 不变，无新增绘画内容、无骨骼/原网格/原 deform 轨迹变化。连接片副本使用原权重和相同 deform，不是把整个区域刚性锁到 chest。原文件保留，候选写入隔离存储。

二元纹理分片首先产生过滤暗线。一次针对性修正只在原图 alpha=255 的内部边界添加一像素重叠保护；不增长源透明外轮廓，不覆盖远端袖布。样本中心 alpha 最大值合成与源图一致，不代表过滤后的实际合成处处严格一致。
