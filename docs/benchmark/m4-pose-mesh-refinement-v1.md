## 后续可行性检查：停止中心点修复路线

`m4_pose_refinement_probe.py` 在同一来源上读取全部骨骼和 deform 时间，
并加入相邻时间中点，共 623 个时刻。这比上面的均匀 113 个保真样本更密，
两者口径不同，不能直接对比失败数。

固定原三角形的三个端点时，无论如何移动重心控制点，三个子三角形的
有向面积之和不变。由于各自 setup 面积都是原面积的三分之一，子三角形
面积比的平均值必定等于原三角形面积比。因此原面积比超出 0.5–2 时，
不存在只移动内部点就使所有子三角形达标的解；原边长超过 2 倍也无法修复。
这个必要条件不依赖迭代次数或位移预算。没有反例不等于证明可行。

结果：layer-003 在 623 个时刻中有 396 个时刻存在不可行三角形，
layer-004 有 513 个。翻转三角形×时刻记录分别为 255、1027，
不是独立三角形数。首次面积反例分别为 0.24062504296875 秒的三角形 117，
以及 0.08750001562500001 秒的三角形 242。
