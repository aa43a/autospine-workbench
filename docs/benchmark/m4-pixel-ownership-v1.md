# 播放器像素归属与换序假设检查（2026-09-26）

本切片交付“点击检查归属”，并核查 Alice 下蹲的五个具体样本。
不修改动画、网格、纹理、绘制顺序或人工验收；六个重点质量案例的通过数不增加。

## 使用入口

动作中心 → Alice / Squat → 已关联改进候选 → 含姿态定位的版本 → 播放器。
展开“部件与遮挡对照”，开启“点击检查归属”，点击画布会暂停并显示材质来源。
每个来源可直接选入部件对照。切换时间、动作、局部显示或关闭检查时清除旧结果。
普通整角色、外部动作及关联候选复用同一播放器；素材任务的离线预览继续内嵌同一实现。

计算采用官方 Runtime 当前应用姿态、当前序列附件和图集 UV，包含 Region 与 Mesh。
CSS 缩放、相机位置、缩放和 framebuffer 半像素中心统一转换。
多层低 alpha 会合成后再判断，不能因为单个附件低于 8 就判为缺口。
共同边上的三角形可能重复计数，故合成透明度只是理想上限；裁剪、非普通混合、
非双线性过滤、非 clamp 边界、缺失纹理和无效状态不给换序结论。
隐藏部件、骨骼和三角形高亮必须先清除；上下文丢失或读像素失败会取消结果。
