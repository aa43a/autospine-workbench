# 显式姿态几何补丁：编译与 Runtime 验证

2026-09-24。新增 pose_geometry_patch 编译器及 m4_pose_geometry_probe 工具。
它允许指定顶点在指定关键时刻到达显式世界坐标，转换为加权骨骼局部增量 deform，并与原 deform 相加。
输入需绑定完整 skeleton 与 mesh 哈希，指定生效区间及严格递增的内部姿态关键帧。
区间边界增量为零；其他顶点、骨骼、纹理、UV、拓扑和其他动画不改。

这使几何编辑与只换 PNG 的素材路线明确分离，但仍是同拓扑补丁，不是重建侧面或自动生成正确姿态。
编译器仅支持其独立求值器可表达的骨骼轨迹与稠密线性 deform；Bezier 骨骼轨迹拒绝，避免当成线性轨迹。
输出保留原有失败，不自动采用；报告覆盖来源关键时刻、编辑时刻和它们的中点，不声称全连续时间证明。
