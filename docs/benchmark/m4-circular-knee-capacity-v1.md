本次检验新表示的必要条件：髋、踝固定，两段直线以相切圆弧连接；截面宽度固定，材料沿中心线分布。与先前 Hermite 条带、分段覆盖不同，圆弧曲率恒定，能够直接计算内外侧面积比例及半径上界。不是重复优化原顶点。

设半宽 w、半径 R、转角 theta、材料纵向伸缩 lambda。内外侧面积比例为 lambda*(1±w/R)。相切裁切长度 R*tan(theta/2) 不能超过任一骨段。先测均匀材料分布的最优半径，再放宽到任意纵向分布，仍保留面积 0.5–2：必要半径为 w*(2+0.5)/(2-0.5)，对材料长度积分得到可容纳的最大原长。通过只是必要条件，不包括边长、接缝、全局交叠或可见外观。

在 setup 膝截面测网格宽度，并沿同一截面以不超过 0.25px 间隔，通过原网格 UV 采样 images/ 下的未填边纹理。分别检查 alpha≥8、alpha≥128 的支持范围，避免把透明网格余量当作腿宽。候选、网格和纹理摘要保存在报告中。此截面不代表整条腿，也未考虑非对称/变宽截面。
