## 真实 Runtime 对照

使用候选自带官方 WebGL Runtime，捕获 0、0.7、1.05、1.725、2.4、4 秒，
完整角色及相同相机，无隔离遮挡或局部缩放。两个版本回退起点截图均逐字节复现，
无页面脚本错误，播放器身份分别对应原候选与独立对照身份。

直接检查 0、1.725、4 秒完整角色画面：

- 首帧整体前置后，左侧画面的袖布盖到披肩前沿，出现突出的平面布片和硬边。
- 中间抬臂姿态，前置布片覆盖披肩下缘及躯干边缘，原有材料连接被破坏。
- 末帧仍存在同类覆盖，不能解释为仅某一帧的插值误差。

这些是助手对捕获画面的观察，不记录为用户视觉验收。
本实验不是逐像素跟随深度的完整方案；但首帧已说明不能仅根据代理前侧判定
把整个近端连接片改成前置。原后置图仍有此前肩部质量限制，不因对照更差而自动通过。

## 决定

拒绝整体前置作为默认修复，不继续调整整层前后顺序。
躯干平面与骨骼深度没有表达披肩覆盖袖根的材料关系。
后续应在现有分区策略中明确“近端服装连接区”和“远端可穿越区”的不同遮挡依据，
验证该区分在其他角色是否成立；不能把本例后置规则硬编码到全部肩部，
也不能改权重来消灭深度代理与服装结构的分歧。
