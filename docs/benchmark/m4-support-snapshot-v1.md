# M4 支持范围报告

集中验收页新增“核对并生成支持范围报告”。读取全部固定组合、阶段验收、
独立关联候选及同源同角色的替代视角，输出 HTML 与 JSON。
不受页面筛选影响，也不提交构建、验收、默认采用或 Runtime 捕获。

## 证据口径

- 固定候选先核对实际源任务、源文件、MotionIR 版本、片段和采样范围，再读取阶段结论。
- 人工结论保留版本、证据摘要、说明及是否适用。兼容的历史空字段扩展仍按服务端判断单独标记。
- 替代视角逐个核对实际来源、候选与比较时的检查摘要；比较期间证据变化则标为未核实。
- 关联改进候选保留独立登记身份、检查、原导入视觉记录及后续验收。原候选接受不传播到改进结果。
- 缺失组合、读取失败、清单超过服务端检查上限均保留。独立结果不加入固定候选通过数量。
- 每项读取时间和总读取区间写入快照；不是同时刻事务，也不承诺下载后仍为最新状态。
- 停止生成或本页保存新的验收时，撤下尚未下载的文件；迟到响应不重建旧链接。

报告只针对固定来源、角色版本、视角和片段。技术失败与阶段接受可以同时存在，
不据此推断任意同类动作可用，也不授予发布权限。
