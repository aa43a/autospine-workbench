# 局部姿态几何编辑页

2026-09-24。新增独立编辑页和 m4_pose_geometry_editor 导出工具，使用已捕获候选的官方 Runtime、原纹理和原骨骼动作。
模板限定精确 skeleton/mesh 身份、部件、顶点及时间范围；不自动采用模板中的历史姿态。

操作：时间轴选区间内部时刻，点击“放大编辑区域”，拖动黄色顶点。松开保存当前关键姿态，可继续在其他时刻编辑。
支持播放、撤销、删除关键姿态、原候选对比、部件隔离、版本绑定的本地草稿恢复及 JSON 导入/导出。
当前帧显示翻转与面积超限；未实现整段接缝/边长验收，不用此提示冒充完整门禁。
区间两端恢复原动画，插值沿用后端的骨骼局部增量；这是同拓扑几何编辑，不是重新生成侧面素材。

## 验证

真实来源：49d38a78510219829ea7c729df7779d384099a28188e80d5afe2ed5a225c9cc0，红美铃 Squat，layer-003 的 66 个顶点。
浏览器脚本 check-pose-geometry-editor.mjs 验证局部放大后的鼠标拖动、反向拖动时间轴、原候选对比、两关键姿态、撤销、导出、刷新恢复、错误身份拒绝、有效导入、播放及删除。
测试草稿仅在隔离测试浏览器保存，没有写入工作台人工决定或采用记录。

check_pose_geometry_preview.py 将浏览器导出的真实草稿交给后端编译器，在 0.6、1、1.1、1.2、1.6 秒逐点比较。
最大误差 0.000133325 px，小于本次一致性阈值 0.001 px；原几何失败保留。
证据：autospine-workbench/tmp/pose-geometry-editor-check-v5，页面：tmp/pose-geometry-editor-v1。
