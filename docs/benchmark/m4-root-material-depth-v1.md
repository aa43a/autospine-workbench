## 观察

连接片 m4-root-material 固定在 layer-006 躯干之前绘制，即被躯干遮挡。
检查材料图片中 alpha≥8 的 1,501 个纹理像素中心，481 个时刻：

- 无未映射或未知深度采样，UV 重叠没有前后冲突。
- 所有时刻都有像素被原代理判为前侧；最大为全部 1,501 个。
- 加入实际变形后躯干三角形和纹理 alpha 的 CPU 最近邻重叠检查后，
  起始帧 1,258 个采样点与躯干重叠，其中 937 个被代理判为前侧。
- 1.72499975 秒峰值：1,489 个重叠采样点全部被代理判为前侧。
- 末帧：1,470 个重叠采样点全部被代理判为前侧。

这里统计的是材料图纹理像素中心，不是 framebuffer 像素，也不是原选择遮罩像素数。
CPU 最近邻 alpha≥8 检查不等于 GPU 双线性混合结果，不覆盖其他遮挡附件。
“代理判前侧”使用已有减去 margin 的重放场；不代表真实人体表面深度。

## 对下一步的影响

已知裁剪插值误差约 0.014 px，暂不支持继续调裁剪参数。
新的证据明确：近端固定后置规则与深度代理存在实际重叠区的矛盾，而且首帧就存在。
不能直接按代理把连接片提到前面，也不能把固定后置视为已验证的泛化规则。
下一实验应保持相同材料和动作，比较两种可见性方案的完整肩臂 Runtime 画面，
确认代理平面的适用范围；不重新改权重、不因数字冲突自动采用新方案。
