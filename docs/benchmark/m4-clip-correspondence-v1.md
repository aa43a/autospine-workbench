# 连续裁剪的全段固定对应实验

2026-09-22。输入为 `reach-clip-contours-v1/report.json` 的 241 条真实右肩深度代理轮廓。
没有生成或采用新的裁剪动画候选。

以全段共有的 73 个原网格边界顶点为锚点，验证锚点循环顺序一致，在相邻锚点之间使用弧长对应。
要求双向折线顶点距离不超过 0.1 px，固定顶点总数不超过 512。
此距离检查不等价于连续 Hausdorff 距离，也不证明深度前景保守性。

均匀加密超过预算。随后尝试在最坏源折角对应的弧长参数处自适应补点；仍超过同一预算。
旧全段重复计算过程已明确停止；优化为缓存已通过边界段后的实际运行仍返回 `clip_correspondence_vertex_budget`，不是因为观测超时判定失败。

结论：全段共享弧长参数路线不继续加密，不放宽误差要求。
单帧闭合轮廓有效与全段固定参数表示有效是两个不同条件；本次仅否定这套全段对应方法。
下一步评估拓扑稳定时间段的局部对应与段间连续性，并保留标准 Spine clipping 表达的顶点和附件数量预算。

5 项测试通过：新增共线顶点、锚点绕序改变、预算不足、移动短折角、非法坐标。
工具 `tools/m4_clip_correspondence.py` 会将失败写成明确的 not_generated 报告，避免留下看似可用的部分 deform。
