## 实现与边界

1. `parent_setup_preservation` 联合保护父候选已有压缩和原本达标的 setup 面积。
   正常区域的求解下限为 `min(0.505, parentSetupRatio)`，换算到投影参考后与
   现有下限取较大值。0.505 是求解余量，最终面积门槛仍为 0.5；不要求固定
   的合格父表面再额外扩大。与投影上限冲突时显式拒绝，不截断掉约束。
2. 横向补偿增加显式 `correction_frame='transverse'` 实验模式：在每个骨骼
   影响上，将已修正位置 `y + deformY` 一起传入行列式为 1 的剪切变换。
   单骨三角形在精确采样时保留父候选的有向面积；混合权重仍需检查。
   默认 `world` 模式保持原有行为。新模式会改变旧接触修正的世界方向，
   必须重验接触，不能继承父候选通过记录。
3. 可传入必须保留的检查时刻，作为精确 deform 键；不删除原始关键时刻，
   仍做各段四分点插值误差检查并保留原键数上限。精确姿态通过不证明段间通过。
4. 新增每三角形位移圆盘的必要条件检查：0/1 个可移动顶点时面积上界精确，
   多个可移动顶点采用保守上界。发现反例可证明当前预算不足；没有反例不能
   证明所有约束联合可解。
5. 局部优化可只选择超过现有最终容差的失败邻域，并在验证固定上下文后移除
   求解中不随变量变化的常量约束。完整最终面积、边长、位移与固定顶点检查
   均保留。真实失败的固定上下文直接返回失败，不能靠剔除约束掩盖。
