# 工作台肩部局部修复

整角色面板增加“肩部局部连接修复”入口。先构建候选，选择出现分离的加权肩部区域，再构建。默认不勾选；切换项目会清空选择。静态残余不作为可选肩部。

构建依次尝试边界约束、异常时间段细化与跨帧连续修复，前一步满足检查即停止。显示当前阶段，支持取消。只有通过采样几何、边界与固定区域检查的结果才进入本次候选；未通过则保留输入候选，并显示修复阻塞。数值通过不代表轮廓改善或视觉接受，仍需在整角色动作中复核。

关闭选项后重建恢复原方案。若区域排除、分区绑定或遮挡复核已固定该构建配方，需先撤销相应决定才可改选项。旧配方不新增字段，不改写历史记录；新配方保存明确的 `shoulder_regions` 列表。

后端在裙装候选之后、最终区域排除之前应用修复，然后继续原分区绑定、遮挡与官方 Runtime 捕获链。未指定区域的请求保持原路径；不自动处理所有肩部，不生成视觉或发布授权。

回归覆盖默认身份、限定区域、有限修复、失败保留原候选、取消、配方恢复与界面选择。真实角色检查结果另存于工作区 `tmp/character-shoulder-workbench/alice`；只有实际报告存在且通过时才能计入 Runtime 验证。十角色完成率不会因为本入口完成而增加。
