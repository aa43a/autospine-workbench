# 回交素材的区域与时段映射

2026-09-23。保存处理方案，不自动执行换图或接受动画。

在动作异常的“回交姿态素材”之后，使用“素材区域与动作时段”：

1. 加载当前草稿的回交版本，选择图片版本。
2. 在原纹理画布上用笔刷选择三角形，可调整半径或擦除。
3. 输入生效区间 `[开始, 结束)`，保存区域与时段。
4. 重新加载可恢复映射；撤销保留旧记录。

映射限定原画布与原 UV，不改变骨骼权重或 deform。没有自动扩大覆盖区域，
没有通过透明叠加声称完成替换；超出原网格的新轮廓仍不能由此表达。
后续构建必须处理所选区域与原区域的互斥显示、时段边界、绘制顺序及新材质图集，
重新执行 Runtime、几何及视觉检查，不能沿用父候选接受记录。

记录绑定精确回交包、父候选、处理草稿、网格摘要、三角形和时间范围，
采用追加历史与乐观版本检查；过期处理草稿、非法选区、越界/非有限时间均拒绝。
历史版本撤销可在原处理草稿撤销后执行，避免留下无法撤销的记录。

接口 `GET/POST /api/motions/{job}/material-mapping`，使用现有同源 mutation 保护。
时间上限来自当前不可变候选的数值参考帧。没有新增真实美术素材；测试用原纹理，
保持 `unchanged_source=true`，不计入修复效果。

实际浏览器联调发现任务 JSON 中浮点整数在 JavaScript 回传后变成整数，
字段相等但内容摘要不同，造成重复回交与映射拒绝。
现在新回交保存服务端权威 request 原文；历史回交先验证其原始摘要，再按字段与
当前任务比较，兼容相等数字，同时保留原内容身份。新增对应回归测试。
