# 统一视角的姿态与髋中心候选

2026-09-22。新增隔离实验入口；不改变现有工作台默认姿态策略或旧版本合同。

## 实现

`automation/motion_view_pose.py` 使用同一明确 yaw 编译 MotionIR 根轨迹/旋转、转换绝对肢体向量和源髋中心；新 profile 绑定原动作、转换后动作及完整视角 receipt。目标姿态入口仅对该 profile 接受匹配的 oblique，其他姿态 profile 仍拒绝混合视角。裁剪时段、不同视角或不同动作身份拒绝复用。

完整构建复用现有网格修正、源三维脚踝稳定性资格、目标接触、同 yaw 深度检查和 Runtime。三维稳定性检查看 world_xyz 距离，不因摄像机 yaw 而改变；目标接触检查仍需重新执行。没有沿用旧候选接触通过状态，也没有声称脚踝稳定等于脚底贴地。Kimodo 准备路径沿用已验证的 source extract，但本次真实运行只有 BVH，未实测 Kimodo 全链。

工具 `m4_full_pose_candidate.py --yaw -45 --capture` 建立独立新候选；不开放 UI 自动采用。此时统一的是源观测坐标，尚未重建角色侧面纹理、厚度或全身遮挡。

## 红美铃 Squat 实际结果

- 精确请求：`motion-e2f8058160c14d959d468d75cc53a35e`。
- 候选：`f953dc8edcc7884aa30e5ed2ad3378109604b7c8a8b541ffff0c8d78b38493a9`。
- 髋中心拟合之前最大偏差约 205.784 px，之后约 2.54e-13 px；只表示对目标源位移的拟合，不是接触或外观误差。
- 623 个实际官方 Runtime 样本数值通过。目标 4.3.26、Runtime 4.3.13。
- 最终几何无翻转；layer-003 仍有 332 个失败帧，最小面积比 0.224303、最大边长比 1.9。其他部件通过该几何检查。
- 接触尝试在 624 个采样时刻的几何门禁失败，保留 `inferred_proxy_drift` 与 `phase_contact_geometry_failed`，不采用失败修正。
- 同步播放器的正向/反向定位、播放暂停、精确候选身份及 0/0.9/1.866667 秒捕获通过。
- 已查看最低点整角色画面：举臂保留，但膝部轮廓和支撑仍不合格；没有视觉接受。

输出位于 localset 下 `tmp/m4-motion-center/squat-full-view-v1`。`comparison/index.html` 左侧复用旧的仅肢体投影、右侧为新候选，两者采用相同相机范围。右侧同时加入髋中心和网格修正，因此不能把画面差异单独归因于其中一个因素。

六项定向测试通过，包括统一髋/肢体视角、零视角保持坐标、拒绝混合相机/裁剪时间，以及原姿态身份和不可观测失败仍不回退。实际完整构建验证新 profile 的目标入口。
