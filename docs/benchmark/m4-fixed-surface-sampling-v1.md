# M4 固定表面补偿的面积驱动采样

日期：2026-09-27。接续 [实测插值余量](m4-joint-boundary-margin-v1.md)。
状态：固定区域采样检查通过；尚未重新组合完整关节纠正动画，不采用。

## 方法

`fixed_surface_sampling.build` 直接从父动画计算精确补偿，对固定三角形检查
父包/正常区域面积下限。每轮从失败区间选择最差时刻作为新精确键，再检查
所有已出现的时间点与新八分点。不减少历史采样，不改变面积门槛，不超过
2,049 键。默认六轮，显式诊断可运行到八轮。达到轮次、键数限制或精确键失败
都会保留失败状态，不能被视作成功。

只改变选定附件的补偿 deform 采样；原骨轨道、绑定、其他附件、拓扑与 UV
不变。暂未叠加新关节局部解，不能代表混合区域或整角色质量通过。
