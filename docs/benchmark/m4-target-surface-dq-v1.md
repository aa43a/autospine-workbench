# 同源三维蒙皮对照

2026-09-24。采用 Kavan 等人的 approximate dual quaternion blending 思路，独立实现刚性三维变换混合；参考作者说明 https://users.cs.utah.edu/~ladislav/dq/index.html 。不复用受许可约束的示例源码。该方法有最短旋转分支限制，不提供网格无翻转或接触保证。

保持 alpha-surface-v1 的目标点、纹理、UV、权重、骨架、源 FBX 和校准方式不变，仅将三维 LBS 改为 DQ 对照。输入四元数归一化、同半球选择、双部正交化；恰好半周的模糊混合拒绝。不改 Spine 默认蒙皮，不覆盖历史候选。

四姿态结果位于 `localset/tmp/m4-motion-center/target-surface-dq-v1`；整段位于 `target-surface-dq-full-v1`。原动作 57 帧，加半帧共 113 个实际源采样时刻；这不是对新导出动画插值的验证，也没有 Runtime 新捕获。

| 指标 | 右腿 LBS→DQ | 左腿 LBS→DQ |
| --- | --- | --- |
| 0.9 秒失败三角形 | 27→4 | 14→1 |
| 113 次采样中仍失败的姿态 | 75→75 | 75→75 |

原 0.9 秒全部 27/14 处失败均包含混合权重顶点；这只是位置关联，不单独证明因果。保持输入不变的 DQ 对照表明混合方式有影响，但未消除异常。

剩余 0.9 秒 DQ 异常均为三维面积压缩：右腿三角形 109/117/126/228 面积比分别 0.4566/0.3501/0.4806/0.3786；左腿 242 为 0.2224。边长未超限。不能将这些内在压缩归为正常屏幕透视，原 0.5 面积下限不变。
