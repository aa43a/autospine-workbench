# 裙装随膝部撑开：固定材料点假设失败

2026-09-25。对已捕获 Alice Squat 的 0.9641929343342781 秒执行一次关键姿态试验。目标只涉及原始姿态被裙装覆盖、当前露出的一个材料样本；原来可见的小腿、腰部、腿脚骨骼均保持。

源材料点对应裙装三角形 292。它当前位于约 (515.344,-901.765)，目标腿部点位于 (652.5,-759.5)。让同一块裙布固定跟随该膝部样本，需要约 **197.614 px** 位移。用既有调和位移模块在三个拓扑邻接圈内分配增量，锁定所有带 chest 权重的腰部顶点。

结果：

- 选定露出点裙装 alpha 从约 7.246 升为 255。
- 原本可见的小腿样本仍未被裙装覆盖，腰部误差为 0。
- **29 个三角形翻转**；最小面积比 -2.988，最大面积比 4.268，边长最大倍率 3.620，明确失败。

这不是候选，也没有烘焙为动画、执行 Runtime 或替换已有结果。输出的 `posed-cloth.json` 仅保留失败试验的坐标证据。试验限制的是选定拓扑范围，未给该大位移授予可采用预算。

停止固定材料点跟随的方向，不通过扩大影响圈、提高预算或反复补点追求盖住一个像素。源图中的覆盖关系不意味着裙布与膝盖沿该材料点缝合。后续应检验允许布料滑动的覆盖边界约束，并同时保留可见小腿和完整裙摆形状；不能仅以目标点 alpha 达标当成服装修复成功。
