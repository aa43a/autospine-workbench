# Spine 动画互补裁剪能力验证

2026-09-22。**仅能力实验，不是真实深度修复或角色验收。**

复用 Alice Reach 原候选
`21969ed99dd41e85171f52842fc4754a8d8c4bd425fd722cf87a78ce94b9d437`
的已验证播放器，隔离 layer-003，保留原骨骼、网格、权重、纹理与变形。
在内存中生成前后两份同纹理 mesh，各由一个 clipping attachment 控制。
两条裁剪边界相同，其中一条 inverse=true；通过 deform 动画移动四顶点矩形。
两份 mesh 在本实验中相邻绘制，不夹入躯干，因此应当恢复完整袖片。

使用本地官方 Spine Runtime 4.3.13，原导出声明 4.3.26；未测试其他版本兼容。
Runtime 脚本摘要：`58aea42c0765cb518667681fa4a580b1d809a62a94423cd4d28f90783325a676`。
工具 `tools/check-m4-animated-clipping.mjs`，输出工作区
`tmp/m4-motion-center/animated-clipping-proof-v2`，包含 proof skeleton JSON 与逐项报告。

11 次采样（10 个不同时间并返回起点）：

- 裁剪顶点随时间变化，倒序回到起点后完全恢复。
- 8 次采样 RGBA 与未裁剪袖片完全一致。
- 其余 1、1.3、1.5 秒分别有 270、187、59 个像素存在任意通道差异，最大差值分别为 4、2、2/255。
- 对应 alpha 差异像素为 88、24、22；不宣称无损或完全没有边界采样差异。
- 负向对照关闭 inverse，1.3 秒产生 5,308 个通道差值 >8 的像素；原袖片有 11,976 个非透明像素，排除了空画面误通过。

结论：当前官方 Runtime 可以用标准 clipping/deform 通道表达移动的互补可见边界。
不同于此前 46 个固定三角形区域，这一表达允许边界穿过三角形内部。
它尚未接入真实源深度、上衣前后顺序、相邻图层保护、通用数值验证器或工作台默认策略。
现有 mesh-only 验证器不能直接把 clipping 证明当作普通候选通过。

下一步：从右肩源深度代理提取连续边界，先检查单闭合轮廓/拓扑稳定性与未知区域；无法满足时明确受限。
再将互补 mesh 放置于躯干前后，检查同帧贴图、切换连续性、覆盖和版本适配。
