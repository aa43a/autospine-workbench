# 袜脚与鞋联合过渡：仅剩一处局部插值几何失败，尚未采用

2026-09-24。承接 ff76b71 的腿鞋材料分离证据，原候选、人工接受记录和默认
工作台策略不变。目标仍为原幅度 Reach / Squat 在三角色上的实际可用结果。

## 局部表示与边界

红美铃原腿网格的右侧包含 29 个纯脚骨顶点、6 个小腿/脚混合顶点；左侧为
33 个纯脚骨顶点、5 个混合顶点。按已有权重确定实验区域，不把它声称为新
人工语义标注。纯脚骨顶点跟随已修正的鞋部世界变换；小腿及膝部其他顶点固定。
仅混合顶点先作调和位移，再在失败姿态作有界硬约束修正。

硬约束沿用面积比 0.5–2、边长比不超过 2；求解器内部保留更严格余量。
自由顶点相对调和解的位移半径取局部网格中位边长，不进行预算扩张。固定
袜脚和小腿边界不可为求解通过而移动。报告保留实际求解器源码 SHA256；
已有 boundary_shape_feasible 的其他未提交实验改动未在本次提交。

## 已验证与失败

- 五个诊断时刻、两侧十条记录：单纯平滑只有五条通过，硬约束后十条通过。
- 原始时间精度下，整段源关键帧及中点共 623 个时刻、1,246 条过渡区记录通过。
- 原膝部几何失败仍保留在 whole_attachment 指标中；局部通过不代表整腿通过。
- 首版 deform 烘焙候选触发 float32 时间关键帧冲突。相邻浮点时间在 Runtime
  中重合且修正值不一致，严格拒绝，不能按“误差很小”直接删除。v1 保留。
- 后续改为在 Runtime 可表示的唯一时间点重新求解，并在相同时间口径下合成
  原 deform 与修正，不放宽冲突阈值。

五项单元测试覆盖固定小腿保持、袜脚目标保持、不可行边界拒绝、Runtime
同时间同值合并和同时间不同值拒绝。没有新增视觉接受记录。

Runtime 时间口径重新解算后，622 个时刻、1,244 条局部记录全部通过。
`coupled-foot-transition-v2` 已烘焙成功，document SHA256 为
`5263277a5fe13e82faa45396a120248e7995aa3bdd335370cae437eddb86ef83`。
本版没有合并任何冲突关键帧；姿态报告 SHA256 为
`e356284fe75468d96eae004c896d2a652d8e936e90253ae27ce95929729e5ebc`。
这两项只证明逐姿态可行和候选已生成，不表示时间插值及 Runtime 已通过。

## v2 烘焙后检查

对候选全部关键帧及中点共 1,933 个时刻，双侧 3,866 条过渡区记录中仅一条
不通过：右侧 layer-003，0.6981770992279053 秒，面积比 0.498619，小于 0.5；
无翻转，边长比 1.96925。没有放宽门槛。整腿仍有 2,788 条失败记录，主要
包含原膝部问题，不以脚部改善替代整角色验收。

官方 Core 4.3.13 对目标 Spine 4.3.26 候选正逆向 3,866 次数值核对通过，最大
世界顶点差 0.000173475 px。`official-core.json` 绑定实际 scene 和 reference
字节摘要；不是 GPU 光栅或视觉验收。

另在七个诊断姿态复查上一轮相同的每侧 64 个材料 UV 点（由官方 Core 已核对
的世界顶点计算）：六个姿态腿鞋分离小于 1e-5 px；上述插值失败时刻右侧为
1.43742 px。结果见 `material-connection-poses.json`。此数字不是可见裂缝宽度，
也没有证明全段材料连接。原来约 151 px 的脱离在对应诊断时刻已消除，但新的
局部插值问题必须处理，不能仅凭大幅改善采用。

下一步在失败时间插入按同一策略重新求解的约束姿态，再检查它与相邻帧的
插值、相同 UV 材料连接和 Runtime；不增加自由区域或修改动作幅度。
