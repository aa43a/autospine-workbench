# M4 跨姿态一致补偿的必要条件筛查

日期：2026-09-27。接续 [小腿补偿对照](m4-distal-compensation-v1.md)。
状态：44 个反例姿态局部通过，完整动画尚未验证，不采用。

## 实现

`transverse_gain_feasibility.screen` 对一个固定强度同时检查全部输入姿态，
不允许每帧各自选择不同强度。使用单三角形位移预算上界、共享单顶点面积
冲突和固定区域面积检查。只有未发现必要条件反例的强度可进入实际求解；
无反例不是可解证明，也不是动画验收。

对于同一精确时刻，顶点位置是统一补偿强度的仿射函数，因此筛查由强度 0、1
的实际表面插值计算。测试将此结果与实际 `build` 在中间强度的输出交叉核对。
输入姿态必须对应相同骨轨道、已有纠正和末端锚定设置；工具从同一父包构建。

`tools/m4_transverse_gain_screen.py` 读取父包和全部既有可动退化最差时刻，
筛查 0 到 1 的 33 档强度。不会把未抽到的强度区间或时间区间宣称为通过。
