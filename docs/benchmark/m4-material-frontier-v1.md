# 肩部纹理遮挡边缘定位

2026-09-25。继网格外边界固定试验失败后，改为查找真实纹理上的遮挡变化位置。该诊断没有生成修正动画，没有改候选、权重或人工决定。

方法：在源手臂纹理像素中心映射至 setup 世界坐标，再读取躯干 alpha；相邻两点均被手臂网格覆盖、手臂 alpha≥8，且躯干 alpha 跨越 254 时记录插值位置。只保留原有 0.65 上臂长度的近端范围，半径边界自身不产生新边缘。这里是离散像素中心之间的诊断插值，不是 GPU 精确等值线，也不证明真实衣料缝合关系。

| 结构 | 边缘样本 | 4 秒同源位置分离中位数 | 最大值 |
| --- | ---: | ---: | ---: |
| Alice | 138 | 27.283 px | 39.685 px |
| 辉夜 | 304 | 31.684 px | 106.259 px |
| 红美铃 | 114 | 35.109 px | 75.923 px |

三个结构在 0、1.725、4 秒均能将全部位置映射到双方网格。独立无动画 setup 验证双方对应误差≤1e-6 px。动画第 0 秒不是 setup，不把该帧已有位移解释为贴图错位。表中数值是两个固定材料位置的分离，不是最终 framebuffer 裂缝宽度。

已直接检查原纹理标记图：Alice 对应的是披肩下沿遮住袖子的轮廓；辉夜包含肩侧、衣饰与斜向覆盖边；红美铃对应上衣侧缘覆盖手臂的区域。这些可见边界具有不同的连接含义，当前图像证据不足以把整条边都当作固定缝合点。固定全部边缘点会把正常遮挡滑动也变成拉伸约束；因此未进入求解或烘焙。

下一项应明确区分固定连接和可滑动遮挡：固定区才允许材料点跟随躯干，遮挡区检查运动后是否露出不应露出的近端材料。没有连接语义时继续保持待适配，不从网格外围或 alpha 轮廓自动批准固定约束。先做关键姿态验证，不能以本报告代替 Reach/Squat 六案例验收。

复现：`tools/m4_material_frontier_probe.py`，输入 `localset/tmp/m4-motion-center/reach-live-yaw-comparison-v1/torso-reference-v2` 和 `reach-depth-replay-v1`；核对每个冻结候选身份及纹理摘要。输出仓库 `tmp/material-frontier-v2/report.json`，以及每角色 `*-frontier.png`、`*-body-frontier.png`。无默认采用权限。3 项单元测试覆盖纹理内跨边、透明/未覆盖点排除、半径不造边、世界坐标半径和输入不变。
