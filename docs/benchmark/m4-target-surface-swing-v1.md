# 绕轴分量隔离：不是薄片问题的充分解释

2026-09-24。加入显式 swing/twist 分解，仅在 `--swing-control` 诊断中去掉源绕轴分量；默认仍保留完整旋转。记录每根骨骼被移除的角度、指向误差和重建误差。半周 swing 歧义拒绝；若链端点变化大于 1e-6，实验拒绝。

输出 `localset/tmp/m4-motion-center/target-surface-swing-v1/poses.json`，原动作帧和半帧共 113 个时刻。三维髋/膝/踝位置相对原完整旋转对照的最大偏差为 4.1784e-11 像素；此处保持的是既有实验链，不是源地面接触。

0.9 秒移除角度：右 thigh/calf/foot 为 -18.578/-10.214/-8.345 度，左为 14.969/20.158/10.954 度。DQ 几何失败时刻数右腿 75→8，左腿 75→79，每姿态最多仍有 1 个失败三角形。不能只报告右腿的改善。

使用同一渲染器进行八张原贴图／单腿不透明对照，输出 `target-surface-swing-render-v2`（v1 保留，v2 增加“移除源绕轴”的显式标记）。检查 0.9 秒合成及左腿独立图，薄片和尖窄轮廓仍存在。不同实验目录的相机取各自全局包围盒，尺度略有差异，不能据此直接做跨目录像素差；每个目录内部 LBS/DQ 相机固定。

18 项测试通过，包括旋转分解重建、指向不变、纯绕轴、歧义拒绝及既有 DQ/表面回归。

结论：去掉源绕轴不足以解决近侧立的二维前表面，没有理由自动删去源动作。应停止用去旋转或 alpha 修改修这一表达限制，下一步建立具备侧面体积的目标部位，并明确侧面材质来源；同时保留失败三角形和当前动作。候选未采用，完整 M4 未完成。
