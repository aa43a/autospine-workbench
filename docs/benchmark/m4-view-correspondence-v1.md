# 新视角显式对应计算

2026-09-25。view_correspondence.compile_mapping 根据人工提供的控制三角形，将原网格 UV 映射到新视角 UV 和骨架世界坐标中的目标姿态点。源与目标 UV 均采用左上原点，姿态点采用世界 XY，不推断解剖或缺失纹理。

输出保持原顶点索引，可供后续姿态附件编译使用；不修改输入网格、不生成动作或接受记录。源网格三角形必须完整处于一个控制单元内，否则必须先显式细分，不能仅移动三个端点而丢失跨单元映射。未覆盖顶点、冲突对应、退化控制单元、UV 翻转和局部姿态朝向不一致均拒绝。共享边须在 UV 与姿态坐标中一致。

五项测试验证已知仿射解、非均匀分片映射、共享边、冲突、身份与覆盖检查。计算有工作量上限。此实现不是全局自交证明，不包含源纹理内容判断，尚未连接上传、附件切换、过渡动画及 Runtime 验收。

下一步将映射结果与有身份记录的素材回交绑定，再生成激活区间内的独立姿态附件；保持区间外原附件，检查切换边界和完整动画，不把单姿态映射成功作为大动作通过。
