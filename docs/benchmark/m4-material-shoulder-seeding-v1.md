- 原直接求解：一侧可行，另一侧未找到可行解。
- 8 步接触目标连续推进：第一侧最终可行；第二侧在 0.5 的中间目标处失败。中间解不作为动画输出，最终门槛未放宽。
- 网格路径必要条件检查：两侧均未找到反例。这不证明可行，也不能把数值求解失败说成数学无解。
- 调和位移初值：复用已有 `material_anchor_field`，由源支持接触点沿网格邻接分配初始位移，再执行原有硬约束求解。两侧在此姿态均可行。

调和初值后的两侧最小面积比约 0.505、无翻转，最大边长倍率约 1.995；最大位移分别约 73.373 / 89.817 px，仍受原来的各侧预算约束。初始化阶段把区域中心作为目标，最终求解仍允许顶点在原覆盖区域内滑动，未改成整边缝合。

## 实现与保留条件

- `shoulder_contact_regions.solve(..., harmonic_seed=True)`：显式实验选项；失败时返回原姿态，绝不把未通过的初值烘焙出去。
- `boundary_contact_continuation.py`：最终一次使用原样的目标与区域，整个过程保持原始 world 相对位移预算。
- `contact_region_path_bounds.py`：用椭圆的外包圆给出保守最短距离下界。无反例不等于通过。
- `m4_material_shoulder_sequence.py`：验证来源候选和 MotionIR 对应候选的骨架与骨骼动画一致，在真实 57 个源时间上求解，保留旧时间并增加插值检查；不自动采用。

24 个针对性测试通过，包含失败初值隔离、最终约束不变、细长椭圆不会被错误判定为路径冲突。单姿态完整证据见 `m4-material-seed-comparison-2026-09-25.json`，路径证据见 `m4-material-contact-path-bounds-2026-09-25.json`。

## 整段结果与下一步

两侧各 57 个源姿态全部成功，源姿态求解失败为 0。独立结构检查确认仅两袖 deform 改变，Float32 关键帧时间没有重合。

但 **7,425** 个密集时间点检查未通过：覆盖区域最大比例约 **1.005867**，193 条区域记录存在面积失败；另有约 **1.094e-6 px** 的固定远端误差，超出保持原位置的 1e-7 检查值。总计 12,483 条失败区域记录，不能按不同帧数量解读。未捕获或接受这一整段候选。

固定远端误差定位到新工具把旧 deform 转折时刻一起取整。已新增 `runtime_union_times`：保持全部旧转折时刻原值，只合并新时间在 Runtime 存储中的别名；若旧时间本身碰撞则明确拒绝。新增测试验证尖角时间附近原曲线不改变。此修复尚未重新跑完整求解，不能追认第一版通过。

目前共 **26** 个相关测试通过。下一步以保留旧关键时刻的版本重建，并针对覆盖和面积插值异常增加有证据的采样/求解余量，最终检查门槛不变。整段证据摘要见 `m4-material-shoulder-sequence-2026-09-25.json`。
