# 连续普通裁剪接入近端材料片

2026-09-22。完成连接片与新裁剪表示的组合验证；未采用，尚未通过肩部视觉验收。

## 变更

此前近端材料实验依赖已拒绝的凹 inverse 裁剪。本次从原动作重新生成固定四顶点普通裁剪，接入独立近端材料片：连接片放在裁剪范围外、躯干之前，继续使用原手臂的加权网格和 deform；其余前后分区共用自由部分纹理。没有把整个袖子固定到胸部，也没有改变骨骼轨迹、动作幅度或关节位置。

修复原 atlas padding 被重新 edge-pad 的问题。新页沿用源图集页的 RGB 和边缘 alpha，仅按分片决定清除 alpha；严格核对源页尺寸、内部像素和 atlas bounds，布局不符则拒绝。这消除了已识别的额外边缘重建来源，不意味着材料分片可以精确重构所有双线性混合。

## 实测

- Alice 近端选区为原策略的 1,390 个纹理像素，含 111 个内部不透明保护像素；只改表示的接入和图集边缘，不扩展选区。
- 完整隔离手臂（连接片加连续前后裁剪）在 481 个键时刻/中点：不透明像素缺失 0；单帧最多 7 个像素差异超过 8/255，最大预乘通道差异 59/255。
- 独立材料分片实验（没有裁剪）同样得到缺失 0、最多 7 个差异像素、最大差异 59/255。说明这些峰值可在材料过滤/合成阶段出现；统计峰值相同不等于每个差异坐标均相同。
- 两实验均有删除手臂的负对照，以及末尾回退起点的像素复现。
- 整角色同步播放器通过；检查 0、0.7、1.05、1.5、2.4 秒，另以相同世界范围和最近邻放大查看肩部。连接片能留在上衣后方，但放大图仍见边缘亮点，未宣称自然轮廓通过。
- 26 项相关单元测试通过，包括保留真实 padding、拒绝不支持布局、原 weighted deform 沿用、连接片位于裁剪范围外和原输入不被修改。

仅材料分片为 2 个隔离槽位；组合手臂为 478 个槽位。几何本身沿用原候选，但尚未完成本表示的独立几何、深度插值和完整遮挡验收，不能用无像素缺失替代这些门槛。
