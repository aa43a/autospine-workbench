# 新视角画布对应编辑

2026-09-25。动作中心 → 检查可用范围与待处理项 → 查看变形区域与处理方案 → 补充姿态附件 → 选择新视角类型并保存。回交区选择 PNG 后，可点击“在画布上编辑新视角对应”。

左画布编辑新图片的目标 UV，右画布编辑相同控制点的世界 XY。保持原图比例，支持选点、拖动、滚轮缩放、空白平移和方向键微调，Shift 增大步长。源 UV、网格三角形、权重身份不改变。所有姿态共享目标 UV；每个姿态单独保存时间与目标坐标，生效区间必须覆盖所有保存点且时间严格在区间内部。

可保存、删除姿态，拖动时间轴或播放对应插值，下载 JSON 草稿，或使用画布结果回到现有候选提交入口。未保存坐标阻止预览切换或回交；再次修改后已加载的回交结果失效。切换图片、草稿或对应文件会清空画布结果。原 JSON 高级提交仍可用。

这不是完整骨骼动画预览：它只线性插值已保存世界坐标，区间端点保持最近保存姿态，未模拟原动画与附件切换。正式几何、接触、遮挡、Runtime 与切换边界检查仍由生成候选承担。新贴图需要用户提供，当前不自动绘制缺失视角。下载 JSON 可用于高级回交，尚未提供重新载入到画布继续编辑。

验证：`tools/check-view-pose-state.mjs` 检查输入隔离、插值不覆盖保存点、UV 同步、非法区间和删除；原 4 项回交身份检查通过。内置浏览器在 `tools/write-view-editor-fixture.mjs` 生成的合成双色 100×200 图片上确认两画布保持比例；方向键将目标点 X 从 0 改至 1，保存 2 秒姿态并回交所得 JSON 相符。再次编辑使回交结果失效，保存 3 秒姿态，播放推进到 1.564 秒后可暂停。未据此宣称真实角色修复或视觉验收通过；鼠标拖动和文件上传仍需后续完整交互回归。

实现分为状态、画布绘制、编辑界面和既有回交入口四个模块，各文件低于 150 行。
