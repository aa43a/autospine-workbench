# 自动绑定人工抽查

## 默认沿用、异常修改（2026-09-20）

重建后的异常保留：同项目中仍有效且完全相同的自动决定（图层、决定地址、目标和策略）会继续显示原任务的未修复异常，并进入当前待办。更换任务 ID 或修改其他候选内容不能消除异常。不同项目、失效证据或已实际改绑的决定不沿用。页面显示原任务来源；沿用项不重复计入当前人工抽查或计时。

实际修改绑定后重建，或明确纠正误报并保存“归属正确／默认沿用”，可以解除对应异常；“无法判断”不会解除。显式解除保存为 `character-auto-binding-audit/v2`，引用原异常 ID；v1 历史保持原字节。客户端提交当前异常证据摘要，其他会话先修改记录时拒绝过期保存。只保存计时不创建新判断，也不会解除异常。

按用户最新要求，自动归属默认沿用，无需逐项确认、保存或完成全量抽查。入口为“动画预览 → 自动归属与异常修改”。在当前页选择图层、查看动作和时间轴；发现错误点击“标记异常并修改”，先保存该项异常，再打开对应图层绑定编辑。保存失败保留草稿，不跳转。修改后重建候选并做阶段验收。

既有错误和人工决定保留；默认沿用在审计合同中仍为 `not_reviewed`，不会伪造 `correct`。抽查是可选质量测量，不作为工作流继续的前置条件；未测总体精度仍为未知。以下抽查操作说明适用于自愿抽样。

整角色候选就绪且没有未保存编辑时，面板自动读取一次当前抽查清单；已有错误会展开显示。
入口：顶部“动画预览” → “当前还差什么”下方“自动归属与异常修改”按钮，点击自动展开并滚动到清单。
读取失败可点击“读取自动绑定清单”重试，不会自动循环请求。切换项目或候选会隔离旧响应。
打开“自动归属与异常修改”，每层显示自动选择的骨骼目标，可定位原图层，记录归属正确、需要修改或无法判断，再保存。默认沿用（未单独抽查）；可以改回该状态，历史记录保留。自动读取仅恢复记录，不自动提交判断。

这里只统计当前候选中证据有效的 `policy_auto` 绑定，不把人工绑定、沿用确认、几何通过或整角色视觉接受当成抽查结果。记录绑定到候选、项目、任务及自动决定清单；来源变化后不能沿用。保存使用乐观版本检查，同一批次先验证全部范围，再追加记录。

抽查不改变绑定。不正确的归属需要在原绑定入口撤销或修正；首批十角色及固定三角色评估会将已验证的“不正确”项加入待办，不能继续计作验收完成。

整角色进度和图层账本默认“待处理图层”中。点击该层可定位原绑定入口；账本解释
修正后需要重建，已有整角色视觉接受不会覆盖此错误。其他候选、其他项目或非自动
绑定的抽查项不会污染当前列表。这里只呈现已读取记录，不会自动填写判断或撤销绑定。

统计展示明确判断数、正确数、需修改数、无法判断数、未抽查数。抽查错误率的分母只有正确与需修改两类；分母为零时为未知。它是人工选择样本的测量，不是全部输入的精度，也不等于独立测试集的错误自动采用率。后者与人工总耗时仍按缺失证据保持未知。

在“动画预览 → 自动归属与异常修改”中，左侧选择图层，右侧直接检查当前候选的官方 Runtime 预览。可切换局部与整角色、选择动作和拖动时间轴；显示策略目标骨骼。检查不再跳转到素材检查页。

使用“当前项：归属正确／需要修改／无法判断”记录判断，再点击“保存并下一项”；也可以逐项选择后统一保存。保存失败保留草稿与当前项，切换候选会清空旧候选预览。局部隔离只作用于预览，不修改纹理、骨骼或绑定。

抽查支持显式“开始 / 继续复核计时”，离开时请暂停。保存抽查会暂停并保存累计计时；重新读取可继续。可以只保存计时，未判断项仍保持未抽查。候选更换会清空未保存计时，历史未计时记录保持未知。汇总单列当前候选自动绑定抽查会话的已测项目数与分钟数，不等同全部人工耗时，不与视觉复核会话盲目相加。旧客户端保存保留已有计时，服务拒绝计时倒退或越界值。

接口：`GET/POST /api/projects/{project}/automation/character/jobs/{job}/auto-binding-audit`。POST 接收 `expected_artifact_sha256`、`expected_review_sha256` 和按图层 ID 索引的 `reviews` 修改项。记录合同位于 `schemas/character-auto-binding-audit-v1.schema.json`。不覆盖已有角色、候选或绑定历史。
