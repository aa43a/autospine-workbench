# 校准后的下蹲三维蒙皮参考

2026-09-24。继骨架兼容性检查后，用 `tools/render-motion-surface-reference.py` 将固定 Squat 的 0、0.933333、1.866667 秒姿态应用到动作库 Beta 模型。原始 FBX 及正式 Spine 候选未修改。

参考传递不是直接复制动作：在共同 armature 坐标系中补偿初始骨骼方向与 roll，再对齐源骨段方向，按源端点距离缩放骨段 Y。逐骨设置世界对应位置后重新读取实际姿态端点，检查与源动作的一致性。此参考使用源身体比例，不声称完成目标二维角色的比例适配。

三个姿态各 53 根骨骼的头尾端点最大 Blender 世界坐标误差 `5.591535402036295e-7`，阈值 `1e-5`。生成正面、侧面共六张 Workbench 蒙皮渲染；同一视角三个时刻使用完全相同的相机和尺度。图像 SHA、相机矩阵及各骨骼归一化投影坐标保存于 report.json。复核六图哈希、每图 53 个骨骼坐标有限、相机一致性通过。

产物：`tmp/squat-source-surface-v4/index.html`。首次 v2 发现 Blender 将相对渲染路径解释到其他位置，已改为绝对路径并增加捕获存在检查；v2 报告保留，v3/v4 完整图像位于仓库临时目录。v4 增补了相机与投影证据。

图像检查：最低点保留源举臂，侧面可读出大腿前伸、小腿倾斜和身体下沉；正面更多体现缩短与遮挡，不能用侧面膝部横向位移直接修正正面图。参考模型是分段人体模型，不是目标角色皮肤/衣料，其局部蒙皮质量未作生产验收。端点通过不能解释为接触、目标轮廓或完整动画通过。

下一步用已保存相机与关节坐标对齐目标候选，在同一视角下比较骨架表达与膝部实际轮廓。只有明确是哪种轮廓/遮挡差异后才生成独立目标修形，不重新启动已失败的原网格 ARAP 参数搜索。M4 原六案例及三角色八动作要求保持。
