# 严重压缩侧的固定顶点不可行证据

2026-09-25。两项长时间双面积求解已主动终止，没有生成或接受候选。
终止依据来自独立必要条件：所有顶点固定的三角形，其面积无法由当前混合
顶点修正改变。0.766667 秒 Alice 有 33 个、红美铃有 68 个这种三角形，
面积约为原始面积 0.296591，低于不变的 0.5 门槛。

新增 fixed_area_feasibility，在显式双面积修正开始前检查所有采样时刻。
报告具体槽位、三角形、时间及两种面积比；有固定顶点反例即停止求解，
没有反例仅记为“未发现固定三角形反例”，不等于整个问题可解。
固定顶点集合在袖口等可选自由区处理后计算，保留原有语义。
该检查不改变默认修正策略，不松动固定顶点或放宽预算。

真实两角色重新预检共耗时约 5 秒（含 12 项测试）：Alice 3,267 条、
红美铃 6,732 条固定面积失败观测；完整记录位于各
`tmp/m4-moving-workbench/{角色}-squat-fixed-feasibility-v1/infeasible.json`。
这些是跨帧重复观测，不是独立错误数。摘要见配套 JSON。

此前右侧完整几何通过结果保留。严重侧现在明确受固定单骨区域的投影
缩短限制，继续调整混合顶点不能解决。后续需研究可表达缩短的区域/姿态
素材及其独立质量验证，不将不可行结果伪装成通过，也不缩小动作范围。

12 项相关测试通过，覆盖固定区反例、可移动顶点不作不可行证明、负向

不是求解器给出的成功或失败终态；正式不可行依据为新预检产物。
