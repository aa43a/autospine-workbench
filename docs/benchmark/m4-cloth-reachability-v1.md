## 可达性口径

固定纹理和 UV 后，三角形内材料点的位移是三个顶点位移的重心组合；每个顶点位移不超过 8px，则任何材料点位移也不超过 8px。对双线性 alpha 采样，把“至少一个角点 alpha 达阈值”的纹理单元作为不透明支持的保守超集，裁切到实际 UV 三角形，再计算与目标的世界距离。超集距离大于预算时，可排除该局部变形假设；不能推出所有修复方式不可行。

检查覆盖目标附近半径 16px 的全部可能纹理单元，远处由三角形包围盒和映射范围排除。距离下界在搜索半径处截断。退化三角形返回未测，不伪造不可达证书。该结论针对逐三角形最大 alpha，不是多附件/GPU 混合结果。
