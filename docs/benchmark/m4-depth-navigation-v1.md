# M4 遮挡诊断的实际时刻定位

2026-09-26。工作台的完整遮挡定位现在读取独立的只读导航接口，继续绑定原候选、
骨架和深度报告身份，不改变 readiness、绘制顺序、骨骼、权重或人工决定。

## 修正的问题

旧入口仅遍历 `order.failures`，并使用其中的区间起点。排序约束可能来自后续中点的
重叠采样；此时跳到起点并不能看到对应证据。排序提前停止后，配对或区域报告里的
未测记录也没有进入这个“完整”定位入口。

新接口使用现有 `depth_failure_records.collect` 汇总已记录的排序和未测项，按部件
关系、原因和时间来源分组。已有实际重叠、区间请求、预算失败、环路边采样时间时，
定位使用该时间，同时保留原判定起点。区间中的两个相反建议分别保留；环路只定位
确实记录了采样的边，不为其他边编造检查时间。没有额外时间时明确显示“报告记录
时刻”。非法的明确时间被拒绝，不悄悄退回起点。

工作台在当前页面提供逐采样滑动选择、精确定位及相关部件隔离，并区分模型前后
不确定、排序约束冲突和未完成检查。模型不确定不被描述为已经观察到穿插。这里只
汇总已记录的诊断；原检查提前停止后尚未产生的潜在问题不能算作已覆盖。
