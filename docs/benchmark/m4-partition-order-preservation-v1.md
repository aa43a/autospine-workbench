# 已有动画排序的无损区域展开

2026-09-25。为局部衣料覆盖表示补齐分区前置能力：`depth_region_partition.build` 增加显式 `preserve_draw_order=True`。默认行为不变，仍拒绝已有排序；新模式在每个源排序关键帧将源附件展开为连续分区，保持分区内部三角形顺序。

## 不变量

- 原纹理路径、UV、顶点与权重完整保留，deform 仍复制到各分区，不重新绑定。
- 源关键帧的时间数值保持；省略时间的零帧仍省略。空 offsets 恢复展开后的 setup 顺序。
- 使用已有 Spine offsets 编解码器检验排列，Float32 时间碰撞、非法时间、未知字段、旧 draworder 键均拒绝。
- 原候选不修改，现有深度、视觉决定和生产状态不迁移。新模式仅保持原画法，不解决原遮挡错误。

## 验证范围

10 项分区及合同测试通过，含真实 reorder/reset、多动画、变形采样、错误回滚和默认拒绝行为。

另读取三角色共享 45° Reach 的精确候选，以现有权重归属分区：Alice 2 区、辉夜 30 区、红美铃 2 区。0、0.7、1.725、2.4、4 秒各区全部顶点与原源层一致；UV、权重逐项一致，各分区三角形串联等于原序列。详见同名 JSON。三份真实输入均无排序关键帧，非空排序保真由回归 fixture 检验，不能称为这三份真实输入已测试动态换序。

没有将这些权重分区标记为袖根/披肩人工语义；没有修改当前资产或生成 Runtime 验收。此轮未接入新的工作台操作。下一步仍需让明确覆盖语义与可穿越区域形成独立候选，再验证实际遮挡，不能以分区保真替代 M4 动作质量。
