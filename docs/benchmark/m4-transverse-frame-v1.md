## 问题与方法

红美铃下蹲的 `layer-004` 同时存在两件事：

- `thigh_l` 在 0.8 秒的世界轴长度约为 setup 的 0.296，横向宽度仍为 1。
  纯大腿权重三角形 53 的面积比为 0.2959757953，与骨骼行列式投影参考一致。
  这不是混合权重塌缩，局部关节修正不能在固定这些顶点的同时满足 setup 面积下限。
- 小腿继承了不等比父骨缩放，横截面还具有约 -1.36 的沿轴分量。
  保留垂直厚度不等于没有斜切；长袜、鞋边等离骨轴较远的像素会被额外拉偏。

新增通用策略按实际 affine 骨骼矩阵消除第二项。若世界矩阵两列为 X、Y，
定义 `k = dot(X,Y) / dot(X,X)`，每个 influence 的新增局部变形为
`dx = (k_setup - k_current) * y_setup`、`dy = 0`。
这保留骨轴映射、每个 influence 的行列式和已有局部 corrective。
不修改骨轨迹、权重、UV、拓扑、贴图和其他附件；不夹紧真实的投影缩短。
该平面横截面约定不是三维表面重建，也不解决未见侧背面或轴向扭转。

直接补偿仍可能破坏关节混合区：最初 129 帧试算在红美铃左腿新增 19 次三角形翻转。
因此候选随后执行 **叠加式关节面积修正**，保留已烘焙的横截面修正，
时间连续性的初始值只传递新增修正，避免重复叠加旧 deform。
能够同时满足 setup 与投影面积门槛的区域继续使用双重约束；
固定区域存在反例时保留反例，只输出投影约束下的诊断对照，原始几何门禁仍判失败。
