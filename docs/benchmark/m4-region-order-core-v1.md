# 区域绘制顺序候选核心

本切片增加 `region_order_candidate.build`：将明确选择的三角形移到参考附件之前或之后。保留原权重、UV、顶点索引及动画 deform，剩余区域留在原槽位位置。它是全动画静态顺序编辑，不是动态深度推断，也不自动采用。

复用现有连续三角形分组，保留每组内部的绘制顺序及完整索引空间。移动组和保留组之间的顺序会改变，不能宣称完整源绘制顺序不变。既有 drawOrder、源 slot 时间轴、clipping、linkedmesh 等不支持结构继续拒绝。

## 验证

- 五项单元测试通过，覆盖多骨影响、稀疏 deform 原样复制、采样位置、输入不变、非法选择及不支持动画。
- Alice Reach 原完整角色的 layer-003 选取 UV 顶部 69 个三角形，生成 18 个连续区域。此选取仅用于结构验证，不是认可的肩部语义边界。
- 官方 spine-core 4.3.13 在 120Hz 的 481 个时刻检查全部输出附件，共 2,765,269 个顶点：与源对应顶点 Float32 值完全一致。输出与输入有独立 SHA，未沿用原候选身份。
- 结果：`tmp/region-order-core-v1/runtime.json`。检查工具：`tools/check-region-order-core.mjs`。

目标 Spine 版本仍为 4.3.26，实际验证 Runtime 版本为 4.3.13。本次不包含 framebuffer、视觉验收或遮挡正确性判断。CPU 测试采样器只支持稠密 deform，因此测试展开独立副本进行位置对照，并单独检查输出稀疏轨道原样保留。
