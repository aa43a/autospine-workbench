# 材质坐标接入肩部整段验证

2026-09-25。肩部区域求解与独立验证已支持实际 attachment 变换，防止漏算躯干烘焙后的材质位移。没有因此接受现有 Squat 候选。

## 自动选择范围

`shoulder_source.contexts` 从已复核上衣源 alpha 中记录能覆盖全部接触样本的材质层。只有唯一候选时，区域流程自动使用它；零个或多个候选明确报错，要求分开区域。此操作只选择约束坐标，不产生新的人工归属或验收记录。

`shoulder_region_validation.inspect` 在每个检查时间从实际衣服顶点恢复精确仿射变换；非仿射、退化和反射仍拒绝。历史手工测试数据未提供材质信息时保留显式标注的 `chest_bone` 结果，不能与 `verified_material_affine` 结果混为一谈。空时间列表不再可能返回通过。

`m4_shoulder_region_sequence.py` 的求解使用同样的实际覆盖材质坐标，随后独立检查最终 baked 顶点。旧 headroom 记录的材质来源不匹配时拒绝复用，避免拿旧坐标系的余量修补新结果。
