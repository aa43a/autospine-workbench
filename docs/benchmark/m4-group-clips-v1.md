# Reach 裁剪合并：压缩成功，覆盖失败

2026-09-22。两版新候选均未采用；停止近似平面合并及边界重叠调参，保留上一版独立三角形候选作为参考。

## 假设与实现

邻接三角形若可由同一个深度平面表达，则共享普通裁剪矩形。精确匹配只将 119 个动态三角形缩为 112 组。实验改用采样时刻 0.05 像素边界偏差预算，得到 50 组、201 个手臂槽位（原 477）。以每组三角形种子的平面验证所有成员，避免邻接链累积误差；统一矩形覆盖整个组，而非仅覆盖种子。

该预算仅约束输入的 241 个时刻，不是插值或视觉接受门槛。前后分侧对照与完整合成重构分别检查。输入纹理和原动作保持不变。

第一版缺失发生于 0.4583335、0.8166665、0.9、0.92499975 秒，最大预乘颜色/alpha 差异 255。不能因为单帧只有一个像素就称为无回归。

第一版前方区域相对未合并参考最多差异 5 个像素、后方最多 5 个；这是前后归属变化的证据，不能当作完整角色的缺失计数。完整合成缺失另行统计如上。

数值重叠试验没有消除缺失，反而增加发生时刻。因此不能把问题确定为共享边界开闭约定，也不继续增大重叠；还可能涉及裁剪后网格边缘的光栅化精度。根因尚未被证明。

捕获工具最初同时传输和构造多份完整场景，浏览器多次意外退出，未产生通过证据。改为 Node 端筛选待检槽位、每次仅传输一对区域，并使用轻量同源页加载官方 Runtime 后，完整合成及前后分侧均完成。此观察支持减少验证内存占用，但没有单独测得退出的系统级原因。

17 项相关单元测试通过，包含按屏幕距离约束、深度单位缩放、邻接范围、统一矩形覆盖、边界重叠上限及原加权数据保持。单元测试通过不覆盖上述像素失败。
