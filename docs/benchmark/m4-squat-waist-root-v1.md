# Squat 裙腰与辅助骨链根部位移实验

2026-09-25。负向 55° Alice Squat 的裙装几何失败已在隔离候选中修正；肩部覆盖与整体视觉异常仍保留。未设置默认策略，也未继承任何 Reach 接受记录。

## 方法与边界

裙腰由 chest 驱动，裙摆三条辅助骨链根部在 pelvis 下。现有躯干平面变换改变裙腰，却不改变这些根部的位移。

新增 `attachment_root_transport.displacements`：对明确指定的辅助骨链根部，计算其锚点在所属躯干平面变换中的位移；整条辅助链只增加相同平移，保留原有线性变换和动作。拒绝重复祖先根部及本来已经继承 owner 的根部，避免叠加两次。算法不包含 Alice 名称、固定坐标或裙装比例；具体骨链由实验显式声明，尚不自动推断所有服装归属。

实验只将位移烘焙到对应加权 deform，不改骨骼轨迹、权重、纹理或绘制顺序。裙腰仍使用原胸部驱动。`m4_combine_correctives.py` 仅允许同一父候选的互不重叠 deform 修改合并，随后重新检查整个角色。

首版新增时间点在 Float32 中有 7 对重合，官方存储检查明确拒绝；该首版不是成功播放结果。第二版在可表示时间重新计算关键帧，原父候选的数值检查时间仍由独立验证器保留。没有删除失败几何样本来通过检查。

## 已验证结果

- 根部最大位移约 **13.561 px**。
- 裙装最小面积比从 **0.487376 → 0.520243**，最大边长倍率 **1.383547**，无翻转。
- 与两腿修正组合后，整角色 **3,713** 个采样时间的几何检查通过。
- 裙腰 **17** 个相同材质点的最大数值分离从 **0.019827 → 0.010071 px**；这是接触定位证据，不代表 GPU 裂缝已验收。
- 官方 Runtime **4.3.13** 对目标 **Spine 4.3.26** 候选完成 **3,713** 个采样检查。PNG 按间隔输出，不是每个采样都有截图。
- 查看约 **0.9646 秒**捕获画面：肩部/披肩间隙与裙旁浅色脱离区域仍存在。因此候选保持待修状态，不请求用户接受明显遗留问题。
