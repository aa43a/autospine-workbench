# 支持范围报告的异常时刻直达

支持范围报告此前只显示 readiness 的检查汇总，虽然 JSON 中已有失败时刻，
仍需另行翻找。现在固定、独立视角、策略及注册改进候选均在各检查项下展示
已有失败样本、部件及原因，并链接到该候选的播放器时间轴。

没有时刻不推算为零秒，非数值、负数及非有限值均不生成时间链接；
相对检查链接只允许已知报告名。候选路径保持精确任务和注册身份，
不使用失败记录提供的任意 URL。显示的样本不代表全部失败帧，
且不修改技术结果、验收结论或固定候选。

验证：

- 22 项支持报告相关测试通过，包括精确注册路径、保留浮点时间、零秒、
  缺失时间、无效时间、转义及既有验收范围回归。
- 使用 v5 快照（SHA256
  `05392bba778a3d5ef8506b97b8e1dbe3e99625144f0d3a8f78576773eac7c078`）
  重新渲染 HTML；没有重新收集或覆盖快照。
- 真实 Chrome WebGL 对转体、下蹲、拳击 × 三角色，共九个实际报告链接逐项点击，
  核对候选身份、暂停状态和时间轴位置，全部通过，无页面错误。
- Alice 拳击几何失败 0.38671875000000006 秒的截图已检查，
  页面显示 0.387 秒，内部时间保持原始精度。

生成入口与证据：工作区 `tmp/m4-failure-locations-20260928/index.html`、
`check.json` 及九张截图。可复用验证工具为 `tools/check-m4-failure-links.mjs`。
两个新增模块/工具均低于 400 行，主报告模块 128 行。
本次解决定位入口，不增加动画质量通过数量，不清除九个组合的技术异常。
