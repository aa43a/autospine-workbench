# 肩部材质点与边界顶点的区别（2026-09-26）

源候选为 Alice Squat `418038c3621a71b2a56893f53862b0611ce1feb7e0b232f75e786d09ff29dcb2`。本轮不改变候选、骨骼、权重或人工记录。

## 发现

旧 `prepare_regions` 为近接触边界的网格顶点选择覆盖区内的圆盘，但顶点本身不一定是有效材质接触点。在原始 setup（不同于动画 time=0）检查：layer-003 的 6 个圆盘约束、layer-004 的 5 个圆盘约束全部不满足，最大距离/半径比约 6.325；另一个右侧顶点没有圆盘，仍单独保留。不能把此基线不匹配全部归因于动画损坏。

## 实现

`material_contact_points` 把覆盖区内的真实材质坐标绑定到所属三角形，使用三个顶点的重心权重逐帧追踪。拒绝网格外点、歧义重叠、退化区域及拓扑变更，不外推到最近顶点。公共边界仅允许顶点权重等价的映射。

诊断工具选择已验证覆盖圆盘的中心点，并检查这些点在来源衣服 alpha 中均为 255。11 个材质点 setup 重建误差为 0。五个测试覆盖仿射及非刚性变形、公共边界、歧义重叠、无外推及拓扑保护。

## 真实姿态取样

在 0、0.964584、1.1 秒追踪同一批点，使用已验证的衣服材质仿射逆变换读取衣服原图最近 texel alpha：

- layer-003 的六点在三个时刻均低于 alpha 8。
- layer-004 的五点在 0 秒均低于 8；后两个时刻有两点达到 249–255，其他仍为 0。
- 与原衣服同材质位置的位移峰值约 85.662 / 94.081 px。披肩允许相对滑动，此数值不是裂缝判定阈值。

这证明这些选定材质点的覆盖发生变化；不能据此认定全部外露都是裂缝，也不是 GPU 合成验证。原始静止姿态约束不匹配与实际动画覆盖变化必须分别处理。

下一步可将三顶点材质约束用于局部求解，而非继续强拉透明边界顶点；仍需限制几何、位移并检查可滑动覆盖。当前只有定位能力，未生成新修复候选、未替换生产求解器、未重新捕获 Runtime，M4 质量门槛不变。
