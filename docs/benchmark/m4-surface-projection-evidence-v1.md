# 三维材质形变与二维投影压缩分离

2026-09-24。上一轮原纹理重叠及局部补图均未解决膝部外观。本轮检查另一项前提：对三维表面，投影面积比例不能直接等同于材质面积比例。没有修改当前二维生产候选的几何门槛，也没有重新解释它们为通过。

新增 surface_projection_evidence 对同拓扑的 rest/posed 三维顶点分别计算三维面积、边长、相机方向法线及二维投影面积。正交相机下，投影面积比 = 三维面积比 × 当前法线朝向余弦 / rest 朝向余弦。rest 近乎侧立时不除以接近零的投影面积；退化三角形单独保留。朝向变为背面不自动认定为材质翻转，也不自动视为可见。

输入沿用已核验的 overhead_squat.fbx（596014069e4ecc8527ba37feded9d7b8564d50832862dad89c0a75ca7c136bba）和 Beta.fbx（fd892dd062b815029539084255d75c19cbc54e5f68536641411865c35ef25af8）。Blender 5.2.1 在原三个精确时刻重新求值参考蒙皮，源骨端点最大误差 5.00577e-7 世界单位。使用此前 yaw=-45° 的同一相机矩阵，没有新增 PNG 渲染。

从 Beta_HighJointsGeo 与 Beta_HighLimbsGeo 两对象选择所有顶点对同侧 UpLeg/Leg 合计权重至少 0.8 的三角形。每时刻双腿合计 7,236 个三角形；这些是参考模型，不是红美铃纹理或网格。源码、输入哈希、三维顶点、三角形、相机及逐项数据均写入独立报告。

在 0.92604183203125 秒：

- 三维面积比范围 0.565844–1.000013，最大三维边长比例 1.000014，所选三角形均未触发既有面积 0.5–2 和边长上限 2。
- 从相机方向向三角形中心发射射线，共 2,038 个中心可见。
- 其中 798 个所在三角形投影面积比例超限，而三维形变仍在门槛内。
- 中心可见不代表整块三角形或所有像素可见；没有通过这份参考证据批准任何目标动画。

这说明，对之后真正具有三维表面证据的候选，需要分开检查材质形变、投影缩短、表面朝向和遮挡。关节深度或其他角色的参考模型，不能替目标二维网格提供免责。当前 Spine 候选没有匹配的目标三维表面，原失败及人工记录全部保留。

下一项应为目标腿部建立可追踪的三维表面与纹理对应，再检查投影和可见面；停止要求自然透视本身满足平面材质保形假设。仍需验证膝部轮廓、脚部连接及完整角色外观，不能仅靠更换检查方式完成 M4。

四项单元测试通过：刚体转动产生投影压缩但不产生三维材质形变、真实压缩不能改判、背面/侧立面不自动采用、相机尺度及退化输入处理。
