# Squat 最终腿姿态上的局部修正实验

2026-09-25。对上一轮 Alice、红美铃四个失败腿网格进行归因：最差三角形
分别为 62/137、124/75，均混合 thigh/calf 权重，不是纯单骨投影。
最差位置和时间记录于原候选目录 `area-attribution-v1.json`。

发现现有构建顺序先生成 deform，再求解移动脚端，因此 deform 没有针对
最终腿骨重新计算。新增隔离工具 `m4_final_leg_corrective_probe.py`，
按骨骼影响自动选出失败腿部，移除实验子文档 deform，用同一自适应算法、
位移预算及阈值重算，然后只替换选中腿部轨道。实际断言骨骼、其他部件、
权重、UV、槽位顺序完全不变。未接入默认构建，未修改原候选。

同一组 1,245 个时刻对照最小 setup 面积比：

| 角色/区域 | 原候选 | 重算 |
| --- | ---: | ---: |
| Alice layer-001-l | 0.171013 | 0.172001 |
| Alice layer-001-r | 0.395666 | 0.499467 |
| 红美铃 layer-003 | 0.454963 | 0.499932 |
| 红美铃 layer-004 | 0.164523 | 0.164697 |

所有重算区域受检时刻无翻转，但四处均未达到原始 0.5 面积门槛。
不能因接近门槛而四舍五入通过，也未提高容差。右侧混合区改善支持“修正
时序不一致是部分原因”；严重压缩侧几乎不变，不能用重算覆盖全部原因。
原面积归因中的投影参考因子约 0.30，也不足以豁免原始几何门禁。

本次仅检查面积和变更边界，没有完整边拉伸、Runtime 或视觉接受。
候选不采用。下一步分别处理最终姿态下的局部插值约束，以及强投影缩短
需要的表面表达；不修改固定动作集分母，不缩减 Squat 幅度。

`m4-final-leg-corrective-2026-09-25.json`。独立产物位于
