# Reach 连续裁剪：真实 Runtime 切换检查

2026-09-22。实验未采用；身份和机器摘要见同名 JSON。

实际候选输出在工作区 `tmp/m4-motion-center/reach-continuous-clip-v3`。相机为肩部世界区域 `(390,-330,100,100)`，100×100 原生 framebuffer；页面放大只用于观察，不改变测量尺寸。

## 实施与验证

- 连续轮廓按拓扑分为 50 段；公共端点保留原始轮廓拐点。最大 155 顶点，低于 512 预算；段间双向顶点到折线距离最大约 5.68e-14 px。区间内部采样近似误差最大仍为 0.0983 px，这不是连续时间深度安全证明。
- 使用 Spine 动画裁剪附件和互补 inverse 裁剪，保留原纹理、骨骼轨迹及原手臂 deform；新增前方副本继承相同 deform。
- 加入有限坐标、帧维度、时间顺序、段间时间、图层顺序、名称冲突检查，并核对来源 Runtime、贴图和 atlas 身份。
- 官方 Runtime 实际捕获 197 时刻：50 个区间内部点，加 49 处切换前/时/后；无浏览器错误。原生 PNG 逐文件摘要记录在 capture.json。
- 比较页同步、播放/暂停及反向定位检查通过；“未检查”不再误显示“未通过”，两个窗口标题明确同视角。

## 结果与限制

最初只比较 RGBA 字节会夸大全透明像素的 RGB 差异，不能当作可见闪动。本次改为透明度预乘颜色加 alpha 的差异，保留未经处理的原始截图。

49 处切换中，1.05 秒仍有 1 个原生像素的可见通道差超过 8/255：坐标 (47,88) 从 alpha 0 变为 255；原候选同处切换无变化。其余切换没有超过该诊断阈值的可见通道差。该阈值用于描述差异，不是新增验收门槛。

公共端点精确化之前，同一像素已有突变；修正没有消除它。更重要的是，0.85/1.05 秒实际肩部放大画面仍有明显直线切边。轮廓对应精确，不代表遮挡边界具有自然衣物形状。

因此停止该轮连续裁剪的细分/拟合调参，不默认采用，不迁移三角色。后续先检查局部姿态附件所需的真实图像区域与连接方式。当前结果不能说明所有 Runtime 裁剪方案均不可行。

尚未完成其他图层遮挡、全段插值深度安全、整角色视觉及跨角色验收。网格专用数值验证器不支持此裁剪候选，状态保持未检查。目标 Spine 4.3.26；实际捕获 Runtime 4.3.13。
