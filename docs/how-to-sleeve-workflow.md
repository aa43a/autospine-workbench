# 一条命令重建袖装候选

在仓库目录运行：

```powershell
$env:PYTHONPATH='src'
python tools/run-sleeve-workflow.py huiye uuz
```

入口读取已保存的两份归属草稿，检查当前骨架及项目来源，依次执行服装权重、根部过渡、交界、
多连接点修正、受限动作、连接带、边界预算与 Spine 导出。无需填写内容地址。
当前v3默认链在边界预算后增加明确袖口的共享权重平滑与非回归比较，并补充边长必要位移预算，共9个生成步骤；安装官方核心时增加第10步数值验证。
未通过比较的袖子保留原候选，不会扩大到未知区域或改变已保存标注。
输出末尾给出每个角色的统一结果页，包含时间轴检查链接、通过区域下载和未通过区域原因。

默认草稿目录为工作区 `tmp/r3a-sleeve-reviewed-v2`。其他目录使用 `--draft-root`，其中每个项目包含 `draft.json`。
草稿必须引用已有且匹配当前骨架的工件；该入口不代替首次Pose、人工归属或分区准备。
默认结果位于工作区 `tmp/r3s-workflow`；可使用 `--output` 指定新的结果目录。

## 中断与恢复

重新运行相同命令即可。运行身份绑定草稿、当前骨架/来源和编译器代码。
完成步骤保存不可变收据，复用前逐文件校验字节摘要；缺少或修改输出会返回 `sleeve_cached_output_changed`，不会把被改动的文件当作可信结果。
失败步骤没有成功收据，已完成步骤仍可复用。进程锁会随进程退出释放，防止两个任务同时写同一次运行。
运行使用草稿的固定副本；代码或项目来源在执行中变化会停止本次运行。

## 自动官方核心验证

已有官方 `@esotericsoftware/spine-core 4.3.13` 安装目录时：

```powershell
python tools/run-sleeve-workflow.py huiye uuz --runtime-core ../tmp/spine43-verification/node_modules/@esotericsoftware/spine-core
```

该选项不下载或捆绑Runtime。工作流将安装文件摘要纳入运行身份，导出后逐个验证可用候选，并校验
报告的骨架、Atlas、数值参考、Runtime文件、动画清单、帧数和误差判定。
验证结果与导出包分开保存，因此重复执行不会破坏导出步骤的缓存。报告损坏或来源不匹配会阻止复用。

`core_passed` 仅表示已导出区域的官方核心顶点验证通过，不覆盖仍阻塞的区域，也不代表GPU渲染或alpha接缝通过。
发生真实核心数值失败时，结果页移除该候选下载入口并显示 `official_core_numeric_failure`。

已验证两角色九步流程：两个右袖共3598帧官方核心核验通过，两个左袖继续阻塞；重复运行18个检查点全部校验后复用，约7秒完成。

## 主工作台入口

在主工作台的“全角色绑定规划”页面，使用“袖装候选 → 重建袖装候选”。
先保存主画布校正；当前入口消费已导入的袖装区域标注，尚未标注的项目会显示不可构建。
后台自动执行默认链，若本地已安装受支持的官方核心 Runtime，则同时执行其数值检查。
无需填写内容地址或本地目录。

页面显示正在执行的阶段，并逐袖列出候选下载或阻塞状态。任务结束后停止查询；
刷新页面可恢复查看当前任务。服务意外退出后，重新构建会验证并复用已有步骤收据。
下载会重新验证项目版本、标注和 ZIP 内容哈希，旧结果不会覆盖新校正。

当前入口只提供候选，官方核心数值检查不等同于 GPU/透明接缝验收；任何未通过几何检查的区域仍阻塞。
该入口位于绑定规划页面，未增加右侧属性栏操作。更新服务代码后需重启工作台服务并刷新页面。
