# 通用袖子处理方案

## 垂布辅助骨候选

交界根部实验：`tools/build-sleeve-helpers.py --input <根部过渡报告目录> --output <目录> --interface-root huiye uuz`，读取精确helper→权重→归属草稿链。只取hanging_cloth与sleeve/cuff的共享边，不以hand/unknown交界推定袖根；按边长加权中点生成根部候选。多段不连通交界返回ambiguous，不把中间点作为有效袖根。
实跑辉夜右/幽幽子左各一段，试验helper失败83→46和82→80但新增局部回归，因此均拒绝；辉夜左/幽幽子右各两段交界，保持旧根部。最终四处结果不变。Setup帧以粉色显示测得的交界和候选位置（不代表采用）；下一步应处理多连接点/袖口结构，而不是继续整体挪动单骨。10项针对性和质量检查通过。

2026-09-10：新增`--root-transition`独立profile，沿三角邻接最短路径到固定交界计算过渡，宽度固定为前臂长度0.25倍。垂布根部更多跟随前臂，内部渐增helper，非垂布顶点不变；无可达交界的组件阻塞。每区域对照旧helper的全部129点轨道，拒绝新增失败/翻转/坏三角形数量/超限拉伸恶化。
四处helper试验失败为83→42、76→49、83→38、82→50；只有辉夜左侧76→49通过逐点回归门禁，其他三处存在坏三角形增加而回退。最终组合83/49/83/82失败，仍不满足完整验收；不能只报告试验总数改善。12项测试覆盖根部距离、断连、比例不变、手骨隔离、权重守恒和质量限制。

`tools/build-sleeve-helpers.py --input <权重候选目录> --output <输出目录> huiye uuz`生成独立`sleeve-helper/v1`工件和固定样本播放页。

仅将垂布内部的下游权重转到新骨，混合边界/hand/unknown不变。采用真正parent关系的FK，不复用此前串行三骨假设；上臂/前臂转动能传递到helper，手旋转不影响helper。

四处均通过setup重建与权重和检查，手旋转90°对垂布内部的增量误差为0。前臂±30°的129均匀角度采样均无失败；手±90°仍有55/114/109/112个失败，helper±15°仍有83/76/83/82个失败（顺序为辉夜右/左、幽幽子右/左）。此处范围和均匀角度采样与之前非均匀关键姿态插值不同，不能直接比较失败计数。
候选未采用；共享边界/袖口约束、真实袖根复核、辅助链次级运动和官方Runtime未完成。下一步定位helper摆动的失败三角形与固定袖布接触，构造有界的连接过渡。

## 可用的三角区域复核入口（2026-09-09）

笔刷支持4–120屏幕像素直径，滑块、加减按钮和`[`/`]`调节；圆形光标展示范围，拖动自动补采样，整笔撤销。笔刷触及的三角形整块归属，最小精度仍受现有三角形边界限制。调整笔刷不改变草稿来源或网格。

显示修复：源层bbox为[left,top,right,bottom]，SVG图片和视口使用差值宽高。此前误用right/bottom导致源图放大、看似网格偏移；已修正并重生成四角色页面，候选、网格、骨架身份不变。加入非零偏移、负坐标及退化边界回归测试。

`tools/build-sleeve-regions.py --input <轴向修正报告目录> --output <输出目录> <项目...>`
生成源图+骨骼+三角形叠加画布。选择区域和归属类别后点击/拖动涂选，支持当前区域建议预填、撤销、下载及载入草稿。
预填仅覆盖pending项，不覆盖人工修改；全部初始归属为unknown。几何提示采用固定0.12前臂长度腕带，跨边界或横向远离手轴的远端三角形保留unknown，不自动猜垂布。

下载后可在同页载入继续，或追加 `--draft <草稿文件>` 并指定单个项目，经精确候选地址与逐项清单校验封存。
`sleeve-regions/v1`保存建议，`sleeve-region-draft/v1`区分pending、geometry_prefill和manual_edit；均无生产权。
来源PNG按SHA核对，网格、权重和原始图像不变。

实际四角色可编辑三角形：Lumia1070、辉夜708、幽幽子720、妖梦714。6项针对性与质量测试通过，四角色Schema和嵌入脚本语法检查通过；未完成浏览器交互/截图验收。
本页是三角形级归属草稿，不是像素切割器。跨语义边界的三角形下一步需要细分，明确归属的袖布才可进入去除手骨影响的候选编译；当前不会立即改权重。

袖子是服装，不应默认将袖布绑定到手掌。当前辉夜、幽幽子的末端轨道失败说明两种问题并存：区域语义未分离，以及旧圆形修正范围无法覆盖横向宽袖。角色名称不参与算法。

## 驱动合同

同一源纹理允许多个内部区域；先保存分区候选，再生成绑定候选，原图与已确认记录不变。

| 区域 | 主驱动 | 后续处理 |
| --- | --- | --- |
| 裸露手掌/手指 | hand | 刚性或手部专用Mesh |
| 贴臂袖段 | upperarm / forearm | 肘部平滑两骨过渡 |
| 袖口 | forearm为主 | 与手腕接触约束；按服装结构决定是否跟随手，不能统一锁到hand |
| 宽袖垂布 | 袖根辅助骨链 | 受上臂/前臂驱动，离线确定性次级运动 |
| 无法确定归属 | 无新增绑定 | 进入语义/区域复核，保留来源 |

识别证据包括明确的 wear.sleeve 语义、原始alpha连通域、肘腕位置、沿骨轴的横向宽度、袖口与手的接触。宽度只能提示宽袖候选，不能证明哪些像素属于手；不能仅由 handwear 名称推断。当前候选层 semantic 为空时不得自动称为“已确认袖子”。

## 执行顺序

1. 在现有区域/骨骼画布中增加 sleeve / cuff / hand / hanging-cloth / unknown 归属候选。自动预填证据充分部分；人工可拖动边界或点选修改。保存来源绑定的mask，不改变原PNG。
2. 仅对明确袖布区域限制手骨影响，将主权重分给上臂/前臂；保留手部原绑定。混合三角形需增加关节/袖口支撑点，避免跨语义区域简单插值。不可把整层hand权重清零。
3. 宽袖垂布另建1–3条辅助链，根部随手臂、袖口接触受约束；不在主链中伪造人体骨。先无次级运动的结构QA，再做固定步长离线Bake。
4. QA固定检查肘屈伸、腕旋转、抬臂及组合动作；检查翻转、面积、拉伸、袖口裂缝、布料穿手/穿身、setup重建，最后走Spine 4.3.26官方Runtime。候选逐区域回退，不静默批准。

## 本次已实现的局部能力及限制

`component_axial_solver.py` 将末端修正支持范围改为骨轴方向的有界带：轴向半宽为父骨长度0.45倍，横向仅覆盖当前隔离区域中的坏三角形邻域。保持旧的0.15父骨长度位移预算、96次确定性解算和旧源网格不变。它是通用末端几何实验，不是袖子自动分区或完整布料解算器。
