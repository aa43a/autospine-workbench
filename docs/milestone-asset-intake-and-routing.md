# 下一里程碑：资产中心与新角色自主接入

规划日期：2026-09-11。目标：用户在工作台导入一个此前未登记的分层 PSD，
管理其生命周期，自行选择或按建议进入普通绑定、袖装标注和候选验证。

## 起始缺口

- 项目 HTTP 列表读取已发现的 audit；尚未形成工作台 PSD 上传与项目生命周期操作。
- 动画来源准备已有从 audit 到姿态与关节复核的入口。
- 袖装已有独立导航、14 阶段进度和候选验证；可构建条件仍依赖工作区已有 draft.json。
- 新项目缺少袖装适用性判断、标注创建与保存的闭环。现有临时目录桥接不能作为新资产登记方式。

## 实施顺序

| 切片 | 交付 | 验收 |
| --- | --- | --- |
| A1 项目目录 | 独立资产中心，缩略图、名称、来源、当前状态、下一步；新增、重命名、归档、恢复、回收站 | 状态重启后保留；归档退出默认列表；删除进入回收站并可恢复 |
| A2 PSD 导入 | 文件选择与拖放、导入任务、解析进度、错误恢复、源文件快照与去重提示 | 新 PSD 无 CLI 创建项目；保留图层偏移、alpha、顺序；同名不同内容不覆盖；失败不产生半成品项目 |
| A3 能力分流 | 普通绑定 / 袖装处理 / 待判断，展示语义与几何依据，支持用户选择或覆盖建议 | 无袖不因 handwear 名称自动进入袖装；用户可开启袖装；缺前置项时列出可执行下一步 |
| A4 标注接入 | 工作台创建与保存袖装标注，源图与全骨骼覆盖、笔刷尺寸、区域选择、实时试播 | 不再要求下载 JSON 再由开发者放入目录；保存绑定当前源网格与骨架版本；改变来源使旧结果失效 |
| A5 连续流程 | 从资产卡进入复核、修复、时间轴、官方捕获；返回资产中心仍可见任务状态 | 任务可恢复，错误有 reason code；明确区分构建完成、数值通过、视觉待复核、已撤回 |

资产中心放在全局导航，与项目内工作步骤分开。属性侧栏只处理当前选择。
资产状态与任务状态分别存储，禁止从任务完成推导人工复核完成。

## 管理语义

- 归档：保留源资产、校正与输出，默认列表隐藏，支持恢复。
- 删除：先进入回收站；首版不提供永久物理清除或共享工件回收。
- 有运行中任务时拒绝删除并提供任务入口，避免输出写入已删除项目。
- 项目 ID 与展示名称分离；改名不改变内容地址。
- 原始 PSD 保持不变；导入使用托管快照，历史内容寻址工件不重写。
- 导入限制文件尺寸与解析资源，记录错误；源文件来源与权利信息可登记但不推断授权。

## 袖装选择规则

自动推荐结合图层语义、连通域、相对骨段覆盖及垂布形状，不使用角色名称规则。
不能只凭 handwear 标签判定有袖。证据不足显示待判断，给出普通绑定与袖装处理选择。
用户选择袖装后依次准备骨架、区域网格和标注；已有前置条件则直接打开标注。
实时试播用于反馈，正式候选仍通过既有数值、接缝与官方 Runtime 验证。
自动推荐、自动预填、人工保存和最终采用保持不同来源记录。

## 里程碑验收

1. 至少一个此前未登记的分层 PSD，全程通过 UI 进入可播放候选，无需 SHA、CLI 或移动 JSON。
2. 覆盖无袖、普通袖、宽袖三个输入类型；至少一个新输入不参与规则调参。
3. 新增、同名冲突、重复导入、归档、删除与恢复、解析失败、重启恢复均有行为测试。
4. 用原辉夜、幽幽子与灵梦回归；只改入口与登记时不改变既有算法及历史输出身份。
5. 原有文件规模 ratchet 保持；新功能采用独立资产管理、导入、分流和页面模块。

本里程碑不包含 PNG 自动 See-Through 分层、任意袖装自动通过、永久删除共享工件、
新物理算法或 Blender 输出。完成标准是新角色接入现有能力的产品闭环。
