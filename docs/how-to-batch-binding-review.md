# 分类与批量预填图层绑定

在主工作台「可变形动画候选预览」展开「图层绑定复核」。

1. 用「绑定复核分类」筛选单骨、网格、分区、衣饰与次级运动、眼口或缺少方案的图层。
2. 在全部或单骨分类下，点击「预填待复核的单骨刚性建议」。
3. 查看各层及所选骨骼。预填只修改当前页面的草稿，可用「撤销未保存修改」恢复。
4. 检查后点击「保存绑定复核并重建」。这仍使用现有带来源校验的保存接口。

批量预填只消费已有的唯一单骨刚性建议；不会创造绑定选项，也不会覆盖已有 bind、exclude、requires_split 或 semantic_review 记录。
筛选仅影响显示，保存仍提交完整记录集合并保留说明。来源变化会清除旧来源的本地草稿；只读状态不能预填或保存。

分类依据是当前候选选项、原因码及源图层名称，是导航提示，不是新的语义分析或自动采用策略。
衣饰、头发、复杂物件、眼口、分区以及存在冲突的候选不参加本轮批量预填。眼口绑定也不代表已经支持眨眼口型。
没有绑定选项时，保留待复核或填写进一步处理说明；不能将空选项保存成绑定决定。
