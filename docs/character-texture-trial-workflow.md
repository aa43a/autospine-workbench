# 整角色低透明度残余候选

在工作台“整角色候选”勾选“归并低透明度残余（候选）”，再构建。
任务在合并所选动作之后，按 `aligned-low-alpha-v1` 生成独立纹理候选，
随后执行原有整角色网格、官方 Runtime 和 setup 对照。页面显示实际转移像素数。

仅处理 alpha 1–7、同源唯一网格、UV 对齐、完整像素被单个三角形覆盖且目标
透明的像素；其余残余继续保留。原始资源、绑定决定和图层完成状态保持不变。
新候选仍需独立视觉复核，不继承旧任务的确认。

关闭选项并重新构建可恢复原纹理。未指定该选项的 API 请求保持旧行为及内容地址。
该选项属于待构建参数，当前下载包是否使用它以任务状态中的归并像素数为准。

API 可选参数：`residual_texture_profile: "aligned-low-alpha-v1"`。
其他非空值拒绝；任务持久化请求包含 profile，相同活动请求复用任务。
来源校正或区域决定变化仍会使旧候选不可下载。

验证覆盖：默认构建与关闭后重建地址一致、新纹理包进入捕获、原层状态保留、
来源变化阻塞下载、非法 profile 拒绝、前端显式选择与切换项目清空。
算法此前两角色官方 Runtime 实验仍是候选证据，不是生产采用证明。

## 逐区域剩余原因

图层账本直接显示当前候选的转移数、保留数和原因。旧任务从内容寻址包内的
`residual-transfer.json` 读取，原任务结果不重写，不重跑 Runtime。
辉夜当前保留 100 个像素：鞋层 53 个位于网格外；右袖 29 个完整像素覆盖不足、
1 个位于网格外；左袖 17 个完整像素覆盖不足。这些仍为待处理区域，不能自动排除。
即使某区域保留数为零，也不自动完成绑定或视觉复核。
