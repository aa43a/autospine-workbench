# M4-Q：大幅动作外观与同页异常修复闭环

归档调整：2026-09-28。状态：M4 质量后续工作清单，不占用 M5 编号。
此清单保留此前质量规划的诊断和修复顺序；只有影响具体联合动画的异常才按需处理，
不要求先完成本清单再进入 M5。正式 M5 见 [脸部、头发与服装联合动画](milestone-m5-joint-animation.md)。

## 目标

用户选择已绑定角色和动作后，在同一个编辑页完成自动映射、异常定位、局部调整、
前后对照、构建复查和 Spine 导出。默认处理有充分依据的方案；用户主要处理
需要判断的异常，并在完整动作上做阶段验收。

重点改善拳击的跨部件遮挡和下蹲的屈膝外观，同时建立可复用的姿态/视角素材能力。
360° 相机与骨架映射继续可用；可信的侧背面外观以实际素材覆盖为依据。

## 起点：已经交付什么

依据 [M4 最终审计](m4-delivery-audit-20260928.md) 和
[角色动作编辑链交付](character-motion-editor-delivery.md)，本次核对已有证据，未重新捕获动画。

| 共用时间轴、连续水平角度、实时角色贴图、角度草稿和撤销 | 正面贴图不能提供未见的侧背面 |

| 实时草稿与实际导出结果同页对照 | 原始预览不包含后台局部修形、接触和遮挡修正 |

也不能将旧基线的失败数套用到所有后来独立候选。M4-Q 新候选逐一保存自己的证据。

## 产品流程与页面布局

主流程：选择角色/动作 → 自动映射 → 查看实际构建结果 → 时间轴定位异常 →
按部位修改 → 构建独立候选 → 同帧对照与整段验收 → 导出当前版本。

- 顶部保留角色、来源、版本及主操作；清楚区分“构建完成”“有技术异常”“阶段接受”。
- 中央以实际角色为主，原方案/新方案可并排或切换；源骨架按需展开。
- 底部共用时间轴，增加异常和修正区间；点击异常自动定位时间、缩放到部位并高亮区域。
- 侧面仅展示当前选区的处理选项：前后关系、局部形状、姿态素材、接触；避免全部操作常驻堆叠。
- “自动处理可修复项”只执行已验证且符合适用条件的策略，生成可撤销候选；
  证据不足时保留异常，集中展示需要用户判断的内容。
- 重建后回到原角色、动作、时间和选区；草稿与旧结果不同步时明确显示。
  播放、验收和下载始终指向同一精确候选，旧接受记录不转移。

## 技术路线与复用边界

### 遮挡：区分身体深度和衣料覆盖

1. 结合源三维深度、已确认的覆盖关系和当前 Runtime 实际可见像素提出约束。
   身体骨骼深度作为证据，不直接当作裙摆、披肩或宽袖的真实表面深度。
2. 能用整层排序表达时复用现有顺序轨道；同层出现局部前后冲突时，使用最小必要分区，
   保留原纹理、UV、权重和运动。检查被跨越的所有相关附件。
3. 前后状态采用有时间依据的稳定切换，检查进入、退出和倒序拖动，避免抖动。
4. Alice 披肩覆盖袖子且可滑动，沿用用户已有确认；不恢复“网格边界必须位于衣服覆盖区内”的旧约束。

现有 `local_depth_analysis.py`、`runtime_visibility_depth.py`、`region_order_candidate.py`
及 `region_order_interval.py` 可复用。显式排序候选目前不是自动深度推断，自动建议需新增独立适用性检查。
第一真实案例见 [拳击可见遮挡证据](benchmark/m4-boxing-visible-blockers-v1.md)：
633 个像素×时刻涉及手与腿的可见代理冲突，另 1,154 个涉及未确定的裙片深度；两类分别处理。

### 变形与素材：先选正确表达，再做局部修正

- 分开识别真实投影缩短、权重额外塌陷、拓扑冲突和缺少姿态外观。
- 对有合适素材的可观察姿态使用已有局部修形；保留正常区域、固定点和位移预算。
- 原图无法表达前屈膝、掌背或侧面时，复用素材任务包、回交、锚点对应和变体编译。
  可以依据现有素材制作生成图候选，但须完成风格、透明边缘和连接位置复核。
- 姿态变体记录部位、源素材身份、适用姿态/视角和过渡条件，支持再次使用；
  第一版先沿用编译器支持的拓扑对应，不把任意新拓扑导入列为必要前置。
- 切换检查不仅看几何：还要实际渲染颜色、alpha、轮廓和遮挡。简单交叉淡化可能形成双轮廓，
  不作为通用解法；原图复制回交只能证明运输链，不能算新姿态改善。

复用 `pose_geometry_patch.py`、`material_region_candidate.py`、`view_pose_variant.py`、
`view_switch_continuity.py`，以及 `motion-repair-*`、`motion-material-*`、`motion-view-*` 界面模块。
以新的局部表示策略补齐缺口，不重新开发 MotionIR、Kimodo 或基础导出器。

### 接触与预览

沿用相机一致的来源观测和接触时段，在现有踝点代理之外增加目标鞋底锚点与明确地面参考。
没有脚面/地面依据的来源保持缺测；镜头旋转导致的屏幕移动不自动锁住。
本阶段采用离线约束和烘焙，不引入完整物理模拟。

局部编辑可即时显示“未验证预览”，最终检查仍对精确烘焙候选执行。复用已有实际导出对照栏，
增加修复策略和素材版本匹配，不承诺昂贵的完整 QA 随每次拖动同步完成。

## 验收集合与完成标准

固定角色：Alice（普通衣装）、辉夜（宽袖长裙）、红美铃（无袖、外露腿部）。
冻结来源、角色版本、相机策略和候选身份，保留原 M4 24 组合及已知失败。

| 集合 | M4-Q 目标 |
| --- | --- |
| 拳击 × 三角色 | 手/臂跨越腿、躯干和服装时，已定位的错误前后关系得到可见修复；动作时序与有效姿态保留 |
| 下蹲 × 三角色 | 源举臂与骨盆下降保留；外露膝表现前屈而非反凹，裙腿覆盖与脚端运动合理；隐藏区域不能靠遮挡推定通过 |
| 转体 × 三角色 | 逐部位标明实际素材可表达区间，验证已有素材与新变体的进入/退出；缺侧背面保留素材需求，不计完整转身可用 |
| 既有十五个阶段接受组合 | 复用原精确版本作为对照，对受影响动作重建回归；未变化历史证据明确标为复用 |

M4-Q 产品闭环要求三角色都能在同页完成异常处理、恢复和一致版本导出。
新增动作可用性的目标是拳击/下蹲六组合通过与该修复相关的技术检查和整段阶段视觉验收；
未解决的原技术项继续展示，不转写为技术全通过。任何组合未达到此目标，支持扩展部分仍记为未完成。
转体交付素材能力管理与真实变体验证，不将完整 360° 侧背面美术制作列为本里程碑承诺。

开发前冻结每个组合本次必须通过的技术项、允许保留的原异常以及受影响区域/时段。
新增的全局几何、接触或显隐回归不能以局部修复范围为由豁免，也不能在结果出现后缩小必过项。

每项修复都检查关键帧、作用区间边界和中间帧；进入整段后执行几何、接触、遮挡、
实际 Runtime 渲染与导出回读。来源不支持的突发半圈、新增翻转、像素缺失、明显硬切及
超过原门槛的接触回归不能通过减少采样、静默限幅或删除失败案例消除。

分别记录构建完成、技术结果、阶段接受、受限/缺素材和失败；使用实际抽查分母统计错误自动采用。
记录人工有效操作、自动处理、端到端耗时和干预次数，历史缺测不补算。
先测当前设备首帧、拖动延迟、播放帧耗时、构建耗时和包体；交互不能阻塞等待后台构建。
缓存已就绪时定位画面的建议目标为 p95≤100 ms，作为待实测工程目标，不是现有通过结论。

## 首个开发切片：M4-Q.1 的具体任务

1. 将已有 geometry/depth/contact 证据适配到编辑页当前结果，保留原任务与证据身份。
   展示异常部位和真实记录时刻；稀疏观测不涂成整段已测区间。
2. 增加时间轴点击定位、当前选区高亮和源/结果同帧对照；旧草稿、不同来源、延迟响应要隔离。
3. 把已有区域顺序草稿接入选区面板：选择参照附件、前/后和作用时段，显示建议依据及未知关系。
4. 保存并构建独立候选，复用进度、取消、重试；完成后同页加载，支持恢复原候选及草稿撤销。
5. 使用上述拳击案例实测完整操作、切换边界与当前导出包；保留原有几何、裙片深度等未解决问题。

此切片交付标准是可操作的真实修复闭环。拳击整体质量是否改善，在 M4-Q.2 单独验收。

## 范围控制与后续能力

脸部、头发与服装联合动画按原定 M5 独立推进，复用已接受身体动作和现有袖装/裙装绑定。
本清单只处理大幅动作的投影、外观及遮挡扩展，不将全部质量修复作为 M5 的前置。
Anime2.5DRig 参考与表情/次级运动计划以正式 M5 文档为准。

每种新表示先验证关键姿态及过渡。连续两次有明确假设的修正仍无实际画面收益，就记录原因并
切换表示或提出素材需求，不持续增加网格、槽位或放宽阈值。算法不得以角色名或三角形编号为条件。
新增代码按证据读取、策略、编译、验证和 UI 拆分，生产模块保持 400 行以内；针对实际反例验证。
计划、开发、技术检查和阶段接受分开更新；此文不修改已有候选与用户记录。
