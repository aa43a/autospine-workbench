# M4 剩余目标：动作保真与整角色交付

2026-09-21。保留原定 M4 范围：FBX/BVH/SOMA77 NPZ、隔离 Kimodo 生成、
MotionIR、整角色 Spine 4.3.26、三种结构与八类固定动作、可播放导出和异常定位。
本计划调整剩余工作的先后顺序，不把成功条件缩小为“能播放”。

## 当前证据

导入、生成、任务生命周期、候选构建与导出已有实测；详见 m4-requirement-closeout.md。
用户只明确接受三角色 breathing 的阶段表现并保留技术异常。
其他动作的概括性反馈不能改写为逐项通过。用户明确指出 squat 膝盖反凹、手未举起，
reach 缓慢抬臂变成快速半圈旋转，以及大幅度屈肢变形。

独立实验 source-absolute-limb-direction-v1 使用红美铃固定来源：

- squat：原旋转重定向的双上臂相对源投影方向误差约 124.80° / 117.65°。
  BVH 编译会扣除第一帧角度，目标又叠加自身 setup，因此不是绝对姿态拟合。
- reach：右前臂 2.20–2.833333 秒共 20 帧投影长度低于三维长度 20%，
  2.466667 秒最低约 3.95%。这一段方向非常敏感，需要三维证据约束。
- 实验能在源采样点拟合绝对方向，但未解决位置、前后遮挡、关节体积；
  未运行新的官方 Runtime，不自动替换候选。

实验输出：../tmp/m4-source-pose/{squat-v1,reach-v1}/index.html、report.json、skeleton.json。
比较对象是未加接触和网格修正的旋转基线；不能将此误差声称为最终 framebuffer 误差。

第二版实验 source-absolute-limb-projection-v1 同时拟合绝对方向与源投影长度，
使用父级逆仿射矩阵补偿，并保留垂直于骨轴的 setup 厚度。
输出 ../tmp/m4-source-pose/{squat-v2,reach-v2}/index.html；源肢体正面/侧面方向链
与目标骨架共享时间轴。右侧是肢体方向示意，不是完整源三维角色。
Chrome 实测 reach 2.467 秒显示前臂 4.0% 投影长度，无页面脚本错误；
播放约 1.1 秒后到 3.600 秒。14 项相关单元测试通过。
新策略尚未接入默认构建，未执行新网格、接触、遮挡或官方 Runtime 验收。

## M4-A：动作语义与投影正确（当前主目标）

交付：source pose → target pose 的显式标定、深度/弯曲平面信息、
退化区间处理与源/目标同步时间轴，均绑定来源和算法版本。

1. 明确世界轴、左右侧、屏幕轴、绑定姿态及源初始姿态；保留源初始举臂/屈膝。
2. 对齐肩肘腕与髋膝踝的目标位置，联合骨长和屈肢平面约束；
   用源三维深度判断朝前/朝后，不能用二维角度正负代替。
3. 对朝向镜头的退化区间使用三维连续方向、弯曲平面与投影长度联合求解；
   明确二维不可辨识区间。不得全局压角度、降低动作幅度或删除问题帧。
4. 比较正面、固定斜视以及受约束的表现性投影；区分忠实投影与视觉近似，
   保留真实多圈旋转，不将所有旋转一律取最短路径。
5. 同页同步源三维与二维、选择动作、拖动时间轴、定位异常区间。

验收：首先 squat / reach 三角色共六组合，随后回归固定八动作。
应能保留初始举臂、下蹲与伸手的时间过程；不出现无源运动依据的快速翻臂；
屈膝前后关系可解释。数值方向吻合不能代替视觉验收。
不可由现有素材表达的姿态要明确标识，不能静默输出为已支持。

## M4-B：大幅度动作下的形状与遮挡

依赖 M4-A 的稳定姿态，避免用变形补偿掩盖动作错误。

- 复用现有局部 corrective，增加姿态驱动的肘/膝体积与轮廓约束。
- 以三维代理骨架/简单体块提供前后顺序、缩短和关节体积参考；
  不默认制作完整三维角色，不把卡通着色当成关节修复。
- 联合前后深度、部件交叠与稳定切换，检查裙腿和手臂躯干关系。
- 对单张纹理无法表达的掌背、侧背面明确要求替代附件或限制；
  不自动生成或伪造缺失素材。

验收：固定六组合再扩展八动作，比较同帧轮廓、接缝、翻转、伸长、脚部接触，
运行官方 Runtime 数值及实际渲染；已有低幅度接受结果不得回归。
宽袖沿用现有通用策略并保留异常，不单独无限优化。

## M4-C：默认流水线与明确支持范围

- 将通过验证的新策略以新版本接入工作台；原候选、参数、来源和人工决定保留。
- 自动完成可判定部分，只将缺图、不可辨识投影、技术失败提交异常队列。
- 一处完成导入/生成、适配、播放、错误定位、调整、重建、下载。
- 固定三角色 × 八动作重新核对当前候选，记录自动处理时间、人工有效操作时间、
  失败类型、技术检查及阶段反馈；未测时间不补造。

验收：每个组合均有精确候选身份、可复现参数、播放/导出证据和明确范围结论。
支持、带异常阶段可用、当前不支持分开列出；不要求把技术失败全部改成绿色，
也不允许用换动作、缩短片段或静默减幅取代用户要求。

## 执行与停止条件

先完成 M4-A，优先 squat 初始举臂和 reach 退化区间。实验模块保持独立，
每次新策略有针对性测试和真实样本对照后再进入现有构建链。
基线对照至少包含 setup、关键姿态、问题区间与连续播放。
若修复需要未提供的侧背面素材，将其归入明确限制并继续其他可表达动作，
不将模型、阈值调参或新增报告本身视为里程碑完成。
